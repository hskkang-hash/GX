## §2 ★★ 어제의 0 은 수가 아니었다 — 조율자 오류 ⑬

```
probe_read_surface.measure(caller, method, url, principal, query)
                                                ^^^^^^^^^  ^^^^^
```
다섯째 자리는 **질의값**이다. 조율자가 거기에 `{"Authorization": …}` 을 넣어 그 글자는
`?Authorization=Bearer+…` 로 URL 뒤에 붙었을 뿐이고, 진짜 헤더는 `Caller.call()` 의
`token` 인자로만 만들어진다 — **한 번도 안 실렸다.** 「익명」과 「가짜」는 **같은 요청**이었다.
그 0 은 **분모 0 인 초록**이다. 잡은 것은 **차선 S** 다.

고친 판으로 다시 쟀다 — 유출은 **여전히 0**, 그러나 **0 의 이유가 다르다**:

| `Authorization` 에 실은 것 | 답 |
|---|---|
| 없음(익명) | **401** ✅ |
| `Bearer `(빈 값) · `Basic …` | **401** ✅ |
| `Bearer gx.bad.token` · 서명 틀림 · 만료+서명 틀림 | **500** ❌ |

뿌리는 `core/middleware/refresh_token.py:173·204` 의 미포착 `jwt.DecodeError` —
**dj-core**(§0.4)다. **손 밖 선언**으로 적되 **회색으로 안 바꾼다.** 잰 빨강이다.
⇒ 아직 **안 쟀다**: 서명이 유효하고 `exp` 만 지난 **진짜 만료 토큰**. 서명 비밀키가 필요해
이 창에서 안 썼다. 그러니 **「고객이 매번 500 을 본다」고 적지 않는다.**
증거: `docs/agent/evidence/SEC-FAKE-BEARER/틀린토큰은401이_아니라500이다_20260923.md`

## §6 새 불변
- **0 이라는 수가 같다고 같은 사실이 아니다.** 어제의 0 은 「안 보냈다」, 오늘의 0 은 「보냈는데 안 나왔다」.
- **게이트가 세상을 다 말하지 않는다** — 유출 0 은 초록인데 세상은 364/364 가 500 이다.
- **게이트를 고치면 그 게이트가 걸린 절을 전부 다시 읽는다**(E 자진).
- **머리글은 늙는다** — 호출 자리·환경 이름·전제는 주석이 아니라 **코드**에서 확인한다.
- **한 갈래를 보고 낸 색은 색이 아니다**(조율자 오류 ⑱).
- **어긋나면 둘 중 하나가 거짓이다** — 두 수를 나란히 둔 덕에 ⑰ 이 잡혔다.
