## §3 P-182 — 게이트를 세우니 **씨가 아직 살아 있었다**

`scripts/verify_bundle_api_base.py` 신설(게이트 이름 `bundle-api-base` · `ALL_GATES` **16→17**).
묻는 것 셋: ① 기대한 API 밑동이 **서버가 내주는 엔트리 JS** 안에 리터럴로 있나
② 그 밑동이 SPA 제 원점과 같지 않나 ③ 정적 서버가 `/api/...` 에 **404** 를 내나.
기대 밑동을 모르면 **회색**이다 — 모르는 채로 초록을 내지 않는다.

**① 이 게이트가 처음 돌면서 제 약점을 스스로 드러냈다.** 처음 규칙은 「밑동이 하나라도 있으면
통과」였는데, 살아 있는 번들을 물어 보니 `http(s)://` 리터럴이 **55개**였고 대부분
`react.dev` · `redux.js.org` · `bit.ly` 같은 **의존성 안의 문서 주소**였다.
그 규칙대로라면 **사고 당일의 번들도 초록**이 된다. 규칙을 「기대한 밑동이 있는가」로 뒤집고
그 실패 사례를 자기시험에 박았다.

**② 탐침 경로에 한글을 썼다가 멀쩡한 서버를 빨갛게 만들었다.** `urllib` 이 비-ASCII 를 못 실어
예외로 죽었고 그 예외가 「SPA 가 안 선다」로 찍혔다. **못 잰 것은 회색이다.**

**③ `deploy.sh` 안에 거짓 초록의 씨가 그대로 남아 있었다** [실측] — **D-493 이 덜 닫혀 있었다.**
턴 U 에 V 가 찾은 씨(정적 서버가 `/api/...` 에 200+HTML)를 `scripts/gate_spa_server.py` 에서
고쳤는데, `deploy.sh` 의 `ensure_spa()` 에는 **옛 본문이 heredoc 으로 통째로** 박혀 있었다.
**배치 한 번이면 고친 서버를 도로 덮고 씨가 다시 심긴다.** 본문이 두 벌이면 고침도 두 벌 해야
하고 한 벌은 반드시 잊힌다(D-369). heredoc 을 지우고 저장소본을 복사하게 바꿨다.
**눌러서 확인했다**: SPA 를 죽이고 `/tmp` 의 본문까지 지운 뒤 `deploy.sh` 를 돌리니
「SPA 섰다」 뒤 `/api/__gate_probe__/no-such-place` 가 **404** 였다.

**④ 위임을 복사하지 않았다.** `verify_route_alive.delegate_to_container()` 에
`extra_args`·`extra_env` 를 더해 **한 벌**로 두 판정기가 같은 문으로 들어간다.
호스트에서 `gx-shell` 은 3002·8000 을 게시하지 않으므로(`docker port gx-shell` 이 비어 있다)
위임이 없으면 이 게이트는 **영원히 회색**이고, 영원히 회색인 게이트는 곧 꺼진다(D-353).

음성 대조 [실측]: 없는 밑동 기대 → **exit 1** · 기대 안 줌 → **exit 2** · 제대로 → exit 0 이고
「입력 1건 — 서버가 HTTP 로 내준 엔트리 JS」를 말한다(D-301).

## §7 오판 (자진)

1. **차선 지시서에 U1 을 「시민 제보자」로 적었다.** 저장소의 U1 은 **관제요원**이다
   (`onboarding_48.md:151` · 계정 `gxseed_u1_operator`). U1 이 저장소를 정본으로 보고
   바로잡아 일했다 — 옳다. 페르소나 이름을 **지시서에서 베끼지 말고 정본에서 읽었어야** 했다.
2. **새 게이트의 첫 규칙이 틀렸다**(§3 ①). 「밑동이 하나라도 있으면 통과」는 사고 당일의
   번들도 초록으로 만든다. 살아 있는 번들을 물어 보고서야 알았다 — **자기시험만으로는
   못 잡았을 자리**이고, 게이트는 실물을 한 번 물어야 태어난다.
3. **탐침 경로에 한글을 써서** 멀쩡한 서버를 빨갛게 만들었다(§3 ②).
4. **「AutoStart 를 켰다」고 적었는데 안 켜져 있었다.** 설정 파일을 고치고 파일을 다시 읽어
   True 를 확인한 것까지는 했는데, **Docker Desktop 이 나중에 제 값으로 덮어쓴다**는 것을
   몰랐다. 오늘 판정기가 잡았다. 교훈은 한 줄이다 —
   **설정은 바꾼 직후가 아니라 한참 뒤에 다시 읽어야 바뀐 것이다.**
