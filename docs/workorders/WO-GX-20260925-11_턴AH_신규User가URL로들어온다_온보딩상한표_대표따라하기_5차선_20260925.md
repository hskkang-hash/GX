## §4 세종 판정 (삭제·되돌리기·운영계 외부 행위·`.env` 실제 값은 대표)

- **P-297 `-old` 컨테이너 셋 — 세종 권고 「지운다」(②) · 결정은 대표 한 마디.** 근거: ① 셋(`gx-celery-e-old` · `gx-celery-e-old-2b` · `gx-gunicorn-e-old-2b`)은 창 2b 되돌리기용이었고 창은 09-17·09-23 두 번 되돌리기 없이 끝났다 — 보존 목적이 소멸했다 ② 컨테이너는 코드·설정의 껍데기이고 자료는 **이름 있는 볼륨**에 있다(`docker rm` 은 `-v` 없이 · 볼륨 0 삭제 · 표로 먼저 확인) ③ 셋이 있는 한 아침 게이트는 **영구히** 셀 수 없고(P-203 게이트를 고쳐 수를 올리지 않는다) ①길(`-old` 이름 바꿔 보관)은 다섯으로 늘려 더 깊이 막는다 ④ 같은 창에서 로그 상한 없는 둘을 다시 만들면 OPS-07-a 도 같은 뿌리로 닫힌다(영실 판단 옳다). **절차**: 표 → 대표 「지워라」 → `docker rm` → 재생성(창 2b 절차 · 되돌리기 10분) → 아침 게이트 재셈 → 보고에 전/후 표. 대표가 「두라」면 ①길 대신 **게이트만 「도는 것」을 보게 고치고 `-old` 는 그대로** — 수를 고치는 게 아니라 분모의 정의를 고치는 것이라 P-203 위반이 아니다.
- **P-298 push 는 대표 손 — 조율자는 세 번째 시도를 하지 않는다.** 두 번 막힘은 Code 환경의 자격 문제다(P-0 · 세종 추정 · 영실 [실측]이 덮는다). 보고에 「push 대기 N커밋 · 해시 목록」을 적고 §5 ② 따라하기로 대표가 올린다. push 뒤 조율자가 `origin/turn-q == turn-q` 를 확인해 적는다.
- **P-299 온보딩 「100%」= 상한 표.** 48행 중 정본이 ◐ 상한으로 정한 행(U4#9 영상 구간 · U6#3 API 키 상세 D-371)과 계약 11조 잠금 행(U3#14 모바일 실시간 ○)은 ●가 될 수 없다 → **상한 46.0/48 = 95.8 %**(세종 추정 · **Q 가 장부에서 계산한 수가 정본** · 손으로 적지 않는다). 「온보딩 100%」= 상한 도달 · RC-1 문턱 90 % = 43.2. 잠금을 지키는 것과 온보딩이 닫히는 것을 한 칸에 적지 않는다(장부 규약 그대로).
- **P-300 대표가 본 열둘(P-285~P-296)은 이 턴의 본 일이다.** 「대표가 본 화면이 게이트보다 먼저다」 — 게이트 초록 위에서 고객 화면이 틀렸으니 게이트가 틀린 것이고, 열둘 중 넷(P-286 로그인 · P-287 비번 찾기 · P-288 종결 카드 · P-290 탐침)은 **신규 User 첫 10분**을 막는 빨강이다. 임자는 WO-10 §9 그대로 · 닫는 조건도 그대로 · 차선 신설 0.
- **P-301 카드 진행률 100 은 PRD §7.2 표 그대로 잰다.** 6역할 × 카드 7(U3·U6 는 4·6) · 완료는 서버 기록이 닫는다(UX-46 · 사람이 체크하지 않는다) · **이미 있음/부분/없음 표 먼저**(D-379) → 없는 훅만 배선 → `verify_onboarding_walk` 가 역할 계정 6종으로 눌러 진행률 N/7 을 낸다. 첫 수는 첫 수다 — 목표를 적지 않는다.
- **P-302 스테이징은 오기 전에 준비한다.** VM 이 오는 날 1시간 안에 서도록 이 턴에 넷: ① 번들(`_fe_dist` + 이미지 태그 표) ② `compose.staging.yml`(운영 프로필 그대로 · 도메인·TLS 자리만 변수) ③ TLS 절차 1쪽(certbot · 80/443 만 · 갱신 cron) ④ `walk_scenarios --base-url https://…` 가 스테이징을 재게. **값은 하나도 넣지 않는다**(도메인·IP·키는 대표가 §5 ④ 로 주는 날).
- **P-303 재부팅 자동화 — 세 조각이 다 있어야 아침이 선다.** ① Windows 작업 스케줄러 04:30 재부팅(명령 1줄 · P-285) ② Docker Desktop 「로그인 시 시작」 ③ **로그인 없이는 Docker Desktop 이 안 뜬다** → 자동 로그인(화면 잠금 유지) 또는 대표 출근 직후 손 로그인. 세종 권고: **자동 로그인 + 즉시 화면 잠금**(게이트 PC · 자료는 볼륨 · 디스크 암호화 유지) — 결정은 대표(§5 ③) · E 가 세 조각의 문안을 보고에 그대로 싣는다.
