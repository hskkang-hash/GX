## ⑦ 못 한 것과 왜

- §3 N 행에 있던 **「OPS-04 회수증 경로 등재」·「승격 12절(P-231)」·「F-11-c2 gate_only
  유지」는 안 했다** — 이번 턴 실제 지시(맨 위 프롬프트 「본 일」)가 P-246 여섯째 부류
  하나로 좁혀져 있었고 "넓히지 마십시오"가 명시돼 있어 그대로 따랐다. 워크오더 §3 표와
  내가 받은 지시가 갈렸다는 뜻이므로 ⑧에도 적는다.
- 「가려진 절 목록」 3건(④)을 **대장에 반영하는 것까지는 안 했다** — "손으로 가르지
  말라"는 지시를 "이 턴엔 기계로 찾기만 하고 옮기는 건 다음 턴"으로 읽었다. 옮기는
  게 맞다면 다음 쪽지로 알려 달라, 바로 할 수 있다.
- Q 의 `verify_readiness_scores.py` 를 **실행해서 확인하지 않았다** — 소유표가
  "다른 판정기는 만지지 마십시오"라 파일도 실행도 건드리지 않았다. 코드를 읽고
  영향을 추론했을 뿐이다(Q.inbox 에 적어 뒀다) — **추론이지 실측이 아니다.**

## ⑧ 틀린 전제

- 워크오더 §3 N 행 텍스트(승격 12절 등)와 내가 실제로 받은 작업 지시 사이에 **범위가
  갈렸다.** 받은 지시를 정본으로 따랐다(이 턴의 "하나만 끝까지" 규약과 일치하는
  쪽이기도 하다) — 조율자가 다르게 보면 알려 달라.
- 애초 가정(암묵적으로 "Q 표도 같은 커밋에서 고친다" P-216 선례)을 **따르지 않기로
  결정했다** — `KIND_SCORE`를 그대로 앨리어스하면 Q 의 자기시험(`len==5`)과 실행
  중 갈림 경보(`aa_kind_score_table`)가 **오늘 밤 조율 없이** 빨개진다는 걸 코드를
  읽고 확인했다(Q.inbox 참고). 재부팅 전 "긴 일을 벌이지 말라"는 규약과 "다른
  판정기는 만지지 말라"는 소유표를 더 우선했다 — 다섯으로 거른 사본을 대신 냈다.
  **이 판단이 틀렸다면** (Q 표를 정말 같은 커밋에서 고쳐야 했다면) 조율자가 되돌릴
  수 있게 정확히 어디를 왜 그렇게 했는지 ②·Q.inbox 에 적어 뒀다.
