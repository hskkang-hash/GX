## 2. ★ 판정기는 부르는 방향이 반대다 (틀리면 뜻 없는 회색)

| 그 파일 안에 | 어디서 부르나 |
|---|---|
| `docker exec` 가 **있다** | **호스트에서** (`python scripts/verify_*.py`) |
| HTTP 를 때린다(127.0.0.1:8000 / :3002) | **`gx-shell` 안에서** |

- 게이트 서버 둘은 **서 있다** [조율자 실측 16:23 · api 8000 · spa 3002].
- ★★ **전량/부분 pytest 정본 호출** — 뿌리가 갈린다:
  ```
  MSYS_NO_PATHCONV=1 docker exec -e DJANGO_SETTINGS_MODULE=config.settings -w /app \
    gx-shell python -m pytest tests/<파일> -k '<좁게>' -q -p no:randomly
  ```
  **`-w /repo` + `backend/tests` 로 부르면 안 된다.** 같은 파일인데 시험이 뿌리를
  `Path(__file__).parents[2]` 로 잡아 `/repo`(얇은 마운트)가 되고, **제품과 무관한 빨강 다섯**이 난다
  [턴 AC 조율자 오판 ④ 실측]. `-w /app` + `tests` 면 뿌리가 `/` 이고 증거가 전부 보인다.
- ORM: `MSYS_NO_PATHCONV=1 docker exec -e DJANGO_SETTINGS_MODULE=config.settings gx-shell python …`
- 호스트 파이썬은 `PYTHONIOENCODING=utf-8`.
- **타입검사는 `-p tsconfig.app.json` 으로만** — 맨 `tsc --noEmit` 은 rc 0 으로 **아무것도 안 잰다**. 기준선 **3234**.
- **`--no-gates` 는 로그인을 못 막는다** — 로그인 0 인 모드는 **`--static` 뿐**.
- 게이트 자격은 저장소 밖 `.env.gates`. **넘길 때는 이름만**. **로그인 IP 당 5회/분 · 계정 바꾸면 61초.**

## 3. 불변 — 이 턴에 특히

1. **지시서도 입력이지 측정이 아니다.** 「지금은 …」 전제는 **코드·번들·화면 세 갈래**로 먼저 댄다.
   턴 AC 에 지시서 전제가 **넷** 틀렸고 전부 차선이 먼저 쟀다. 틀리면 쪽지에 반증을 적는다.
2. **한 그물이 0건을 내면 「없다」가 아니라 「이 그물로는 안 잡힌다」이다.**
3. **거짓 빨강은 거짓 초록만큼 나쁘다** — 없는 병을 쫓게 만든다. 빨강을 적기 전에 **부르는 자리**부터 의심한다.
4. **분모가 줄어 올라간 수는 수가 아니다** · **분모는 손으로 안 적는다** · **분모 0 인 초록은 초록이 아니다**.
5. **누른 뒤를 본 것만 초록** · **회색은 초록이 아니다** · **못 잰 칸은 0 이 아니라 회색**.
6. **재서 빨강은 못 잼과 다른 칸이다**(P-246 · 이 턴 신설).
7. **경보를 끄는 고침과 병을 고치는 고침은 다르다.**
8. **허용 목록으로 눈을 감기지 않는다**(D-350) — 규칙은 두고 **코드 모양**을 바꾼다.
9. **삭제 0.** 이 턴 삭제 결정 0건 — 잔여는 **표식**, 0바이트 덤프는 **`.failed` 이름 바꿈**(P-248 · 오늘은 안 한다).
10. **도구는 자기가 태어난 표본을 시험에 넣는다**(D-310) — 새 판정기·새 게이트 함수에 **「출생 표본」**을 적는다.
11. **게이트는 분모를 말한다**(D-301) · **머리글 세 줄**(P-107)도 `--self-test` 때 찍힌다.
12. **비밀은 이름 · 길이 · sha256 앞 12자까지.** VAPID 실값 0. **`--no-verify` 금지.**
13. **커밋은 조율자만.**
