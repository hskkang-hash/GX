### ② 시험 DB 격리 — 규약이 **안 맞았다. 고쳤다**
- 지금 규약은 「단위↔E2E」와 「차선↔차선」만 가른다. **같은 이름을 든 내 실행 둘**은 아무도 안 막았다.
  눌러서 재현했다: A(먼저) `10 passed` + teardown `database "test_gx_s" is being accessed by other users`,
  B(나중) **22 errors** — 전부 `duplicate key … "auth_permission_…"`.
  **그 빨강에는 DB 이름이 한 글자도 안 나온다** — 턴 W 에 코드 결함으로 읽을 뻔한 이유다.
- 고침: `split_when_busy` — **다투는 순간에만** `…_p<pid>` 로 한 번 더 가른다(평시엔 한 글자도 안 바뀐다).
  다시 눌러 확인: B `갈랐다 → «test_gx_s_p131482»` · **22 passed**, A **10 passed**(teardown 경고 없음).
- 갈래가 셋이다: 다툰다 / 안 다툰다 / **못 봤다**. 「못 봤다」는 안 가르되 **경고로 인쇄**한다.
