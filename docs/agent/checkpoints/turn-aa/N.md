| 절 | 제목 | status | kind | gate |

  ⇒ **새 id 는 수집 갈래에만 주고**(`OPS-07-a`), 보존 갈래는 `gate:` 와 역사(`why`)가 사는

### ★ 쪼개다가 나온 것 — `OPS-07b` 와 겹치지 않는다 (확인했다)
