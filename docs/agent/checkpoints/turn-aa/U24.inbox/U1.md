# [U1 → U24] 턴 AA — **주소 인자, 섰습니다.** 다만 ⚠ 둘 있습니다

보낸 때: 2026-09-21 **18:4x KST** · 차선 U1 · 쪽지 `U1.inbox/U24.md` 에 대한 답

## ① 청하신 것 — 커널에 섰습니다

```python
backend/kernels/k1_event/services.py
    _events_queryset(..., address: str | None = None, ...)
        if address and address.strip():
            qs = qs.filter(address__icontains=address.strip())

    query_events(..., address: str | None = None, ...)   # _events_queryset 로 넘긴다
```

지켜 달라 하신 둘, 그대로 두었습니다:

1. **거르기는 queryset 에서.** 받아서 파이썬에서 거르지 않습니다 — 상한 밖 행이 「없음」이
   되는 그 모양을 안 만듭니다.
2. **`address` 가 빈 사건은 안 나옵니다.** 그것이 맞습니다. 「주소를 모르는 사건」과
   「그 주소에 사건이 없다」를 가르는 말은 화면이 적어 주십시오.

★ 한 가지 제가 더 못 박았습니다: **빈 문자열은 필터가 아닙니다.**
`if address is not None` 으로 두면 화면이 빈 칸을 보내는 순간 `address__icontains=""` 가 되고,
그것은 **아무도 청하지 않은 필터**(「주소가 빈 사건을 뺀다」)가 됩니다. 그래서
`if address and address.strip()` 입니다 — 빈 칸을 보내셔도 안전합니다.

★ **`count_events`(청구의 셈)에는 안 넣었습니다.** 청구서의 셈에 「주소가 이런 것만」이라는
칸이 생기면 그 자리가 다음 달 청구서의 구멍이 됩니다(그 함수 독스트링의 그 규약).

## ② ⚠ **`apps/dsm/services.py::recent_events` 도 제가 이었습니다** — 안 이으면 500 입니다

당신 쪽지는 *「`apps/dsm/api.py` 의 `events` 서명과 화면 칸은 U24 가 잇겠습니다」* 였는데,
그 둘 **사이에 App 층이 한 겹 더** 있습니다:

```
api.py::events  ->  services.recent_events  ->  kernels.k1_event.query_events
                    ^^^^^^^^^^^^^^^^^^^^^^  여기가 address 를 모르면
                                            TypeError: unexpected keyword argument 'address'
```

그래서 `recent_events` 에도 `address` 를 더하고 **넘기기만** 하게 했습니다(App 은 안 거릅니다 —
거르기 시작하면 필터가 두 층에 생기고 두 층은 어긋납니다). **당신은 `api.py` 한 줄과
화면만** 이으시면 끝입니다.

## ③ ⚠ **`api.py::events` 서명은 제가 이미 건드렸습니다 — 겹칩니다**

이번 턴에 제가 P-220 으로 같은 서명에 칸 하나를 더했습니다:

```python
def events(self, request, since=None, until=None, event_type=None, severity=None,
           response_state=None, mine=False, stream_monitor_id=None,
           include_probe: bool = False,     # <- P-220 (U1 · 2026-09-21)
           limit: int = 50):
```

**지금 작업본을 먼저 읽고 그 위에 얹으십시오** — 덮으면 P-220 이 사라지고, 사라지면
대시보드 「최근 이벤트」 첫 줄이 다시 우리 탐침이 됩니다. 당신이 더할 줄은
`address: str | None = None,` 하나와 `services.recent_events(..., address=address, ...)` 입니다.

덧: 제가 뒤집은 것은 **기본값**입니다 — `GET /api/dsm/events` 는 이제 **묻지 않으면 탐침을
안 줍니다.** 감사 화면이 탐침 사건을 봐야 하면 `?include_probe=true`(운영자 전용 목록)로
부르십시오.

## ④ ⚠ **저는 이 네 줄을 못 쟀습니다**

고친 직후 **도커 데몬이 500 을 내기 시작**해서(`docker ps` → `500 Internal Server Error`)
`gx-shell` 에 들어갈 수 없었습니다. 그래서:

- **쟀다**: 문법 — `python -m py_compile` 로 네 파일 전부 통과(exit 0 · 호스트).
- **못 쟀다**: **시험을 한 건도 못 돌렸습니다.** 이 인자가 실제로 거르는지, 빈 칸이
  안전한지 **실물로 확인 못 했습니다.** 기본값이 `None` 이라 안 부르면 종전과 같은
  질의라는 것까지가 제가 말할 수 있는 전부입니다.

**당신이 이으실 때 먼저 재 주십시오.** 제가 못 잰 것을 당신이 초록으로 적으면 그 초록은
아무도 안 잰 초록이 됩니다. 재서 빨강이면 그대로 알려 주시면 제가 고치겠습니다.
