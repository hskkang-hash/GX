## ★★ 쪽지 — 규약이 바뀌었다 (턴 Z 사고 셋)

턴 Z 에 체크포인트가 **세 번 덮였다**(S→N · A→Q · U1→Q). 다섯 차선이 같은 자리를 밟았다.

```
쪽지를 보낼 때:  docs/agent/checkpoints/turn-aa/<받는차선>.inbox/<보낸차선>.md   ← 새로 만든다
제 보고를 쓸 때:  docs/agent/checkpoints/turn-aa/<내차선>.md
```

- **받는 차선은 제 보고 파일만 쓰고 `<내차선>.inbox/` 폴더를 읽는다.** 덮을 파일이 구조적으로 없다.
- **제 파일을 만들자마자 `git add`** 하라 — 스테이지에 한 번도 없던 파일은 되살릴 판이 아예 없다.
- 남의 파일에 쓸 일이 생기면 **덮지 말고 덧붙인다.** 쓰기 전에 **있는지 먼저 본다.**

## 불변 — 이 턴에 새로 서는 것

- **고객 화면에 시험 장치 0** — 탐침·시드가 고객 눈에 보이면 그것은 결함이다
- **정직한 회색을 고객 말로** — 「서버가 404」는 정직하지만 고객 말이 아니다.
  **원인과 다음 손을 같은 줄에.** 실제 값(창구 번호·주소)이 없는 문구는 **비표시**
- **한 차선이 화면과 술어를 둘 다 쥔다**(영역 ①)
- 기존 전부: 초록은 다섯 부류 · 결정문은 배선 · 차선 보고는 입력이지 측정이 아니다 ·
  후보에 색 없음 · 누른 뒤를 본 것만 초록 · 분모 0인 초록은 초록이 아니다 ·
  대장은 줄지 않는다 · 경합 중 수는 수가 아니다 · 내려간 수가 정본 ·
  비밀은 본문으로(**쿼리·argv 에 0** · 넘길 때는 환경 **이름만**)
- 삭제·되돌리기·운영계·`.env` 실제 값·**청구 근거 변경**은 대표

## 차선 Q 가 찾은 것 — **세종의 수 하나가 그 셈법으로는 나올 수 없다**

```
CR = 8칸(각 0 / 0.5 / 1) ÷ 8
세종 산정 = 「8칸 중 **2.2**」
```
**8칸이 {0, 0.5, 1} 이면 합은 언제나 0.5 의 배수다. 2.2 는 나올 수 없다.**
Q 의 산출기가 이것을 **빨강**으로 냈고, 그 파일 출생 표본 ①(「38 은 낼 수 없는 수」)이
**그대로 재발한 것**이다.

⇒ **세종께**: `| CR1 | 가격 숫자 4 | 0 | 근거 |` 여덟 줄만 적으시면 그때부터 산출기가 냅니다.
**8칸 표가 저장소에 없습니다** — §0 은 합만 적고 행이 없습니다.
