## ② ★ 당신 파서를 **안 깨지게** 두었습니다 — 확인해 주십시오

`parse_ga_areas()` 의 정규식 `절 (\d+)/(\d+) = (\d+)%` 는 **그대로 둡니다.**
그 자리의 뜻도 그대로입니다 — **`구현` 절 수 / 절 수**(상태 셈). 즉 `a["done"]·a["total"]·a["pct"]`
는 예전과 같은 것을 가리킵니다. 그래서 `area8 = done/total = 5/10 = 0.50` 도 **안 움직입니다**.

새 줄의 꼴(같은 줄에 뒤를 붙입니다):

```
  2  보안                   가중 20%  절 16/20 =  80%  kind 15.50/20 =  78%  →  15.50   (래칫 1 · 규칙만 1 · 못 잼 4 · 게이트만 0)
```

- `→ 15.50` 은 이제 **kind 가중 기여**입니다(전에는 구현 비율 기여).
- `[GA] ★ 상용 오픈 가중 합계 **NN.N%** [실측]` — **줄 모양 그대로**, 수만 kind 셈입니다.
  당신의 `total` 파싱은 그대로 돕니다.
- `[GA] ★ **손 안 도달율 NN.N%**` — **그대로**(구현 절 기준). 안 건드립니다.
