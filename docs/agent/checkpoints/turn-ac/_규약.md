## 3. ★ 판정기는 부르는 방향이 반대다 (틀리면 뜻 없는 회색이 나온다)

| 그 파일 안에 | 어디서 부르나 | 예 |
|---|---|---|
| `docker exec` 가 **있다** | **호스트에서** | `bash scripts/verify_*.sh` · `python scripts/verify_*.py` |
| HTTP 를 **때린다**(127.0.0.1:8000 / :3002) | **`gx-shell` 안에서** | `docker exec gx-shell sh /repo/scripts/gate_servers.sh …` |

- 게이트 서버 둘은 **이미 서 있다** [조율자 실측 13:22 · api 8000 응답 · spa 3002 200]. 두 번 띄우지 않는다.
- ORM: `MSYS_NO_PATHCONV=1 docker exec -e DJANGO_SETTINGS_MODULE=config.settings gx-shell python …`
- 호스트 파이썬은 `PYTHONIOENCODING=utf-8` 를 붙인다.
- ★★ **타입검사는 `-p tsconfig.app.json` 으로만 잰다.** 맨 `tsc --noEmit` 은 **아무것도 안 재고 rc 0** 을 낸다
  (`/app/tsconfig.json` 은 107바이트 solution 파일). 옳게 부르면 **rc 2 · 3234 줄 = 기준선**.
- ★★ **`--no-gates` 는 로그인을 못 막는다** — 절의 게이트만 끄고 영역 ①의 게이트는 그대로 불러
  `verify_contract_route_reach.py:363` 이 로그인한다. 로그인 0 인 모드는 **`--static` 뿐이다.**
- ★ **`--static` 으로만 재고 「회색」이라 적지 않는다**(턴 AB 조율자 오판 ③). 게이트 부르는 판도 있으면 그것도 잰다.
- 게이트 자격은 저장소 밖 `.env.gates`. **넘길 때는 이름만**: `docker exec -e GX_API -e GX_ROUTE_USER -e GX_ROUTE_PASSWORD`.
  쿼리 문자열에 비밀 0 · 명령줄(argv)에도 0.
- **로그인은 IP 당 5회/분.** 계정을 바꾸면 **61초 기다린다.** 재는 동안 다른 차선은 로그인하지 않는다.

## 4. 불변 — 이 턴에 특히

1. **지시서도 입력이지 측정이 아니다.** §1·§3 의 「지금은 …」 은 **코드·번들·화면 세 갈래**로 먼저 댄다.
   턴 AB 에 지시서 전제가 **여섯 번** 틀렸고 **전부 차선이 먼저 쟀다.** 틀리면 쪽지에 반증을 적는다.
2. **한 그물이 0건을 내면 「없다」가 아니라 「이 그물로는 안 잡힌다」이다.** (조율자가 턴 AB 에 틀린 자리)
3. **분모가 줄어 올라간 수는 수가 아니다**(D-513) · **분모는 손으로 안 적는다** · **분모 0 인 초록은 초록이 아니다**.
4. **누른 뒤를 본 것만 초록** · **회색은 초록이 아니다** · **못 잰 칸은 0 이 아니라 회색**.
5. **조율자는 판정기를 안 고친다**(P-203). 판정기가 틀렸으면 **Q 에게** 쪽지 — 좁게 넓히고 **음성 대조**를 붙인다.
6. **허용 목록으로 눈을 감기지 않는다**(D-350). 규칙이 거짓 양성을 내면 **코드 모양**을 바꾼다.
7. **창과 다른 변경을 섞지 않는다** · **대장은 줄지 않는다** · **경합 중에 잰 수는 수가 아니다**.
8. **삭제 0.** 이 턴 삭제 결정 0건 — 잔여는 **표식**(`mark_unbillable`), 옛 체인 어긋남은 **등재만**.
9. **비밀은 이름 · 길이 · sha256 앞 12자까지.** VAPID 실값은 저장소·`.env*`·보고 어디에도 안 적는다.
10. **`--no-verify` 금지.**
11. **고객 화면에 시험 장치 0**(P-220) · **정직한 회색을 고객 말로**(P-221).
12. **기계로 다시 찍는 것이 사람의 내력을 지우면 안 된다**(`caveat` 보존).
13. **판정기는 고객의 로캘로도 잰다** — 이 턴 Q 가 `ko-KR` 를 기본으로 만든다. 고친 뒤 **색이 움직인 절은 전부** 보고.
