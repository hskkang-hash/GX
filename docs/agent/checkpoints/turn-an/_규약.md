# 턴 AN 차선 공통 규약 (WO-GX-20260929-17 · 조율자 영실)

모든 차선이 **먼저 이 파일을 읽는다.** 정본 지시서: `docs/workorders/WO-GX-20260929-17_턴AN_창2b먼저_반쪽여섯_F3감시원_30절_20260929.md`.

## 절대 금지
- §0.4 금지구역 수정 금지: `backend/delivery/` · `backend/orders/` · `backend/terminals/` · `frontend/src/features/{Delivery,Orders,Terminal}` · rj-core · dj-core · `MapForRoute*` · `FormRoute.tsx` (읽기·호출만).
- 비밀 값 출력 금지 — 이름 · 길이 · sha256 앞 12자까지만. `.env*` 값을 읽어 화면·파일·커밋에 쓰지 않는다. 비밀은 쿼리 문자열·argv 에 싣지 않는다.
- **git commit / push / stash / checkout / reset 금지** — 커밋은 조율자만 한다. 작업본에 파일을 남기고 끝낸다.
- 컨테이너 재시작 · 8500 배포 · DB 삭제 · `ga_readiness.yaml` 수정 금지(대장 이동은 조율자).
- **남의 차선 파일을 고치지 않는다** — 한 파일은 한 차선. 공용 파일(`backend/apps/fws/api.py` · `urls.py` · `frontend/src/App.tsx` · `features/fws/routes.ts` · `features/fws/copy.ts` · `backend/apps/fws/constants.py`)이 필요하면 **고치지 말고** 최종 보고에 「조율자에게: 이 줄을 이 파일에」로 적는다.
- 판정기(`scripts/verify_ga_readiness.py` · `verify_spec_coverage.py` · `measure_onboarding_t.py` · `verify_click_completes.py`)를 고치지 않는다(P-203 · P-399). 예외는 쪽지에 적힌 것만.
- 라이브 서버(8500 · runserver)에 로그인하지 않는다 — 측정은 V 창의 몫.

## 시험
- gx-shell 안에서 **자기 DB 이름**으로: `MSYS_NO_PATHCONV=1 docker exec -e DJANGO_SETTINGS_MODULE=config.settings -e DB_TEST_NAME=<쪽지의 이름> -w /app gx-shell python -m pytest tests/<파일> -q -p no:randomly` (처음 한 번 `--create-db`). 출력이 길면 `sh -c '... > /tmp/<이름>.log 2>&1; grep -aE "passed|failed" /tmp/<이름>.log | tail -2'`.
- 전량 시험은 돌리지 않는다(조율자 몫). 자기 시험 + 인접 시험만.
- 동시 `docker exec` 을 여러 개 띄우지 않는다(엔진 상한) — 한 번에 하나.
- Bash 도구는 heredoc 안의 이중 백슬래시를 벗긴다 — 코드는 Write/Edit 도구로 쓴다.

## 코드 규칙(이 저장소가 게이트로 막는 것)
- F-05 잠금: `kernels.k1_event` 는 `backend/apps/dsm/services.py` 만 import 한다 — 다른 앱은 `apps.dsm.services` 를 거친다.
- D-278: 앱은 커널의 공개 면만 import 한다(`kernels.<k>.services` 등 공개 모듈 · 비공개 `_x` 금지).
- 새 라우트마다 `@tenant_scoped(reason="...")` + `auth=JwtOrInboundKey()` (ISO-03). 익명 문 새로 열지 않는다(ratchet 73).
- 새 `/api/dsm/` 라우트는 `backend/tests/test_f05_event_api.py` 의 `EVENT_ENTRY_SURFACE` 에 올라야 한다 → 그 파일은 조율자 몫이니 보고에 줄을 적는다.
- 동음이의 게이트: `api_key` 단독 금지 → `inbound_api_key` / `outbound_api_key`.
- 화면 문구는 한국어 · 개발 용어·절 번호(`D-123`·`P-123`)·영문 라벨을 화면에 내지 않는다(셋째 조건). 문구는 차선 소유 copy 파일에.
- 새 모델(표)은 차선당 ≤ 1 · 마이그레이션 번호는 `backend/apps/<app>/migrations/` 의 최신 다음 번호 · 다른 차선과 겹치면 조율자가 병합 때 번호를 조정한다.

## 별표 절 승격(P-356 넷 · P-392 · WO-17)
절 하나를 「닫았다」고 적으려면 넷이 다 있어야 한다:
1. **구현** — 엔드포인트(+ 필요하면 화면)가 명세 제목이 부르는 것을 한다.
2. **증거** — `docs/agent/evidence/SPEC/<ID>.json` (시험이 HTTP 로 실제로 두드린 기록 · 기존 파일 모양을 따른다 · 예 `FWS-F6-01.json`).
   증거 안에 **「제목이 부르는 것 ↔ 있는 것」 표**(`title_parts: [{part, where, status}]` 모양 · 빈 칸 0)가 있어야 한다 — O 게이트가 빈 칸을 센다.
3. **게이트 1행** — 자기 차선의 `scripts/verify_spec_<...>.py` 에 그 절의 행(기존 `verify_spec_fws_f6.py` 모양 · 기본 `--no-run`).
4. **대장 이동 제안** — `docs/agent/evidence/SPEC/<차선>_promotions_an.md` 에 절 번호·증거·게이트 행. 대장 이동은 조율자가 한다.
**반쪽은 닫힘이 아니다.** 제목의 일부가 없으면 올리지 말고 「무엇이 없는가」 1줄.
