## §1 ★★ 모든 차선에 걸리는 다섯 줄 — 어기면 그 차선의 수는 수가 아니다

1. **차선은 브라우저를 재지 않는다.** 로그인은 IP 당 5회/분이고 계정마다 세션이 하나다.
   다섯이 동시에 누르면 서로의 수를 망친다. **차선은 코드와 단위시험까지** 하고,
   「누른 뒤」는 **조율자/V 가 한 창에서 한 번에** 잰다. 브라우저가 필요한 닫는 조건은
   **「조율자가 누를 수 있게 준비됐다」**로 바꿔 읽는다(무엇을 · 어느 계정으로 · 어디를
   누르면 되는지 쪽지에 적어라).
2. **한 파일은 한 차선.** §2 소유표 밖의 파일은 **읽기·호출만.** 남의 파일을 고쳐야
   하면 고치지 말고 **쪽지**(`<받는차선>.inbox/<보낸차선>.md`)를 써라.
3. **§0.4 금지구역 수정 금지** — `backend/delivery/` · `backend/orders/` ·
   `backend/terminals/` · `frontend/src/features/{Delivery,Orders,Terminal}` ·
   `rj-core` · `dj-core` · `MapForRoute*` · `FormRoute.tsx` (읽기·호출만).
4. **비밀은 이름으로만.** 값을 출력·커밋·쿼리문자열·argv 에 **0**. 있는지 볼 때는
   길이와 sha256 앞 12자까지. ⚠ **`docker exec -e 이름` 은 호스트에 그 이름이 없으면
   컨테이너의 값을 빈 값으로 덮는다** — 넘기기 전에 호스트에 있는지 보고, 없으면 안 넘긴다
   (조율자가 어제 이 자리에서 두 번 물렸다).
5. **회색은 회색으로.** 못 잰 것을 초록으로 적지 않는다. 「혼자 재면 통과」를
   「고쳤다」로 적지 않는다 — **음성 대조**가 있어야 고친 것이다.
   그리고 **반만 하고 받는 초록은 초록이 아니다**(조율자가 오늘 아침 그래서 파일 하나를
   안 놓았다 · `evidence/OPS-19/자동덤프_첫건_20260923.md` §⑥).

### ★ 전량 시험 정본 호출 — 이것 말고 다른 모양으로 부르지 마라
```
MSYS_NO_PATHCONV=1 docker exec -e DJANGO_SETTINGS_MODULE=config.settings \
  -w /app gx-shell python -m pytest tests -q --create-db -p no:randomly
```
`-w /repo` + `backend/tests` 로 부르면 **뿌리가 갈려 거짓 실패 다섯**이 난다.

### ★★ 머리글은 **늙는다** — 오늘 세 번 걸렸다 [턴 AE 신설 불변]
파일 머리의 안내문은 **쓴 날의 사실**이고, 코드는 **오늘의 사실**이다. 둘이 갈리면
**코드가 이긴다.** 오늘 걸린 셋:
- `verify_seed_p20.py` 머리글 「호스트에서 `docker exec` 로 위임한다」 — **위임 코드 0건**
  (조율자 · 09-22)
- `scripts/seed_role_users.py` 머리글 「무인증 HTTP」 — D-343 이 그 사이 인증을 붙였다.
  차선 U56 이 그대로 믿고 시작했다가 401 로 막혔다(09-23)
- `scripts/measure_onboarding_t.py` 의 자격 — `.env.gates` 에 **있는데** 조율자가 안 넘겨
  U6 네 행이 회색이 되고 정본 수가 2.5 내려갔다(09-22)
⇒ **부르기 전에 그 파일의 코드를 본다.** 특히 ① 부르는 자리 ② 필요한 환경 이름
③ 인증 전제 — 이 셋은 머리글이 아니라 코드로 확인한다.

### ★ 판정기는 부르는 방향이 반대다
파일 안에 `docker exec` 가 **코드로** 있으면 → **호스트에서** 부른다.
파일이 HTTP(127.0.0.1:8000 · 3002)를 때리면 → **gx-shell 안에서** 부른다.
⚠ **머리글의 안내문을 믿지 마라 — 코드를 봐라.** `verify_seed_p20.py` 는 머리글에
「호스트에서 위임한다」고 적어 두고 위임 코드가 **없다**(K+Q 가 오늘 고친다).
