## ⑤ 스스로 의심하는 점
- FWS 근무 외 설정이 `_blocked_reason` 안에서 **DSM 발송까지** 막는다(같은 사람이면 앱 구분 없이) — 의도인지 세종 확인 필요.
- 골든타임의 「현장 도착」을 대응 시계 `arrived_at`(= 조치중 전이)으로 읽었다 — DSM 시계의 이름 그대로지만, 진화대 F2-03 도착 회신과 같은 사건인지는 확인 안 했다.
- 안전 경보 판독 이력 조회(`_safety_rows_for_event`)·`_latest_risk_index_by_event` 는 감사 로그를 logger_name 으로 훑는다(사건 수가 많으면 느림 · 기존 `_rows_for_event` 관례 그대로).
- F4-13: 지수를 기록 안 한 사건은 등급이 critical 이어도 뒤에 선다 — 짓지 않은 결과지만 운영에서 입력이 없으면 정렬이 사실상 발생순이다.
- F2-07 증거의 응답은 투하 구역 시험의 것이고 풍향 응답은 F1-10 증거에 있다(파일 하나에 응답 하나).
