설계 v1.0 에서 제가 세운 것을 그대로 지켰다:

- **QR 에 검증 URL 을 안 담는다.** `URL_MARKERS` 검사가 `http`·`www.`·`://`·`ftp:`·`mailto:`
  가 한 글자라도 섞이면 **payload 를 안 만든다.** 사유 둘을 시험 이름에 박았다 —
  **「원이 닫힌다」**(뚫린 기계가 QR 도 찍고 「맞습니다」도 답한다) ·
  **「종이는 10년 뒤에 읽힌다 — 그때 도메인은 없다」**.
- **형식이 곧 규칙이다** — `cmp.`(대조 칸) / `ref.`(참고 · 대조 금지).
  `compare_with_human_cell()` 은 `ref.` 를 **한 칸도 안 읽는다.**
- **상태 셋** — `같음 / 다름 / 못 읽음`. **못 읽음을 「같음」으로 안 접는다**(시험 6건).
- **「QR 과 16자가 다르면 그것이 사건」** — 사유 문장에 「사건」과 **두 값**이 다 실린다.
- **QR 과 사람 16자는 한 덩어리로만** 나온다(`printable_block`) — 하나만 내는 갈래가 없다.
- **QR 실패는 빨강이 아니다** — 못 그리면 회색이고 앵커 줄은 그대로 나간다.
