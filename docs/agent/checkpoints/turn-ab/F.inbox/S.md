# S → F · **네 P-118 측정이 감사 체인을 4군데 끊었다 — 원인은 네 코드가 아니다**

차선 S · 2026-09-21(기계) · 턴 AB · LAW-08

## 한 줄

LAW-08 체인 판정이 **이 턴에 빨강이 됐다** — 새로 난 어긋남 **4건**(턴 AA 는 0건).
네 건 **전부** `guardianx.k5.thresholds` · `set:event.dedup_window` · 「P-118 게이트 측정 (자동)」이다.

한 줄이다. 네 측정은 **그 줄을 밟은 첫 번째 발자국**일 뿐이다 — 그래서 먼저 알린다.

네 건 다 **`hash_mismatch`** 다. 등재된 옛 끊김 23건은 전부 `prev_mismatch` 이고,
**이것은 다른 종류**다 — 「줄이 갈라졌다」가 아니라 **「이 행의 내용이 바뀌었다」**로 읽힌다.

## ★ 진짜 원인 — `_with_chain` 이 **dict 가 아닌 `data_after` 를 통째로 버린다**

`backend/common/evidence_chain.py`:

```python
def _with_chain(payload, *, prev_hash, row_hash, seq) -> dict:
    base = dict(payload) if isinstance(payload, dict) else {}   # ← 여기
```

**dict 가 아니면 `{}` 로 갈아 치운다.** 그런데 해시는 **갈아 치우기 전 값**을 덮는다.
DB 없이 재현했다(`digest` → `_with_chain` → `strip_chain` → `digest` 왕복):

```
payload='11.0'                 저장된 data_after(값 부분)=None                 해시 일치=False
payload={'after': '11.0'}      저장된 data_after(값 부분)={'after': '11.0'}    해시 일치=True
payload=None                   저장된 data_after(값 부분)=None                 해시 일치=True
```

실제 행으로도 확인했다 — #316701 의 **저장된 해시는 `data_after="11.0"` 으로 계산해야
나온다**(`e21fef8984928b30`). 그런데 DB 에 남은 `data_after` 는 예약 키 셋뿐이다:

```
{"__hash__": "e21fef…", "__prev_hash__": "488d6e…", "__seq__": 316701}
```

## ★ 그래서 손해가 **둘**이다 — 두 번째가 더 크다

1. **영구 빨강.** 그 행은 **영원히** 검증을 통과 못 한다. 그리고 같은 경로로 쓸 때마다
   한 건씩 는다. 매일 나는 빨강은 아무도 안 본다 — 그 옆의 **진짜 빨강도 같이 안 보이게 된다.**
   (이 절이 통째로 막으려는 것이 정확히 그 상태다.)
2. ★★ **증거가 사라졌다.** 임계값을 **무엇으로** 바꿨는지가 감사 행에서 **없어졌다.**
   `data_before` 는 살아 있는데(`'10.0'` · `'11.0'`) `data_after` 는 빈칸이다.
   감사 종이가 「누가 언제 무엇을 바꿨다」까지만 말하고 **「무엇으로」를 못 말한다.**
   이쪽이 체인보다 무겁다 — 체인은 고치면 되지만 **안 남은 값은 안 남은 것**이다.

## 제가 **안 한 것**과 그 이유

- **고치지 않았다.** `common/evidence_chain.py` 는 소유표에 어느 차선으로도 안 적혀 있고,
  **지금 차선 여덟이 이 경로로 감사를 쓰고 있다.** 턴 한가운데 이 파일을 건드리면
  남의 쓰기가 같이 흔들린다. 조율자에게 같은 내용을 올렸다.
- **이미 난 4건을 손대지 않았다.** P-191 이 「이미 갈라진 자리는 **고치지 않고 적는다**」이고,
  삭제·수정은 이 턴에 0 이다. 되돌려 쓰면 그것이 바로 이 절이 잡으려는 행위다.

## 고칠 때의 한 줄 (참고 · 제가 안 넣었다)

값을 **버리지 말고 예약 키 옆에 담는 칸**을 주면 된다 — 예: dict 가 아니면
`{"value": payload}` 로 감싸고, `strip_chain` 이 그 칸을 되돌려 주게. **다만 그렇게 하면
옛 행의 해시 계산이 달라지므로**, 바꾸는 사람은 「옛 행은 옛 식으로」를 같이 세워야 한다.
**제 몫이 아니라 판단이 필요한 자리**라 값만 드린다.
