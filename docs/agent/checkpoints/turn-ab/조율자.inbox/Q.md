```
때  : 턴 AB 초반 (docker 장애 이전)
무엇: PYTHONIOENCODING=utf-8 python scripts/verify_readiness_scores.py --aa

      → SERIAL_GATES 8종이 돌았고 그중 verify_contract_route_reach 가 로그인한다
```

**N 이 세 번 로그인한 그 자리를 나도 밟았다.** 내 창에는 로그인이 0이어야 했다.
고쳤다 — `run_ga()` 가 이제 **`--static`** 으로 부른다(`GA_STATIC_ARGS`). 사유를 소스에 박았고,
`verify_spec_coverage.py` 도 처음부터 `--static` 이다.
★ **`--no-gates` 로는 못 막는다**는 N 의 실측을 코드 주석에 그대로 옮겨 적었다.

⚠ **그 실행에서 나온 수는 버려라** — 그리고 docker 장애 창과 겹쳤을 수 있다.
아래 ②의 수는 **장애 복구 뒤**(12:0x UTC) `--static` 으로 다시 잰 것이다.

## ② CR — **네 판정대로다. 산출기가 1.5/8 = 18.8 % 를 낸다**

`parse_aa_cr8` 이 **두 모양을 다 읽게** 고쳤다. 그러지 않으면 N 의 전사본에서 **0행**이 나왔다
(N 의 표는 `| ① | CR1 가격 숫자 4 | 술어 | **없다** — 값 0 | 근거 |` 라 CR 표식이 **둘째 칸**이다).
지금은 셋을 다 열고 대조한다:

```
WO-04 §4-1 (세종 정본)  행 8 · 칸의 합 1.5 · 표가 적은 합 2.0
N 전사 GX-CR_8칸_v1.0   행 8 · 칸의 합 1.5 · 합 줄 없음        ← 값이 **같다**
GX-REVIEW v2.0          표 없음(합 2.2 만) — 폐기된 수(P-232)
```

산출기가 내는 빨강 **한 줄**(이것을 §8 에 올려 달라):

> ★★ **표의 합이 제 행과 갈렸다** — §4-1 이 적은 합 **2.0/8**, 여덟 행을 더하면 **1.5/8**(−0.5).
> **행이 정본이다.** CR 은 25.0 % 가 아니라 **18.8 %** 다.

**0.5 짜리 칸을 지어내지 않았다.** 세종께 청할 것: 「**반인 칸이 하나 더 있는가**」 — 값을 정할 자리는 세종이다.
★ CR 은 **회색[0/8] → 잰 칸 8/8 · 회색 0** 으로 올라갔다. 수는 25 → **18.8** 로 내려간다.

## ③ ★★ **기능명세 id 는 있다 — 너와 N 의 실측이 서로를 확인했지만 둘 다 못 찾았다**

이것만은 다르게 재라고 청한다. 기계로 대 봤다:

```
그물 `DSM-01`         → 0건        ← 조율자·N 이 던진 그물
그물 `DSM-U\d+-\d+`    → **32건**   ← 실재 표식은 `DSM-U1-01`
그물 `FWS-[FU]\d+-\d+` → **90건**   ← 세종의 「FWS 90」과 **한 자도 안 틀린다**
그물 `O-\d{2}`         → **14건**   ← 세종 판독 12 · 실물 `O-01`~`O-14`
```

**473 과 136 은 갈린 한 수가 아니라 다른 것을 센 두 수다.**
473 = 세 문서의 **모든** 표 데이터행(§5 업무처리명세 · §6~§9 화면구성도 · 매핑표까지).
136 = 「**사용자별 세부 기능명세**」 절의 항목만. 지시서의 분모(대장 절 + 기능명세)는 후자다.

⇒ 회색으로 내지 않았다. **규칙을 소스에 적고 기계가 뽑았다** — `docs/agent/evidence/P-234/spec_ids.json`.
세는 규칙 전문은 `N.inbox/Q.md` 에 보냈다(`annex_2_spec` 의 `rule`·`source` 에 넣을 문구 포함).

★ 그리고 **분모가 늘었다: 134 → 136.** 「운영자 콘솔 12」가 실물 14 였다. **내려간 수가 정본이다.**

## ④ 「MEASURED 없는 초록은 턴 AC 부터 빨강」을 **배선했다** (P-217)

턴 AA 에 문서에만 적은 그 기한을 `docs/agent/decisions.yaml` 의 **D-511** 로 세웠다:

```yaml
- id: D-511
  deadline: "2026-09-23"      # 턴 AC 첫날
  escalates_to: red
  enforced_by: _gate_header.escalation → verify_gate_header.MEASURED_LINE
```

`verify_gate_header` 가 **그 파일을 읽어서** 오늘과 댄다 — 날짜는 코드에 없다.
그날이 오면 **사람이 코드를 안 고쳐도** 회색이 빨강이 된다. 결정문을 지우면 꺼지는 것이 아니라
「**결정문을 못 읽었다**」고 말한다. 세 갈래(기한 전·후·못 읽음) 전부 자기시험에 있다.

⚠ **기한을 09-22 가 아니라 09-23 으로 잡았다** — 턴 AB 가 09-22 이므로(WO §6). 다르면 결정문의
`deadline:` 한 줄만 고치면 된다(코드는 안 고친다).
