# S → 조율자 · **도커 엔진이 죽었고, 조율자가 되살렸다 — 그 사이 게이트 서버 둘이 끊겼다**

차선 S · 2026-09-21(기계) · 턴 AB · **읽는 즉시 처리할 것**

## ★ 한 줄 — 제가 재기동한 것이 **아니다**

**2026-09-21T12:00:43Z (= 21:00:43 KST)** 에 **컨테이너 10개가 전부 다시 떴다.**
저는 `docker restart` · `docker compose` · `docker stop` 을 **한 번도 안 불렀다.**
제가 부른 것은 `docker exec` · `docker ps` · `docker inspect` 셋뿐이다.

## 무슨 일이 있었나 — 시각 순서

| 호스트 시각(KST) | 무엇 |
|---|---|
| ~20:5x | `docker exec` 가 갑자기 `500 Internal Server Error … dockerDesktopLinuxEngine/v1.54` 를 내기 시작 |
| 20:5x~21:00 | `docker ps` 조차 같은 500. 8번 연속 실패(제 시험 실행 하나가 통째로 회색이 됐다) |
| **21:00:43** | **조율자가 `docker desktop restart` 를 불렀다**(차선 K 신고 → 조율자 확인 뒤). 컨테이너 10개 전부 `StartedAt` 이 이 시각으로 새로 찍힘 |
| 21:00:56 | `docker ps` 정상. `RestartCount=0` · `Created` 는 그대로(4일 전) → **컨테이너를 새로 만든 것이 아니라 엔진이 다시 띄운 것** |

Docker Desktop 엔진 버전 `29.3.1`.

> ★ **[조율자 정정 · 받아 적는다]** 처음에 저는 이것을 「엔진이 **스스로** 돌아왔다」로
> 적었다. **틀렸다.** 되살린 것은 **조율자**다 — 차선 K 가 먼저 신고했고, 조율자가
> 확인한 뒤 `docker desktop restart` 를 불렀다. 제 관측(`RestartCount=0` · `Created` 는
> 4일 전 그대로)은 정확히 **그 한 줄의 결과**를 본 것이었다.
>
> **둘 다 참이다**: 제가 재기동하지 않았다는 것도, 조율자가 재기동했다는 것도.
> 제가 못 본 것은 **원인**이고, 못 본 것을 「스스로」로 메우면 그것은 추측이다.
> 기록이 한 턴만 지나면 **원인 없는 사고**로 굳는다 — 그래서 결론 줄을 고쳐 적는다.

## 그때 끊겨 있던 것 — **게이트 서버 둘** (지금은 조율자가 다시 세웠다)

21:00 직후 `gx-shell` 안에서 잰 것:

- **3002 정적 SPA — 프로세스가 아예 없다.** `http.server`/`SimpleHTTP` 가 `ps` 에 0건.
- **8000 runserver — 프로세스(pid 60)는 있는데 TCP 는 `ConnectionRefused`** (잰 순간 기준).
  컨테이너 기동과 함께 다시 뜬 것으로 보이나, **뜬 것과 답하는 것은 다르다.**

즉 **「게이트 서버 둘은 이미 살아 있다」는 턴 머리의 전제가 21:00 부로 한동안 깨져 있었다.**

> ★ **[조율자 정정 · 받아 적는다]** 제가 잰 **뒤에** 조율자가 `gate_servers.sh start` 로
> 둘을 다시 세웠다 — `api 8000 pid 60`(12:01:05Z) · `spa 3002 pid 163`(12:01:27Z).
> 제가 「프로세스 0건」으로 본 3002 가 바로 그 자리다. **제 관측은 그 사이의 30초를 본 것**이고,
> 지금은 둘 다 대답한다. 저는 3002 를 **스스로 올리지 않았다.**
이 시각 이후 **HTTP 를 때리는 판정기**(`gate_servers.sh` · `verify_ui_secrets.py --api` ·
`measure_onboarding_t.py` · `verify_route_alive.py`)가 내는 빨강·회색은
**제품의 색이 아니라 이 사고의 색**이다. 턴 AA 의 N 보고 §「09:13 이후」와 같은 모양이다.

## 제가 하지 않은 것

- **서버를 다시 띄우지 않았다.** 3002 를 제가 올리면 남의 창을 제가 정하게 된다 —
  규약대로 **조율자 허락 뒤**다. 필요하시면 제가 올린다(명령 한 줄만 주시면 된다).
- 로그인 0회. 이 턴에 HTTP 자격을 **한 번도** 안 썼다.

## 다른 차선에 알릴 것 두 가지

1. **21:00:43 이전에 잰 HTTP 수치는 다른 서버 판이다.** 같은 절을 앞뒤로 잰 차선이 있으면
   두 수가 갈릴 수 있고, 갈리면 **나중 수가 정본**이다(경합 중에 잰 수는 수가 아니다).
2. **시험 DB 를 쓰던 실행이 중간에 끊겼다.** 제 `test_gx_s` 는 지우고 다시 만들었지만,
   다른 차선의 `test_gx_*` 가 남아 있으면 다음 실행이 「이미 있다」로 멎는다.
