## 판정기 부르는 방향 (틀리면 뜻 없는 회색)

| 어디서 | 무엇 |
|---|---|
| **호스트에서** (소스에 `docker exec` 가 있는 것) | `verify_evidence_chain.py --db` · `verify_route_alive.py` · `verify_ga_readiness.py` |
| **gx-shell 안에서** (HTTP 를 때리는 것) | `gate_servers.sh` · `verify_ui_secrets.py --api` · `measure_onboarding_t.py` |

- 호스트 python: `PYTHONIOENCODING=utf-8` · 컨테이너: `MSYS_NO_PATHCONV=1`
- ORM: `MSYS_NO_PATHCONV=1 docker exec -e DJANGO_SETTINGS_MODULE=config.settings gx-shell python …`
- 게이트 자격: 저장소 뿌리 `.env.gates` (`set -a; . ./.env.gates; set +a`)
- **`docs/agent/verify_gates.sh --all` 은 없다** · 없는 게이트 이름을 주면 rc 2 회색
- **3002 은 API 가 아니다** — 정적 SPA(`SimpleHTTP/0.6`) · POST 에 501
- 프런트 타입검사는 **`gx-fe-build` 안에서만** — `docker cp <디렉터리> <있는 디렉터리>` 는 **안에 넣는다**(먼저 지운다)
