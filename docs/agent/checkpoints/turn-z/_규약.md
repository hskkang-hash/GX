## 이 턴에 새로 서는 불변

- **수를 움직이는 일은 상태를 바꾸는 일이다** — 증거를 채우는 것이 아니다
- **초록은 다섯 부류다** — `closed · ratchet · rule_only · unmeasurable · gate_only` · 어느 것인지 적는다
- **결정문은 배선이다** — `enforced_by` 없는 결정은 커밋되지 않는다
- **차선의 보고는 입력이지 측정이 아니다** — 보고에 `[차선 보고]` / `[조율자 실측]` 을 가른다
- **후보를 줄 때 색을 적지 않는다**
- **쪽지는 받는 차선 파일에 쓴다** — 보낸 차선 파일에 쓰지 않는다 (턴 Y 오배송 4통)
- 비밀은 본문으로 — **쿼리·argv 에 0** · 넘길 때는 환경 **이름만**
- 조율자는 판정기를 고치지 않는다 · `exit 0` 은 「이 호출이 통과」 · 회색은 초록이 아니다
- 대장은 줄지 않는다 · 분모 0인 초록은 초록이 아니다 · 누른 뒤를 본 것만 초록

## ★ 규약 결함 — 「쪽지는 받는 차선 파일에」가 **첫 턴에 사고를 냈다** [조율자 2026-09-21]

턴 Y 의 오배송 4통(보낸 차선 파일에 써서 받는 쪽이 못 봄)을 고치려 세운 규약인데,
**반대쪽 사고가 났다**: 받는 차선이 제 보고를 **같은 경로에 저장하면서 쪽지를 덮었다.**

| 언제 | 무슨 일 |
|---|---|
| S → `N.md` | N 이 제 체크포인트를 저장해 **쪽지가 사라졌다.** S 가 덧붙이기로 되살림(331행 무손상 → 379행) |
| A → `Q.md` · U3 → `Q.md` | 나중에 쓴 쪽이 앞사람을 덮음. U3 가 A 의 340행을 지우지 않고 뒤에 다시 붙임(→ 485행) |
| Q → `N.md` | N 보고: 「Q 의 쪽지는 **없었다**」 — N 이 읽은 시점에 아직 안 왔다 |

**뿌리 둘**: ① 받는 차선이 같은 파일을 **쓴다**(읽기만 하는 것이 아니다)
② 보내는 차선이 여럿인데 파일이 하나다 (`N.md` 의 보내는 쪽은 **다섯**: Q·S·F·U1·U56).

★ **다음 턴 규약** — 쪽지는 **보내는 쪽 이름이 든 제 파일**에 쓴다:
```
docs/agent/checkpoints/turn-<턴>/쪽지/<받는차선>_from_<보낸차선>.md
```
받는 차선은 제 보고 파일만 쓰고, **`쪽지/` 폴더를 읽는다.** 덮을 파일이 없다.
「받는 차선 파일에 쓴다」는 **받는 차선이 보는 자리에 쓴다**는 뜻이었지 같은 파일이 아니었다.
