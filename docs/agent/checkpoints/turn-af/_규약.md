## §1 모든 차선에 걸리는 여섯 줄

1. **차선은 브라우저를 재지 않는다.** 로그인 IP 당 5회/분 · 계정당 세션 1.
   「누른 뒤」는 **조율자가 한 창에서** 잰다. 브라우저가 필요한 닫는 조건은
   「조율자가 누를 수 있게 준비됐다」로 읽고, **계정 · 주소 · 무엇이 보이면 초록**을 쪽지에 적어라.
2. **한 파일은 한 차선.** §2 밖은 읽기·호출만. 필요하면 쪽지.
3. **§0.4 금지구역** 수정 금지 — `backend/delivery/` · `backend/orders/` · `backend/terminals/` ·
   `frontend/src/features/{Delivery,Orders,Terminal}` · `rj-core` · `dj-core` ·
   `MapForRoute*` · `FormRoute.tsx`.
4. **비밀은 이름으로만** · 값 출력·커밋·argv·쿼리에 0. ⚠ `docker exec -e 이름` 은
   호스트에 그 이름이 없으면 **컨테이너 값을 빈 값으로 덮는다**(A/B 실측 · 길이 20→0).
5. **회색은 회색으로.** 못 잰 것을 초록으로 적지 않는다. **분모 0 인 초록은 초록이 아니다.**
   「혼자 재면 통과」를 「고쳤다」로 적지 않는다 — **음성 대조**가 있어야 고친 것이다.
6. ★★ **게이트를 고치면 그 게이트가 걸린 절을 전부 다시 읽는다**(턴 AE 신설).
   자기시험이 통과하는 것과 **그 게이트가 세상을 옳게 말하는 것**은 다른 일이다.

### ★★ 추측한 낱말이 **거짓 빨강**을 만든다 — 어제 조율자가 세 번 밟았다
- 화면의 낱말은 **사전에서 읽는다**: 등급은 `frontend/src/features/dsm/severity.ts:22`
  — **심각 · 경계 · 주의**(「경고·정보」가 아니다).
- 확인창 단추는 `Modal.confirm` 의 **`okText`** 다 — 「확인」이 아닐 수 있다
  (등급 재판정은 okText 가 **「등급 재판정」**이다).
- **머리글은 늙는다**: 부르는 자리 · 환경 이름 · 인증 전제 셋은 **코드로** 확인한다.
- `| tail` 뒤에서 읽은 종료 코드는 **언제나 `tail` 의 것**이다 — `${PIPESTATUS[0]}` 나 파일로.

### ★ 전량 시험 정본 호출
```
MSYS_NO_PATHCONV=1 docker exec -e DJANGO_SETTINGS_MODULE=config.settings \
  -w /app gx-shell python -m pytest tests -q --create-db -p no:randomly
```
`-w /repo` + `backend/tests` 로 부르면 **뿌리가 갈려 거짓 실패 다섯**이 난다.

### ★ 판정기 부르는 방향
코드에 `docker exec` 가 있으면 → **호스트에서**. HTTP·ORM 을 직접 쓰면 → **gx-shell 안 `-w /app`**.
