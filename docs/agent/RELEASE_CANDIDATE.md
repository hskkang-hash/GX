## 0. 한 문장 — **'완주' 가 아니다**

> **릴리스 후보(SDN 제외판)의 범위 안에서는 끊긴 단계가 없다.**

이 문장을 "완주" 로 줄여 적지 않는다(D-302). 잠긴 칸은 실패가 아니고 통과도 아니다 —
**잴 수 없는 것**이고, 잴 수 없다는 사실 자체가 이 문서가 전하는 내용의 절반이다.

## 1-1. 잠금 유형별 건수 (D-307) — **오늘 무엇을 하면 몇 개가 풀리는가**

```
[BLOCKER] 검사 5건 · 유형별: DEV 3 · CONTRACT 1 · ADMIN 1   (2026-09-06 갱신)
[BLOCKER] ★ **지금 막고 있는 것 4건** · 남겨 두었으나 막고 있지 않은 것 1건 (총 5건)

★ D-323 — 잠김 총수와 **지금 막고 있는 수**는 다른 수다. 술어가 「끝났는가」가 아니라
  **「지금 이 환경에서 막혀 있는가」**(`blocked_now`)로 바뀌었고, 게이트가 둘을 따로 낸다.

  CONTRACT  SDN_API_SPEC        → 에스비정보기술   **발송 완료** · 기한 2026-09-19
                                  (게이트가 매 실행마다 대기·지연 일수를 출력한다 · D-320)
  ADMIN     JUSO_API_KEY        → 대표   **blocked_now: false** (D-332)
                                  ★ 사유가 통째로 바뀌었다: 키는 왔고(파일로),
                                    그 키로 FX-5 는 **못 한다**(팝업 API · D-329).
                                    그리고 FX-5 자체가 카메라 설치 주소로 대체됐다(D-330).
                                    남은 용처는 주소 입력 팝업이고 **지금 막고 있지 않다**.
                                    없앤 것과 미룬 것은 다르므로 **지우지 않는다**.
  DEV       F03_POLYGON_DESIGN  → Code (설계 확정 후)
  DEV       CLIP_EXTRACTION     → Code
  DEV       MIGRATE_ONE_LINER   → dj-core 담당 (§0.4 로 우리가 못 고친다)
  ── 하차: CCTV_SERVICE_NAME (D-321) — 신청 불필요로 판정. **이름의 유사성을 기능의
     필요성으로 읽은 것**이었다. 국립공원·아동센터도 같다
```

**DEV 는 일정 문제, CONTRACT 는 책임 문제, ADMIN 은 하루면 풀리는데 안 한 것**이다.
섞어 두면 하루짜리가 계약 리스크 뒤에 숨는다 — 그래서 유형을 칸으로 만들었다.
재현: `python scripts/verify_blockers.py --summary`

## 1-2. 계약 AC 전수 (D-309) — **우리가 무엇을 모르는가**

```
[AC] 검사 14행 · **절 39개** · 증명 시험 66건        (2026-09-06 · D-325 표 ① 반영)
[AC] 절 상태: 구현 27 · 미착수 4 · 잠김 8 · 미측정 0
[AC] ★ **잔여 12절 / 전체 39절 (구현 69%)** — 이제 잔여가 숫자다

★ 표 ①(임계값)이 두 절을 함께 올렸다 — F-02 「지점별 기준선 설정」 · F-12 「임계값」.
  절 분해가 없었으면 둘이 **같은 뿌리**라는 것이 보이지 않았다(D-325).
★ 그러나 표 ②(자격증명)는 **F-05·F-12 의 API키 절을 갚지 못했다** — 방향이 반대였다.
  표 ②는 **나가는** 키(우리가 남의 API 를 부를 때), FR-05-3 은 **들어오는** 키
  (남이 우리 OpenAPI 를 부를 때)다. 둘 다 "API Key" 라 불려서 같은 것으로 읽혔다.
  지시서 예상은 잔여 10절이었고 **실측은 12절**이다.

★ '부분' 이라는 칸을 없앴다(D-314). '부분' 은 상태가 아니라 **아직 안 쪼갠 것의 이름**
이고, 그것이 남아 있는 한 5건이 95% 인지 20% 인지 표가 말하지 못한다.
```

증명 시험이 없는 절은 '구현' 으로 적지 않는다 — 그런 절은 **'미측정'** 이다.
재현: `python scripts/verify_contract_ac.py --table`

재현: `python scripts/verify_release_candidate.py` (exit 0)

★ 이 판정기는 **증거가 없으면 통과가 아니라 exit 1** 한다. 증거를 지우는 것만으로
초록이 되면 그 게이트는 게이트가 아니다 (D-301 「검사 못함 ≠ 0건 검사」).
