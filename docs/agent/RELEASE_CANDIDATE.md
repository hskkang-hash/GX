## 0. 한 문장 — **'완주' 가 아니다**

> **릴리스 후보(SDN 제외판)의 범위 안에서는 끊긴 단계가 없다.**

이 문장을 "완주" 로 줄여 적지 않는다(D-302). 잠긴 칸은 실패가 아니고 통과도 아니다 —
**잴 수 없는 것**이고, 잴 수 없다는 사실 자체가 이 문서가 전하는 내용의 절반이다.

## 1-1. 잠금 유형별 건수 (D-307) — **오늘 무엇을 하면 몇 개가 풀리는가**

```
[BLOCKER] 검사 6건 · 유형별: DEV 3 · CONTRACT 1 · ADMIN 2
  CONTRACT  SDN_API_SPEC        → 에스비정보기술 (독촉은 대표)
  ADMIN     JUSO_API_KEY        → 대표   ★ 10분
  ADMIN     CCTV_SERVICE_NAME   → 대표   ★ 10분
  DEV       F03_POLYGON_DESIGN  → Code (설계 확정 후)
  DEV       CLIP_EXTRACTION     → Code
  DEV       MIGRATE_ONE_LINER   → dj-core 담당 (§0.4 로 우리가 못 고친다)
```

**DEV 는 일정 문제, CONTRACT 는 책임 문제, ADMIN 은 하루면 풀리는데 안 한 것**이다.
섞어 두면 하루짜리가 계약 리스크 뒤에 숨는다 — 그래서 유형을 칸으로 만들었다.
재현: `python scripts/verify_blockers.py --summary`

## 1-2. 계약 AC 전수 (D-309) — **우리가 무엇을 모르는가**

```
[AC] 검사 14행 · 증명 시험 35건
[AC] 상태별: 구현 5 · 부분 5 · 잠김 3 · 미측정 1
[AC] ★ 미측정 1건 — F-05 (외부 App 의 유일한 진입면). 구현 여부와 무관하게 **재는 시험이 없다**
```

증명 시험이 없는 칸은 '구현' 으로 적지 않는다 — 그런 칸은 '부분' 이 아니라 **'미측정'** 이다.
재현: `python scripts/verify_contract_ac.py --table`

재현: `python scripts/verify_release_candidate.py` (exit 0)

★ 이 판정기는 **증거가 없으면 통과가 아니라 exit 1** 한다. 증거를 지우는 것만으로
초록이 되면 그 게이트는 게이트가 아니다 (D-301 「검사 못함 ≠ 0건 검사」).
