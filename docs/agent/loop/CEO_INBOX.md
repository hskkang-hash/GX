# CEO_INBOX — 대표가 답하는 자리 (한 줄씩 · 최신이 위 · `[ ]` → `[x]` 또는 문장)

> 세종·영실이 질문을 올리면 아래 형식으로 한 줄이 생긴다. 대표는 `[ ]` 를 `[x]` 로 바꾸거나 그 줄 끝에 문장을 적는다.
> 감시기가 5분 안에 읽어 영실에게 넘긴다. **값(비밀)은 여기 적지 않는다** — 금고 경로만.
