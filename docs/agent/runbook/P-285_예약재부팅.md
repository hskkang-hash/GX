# P-285 — 매일 04:30 예약 재부팅 · 대표 손 ㉢ (관리자 PowerShell 1회)

턴 AR · 조율자 E · 2026-09-30. 시각은 **KST**(P-447 뒤 서버 시계와 같다).

## 등록 (관리자 PowerShell 에서 한 줄)
```powershell
schtasks /Create /TN "GuardianX\NightlyReboot" /TR "shutdown.exe /r /f /t 60" /SC DAILY /ST 04:30 /RU SYSTEM /RL HIGHEST /F
```
## 확인 · 되돌리기
```powershell
schtasks /Query /TN "GuardianX\NightlyReboot" /V /FO LIST    # 다음 실행 시각 04:30
schtasks /Delete /TN "GuardianX\NightlyReboot" /F            # 되돌리기 한 줄
```

## 왜 04:30 인가 — 밤 beat 표(P-447 대조 표 KST)와 겹치지 않게
| KST | 일 |
|---|---|
| 02:00 · 02:05 | 순찰 프로필 생성 · LAW-08 앵커 |
| **04:30** | **재부팅(60초 유예)** |
| 04:40 · 04:50 | 감사 정리 · 영상 보존 (둘 다 지금 꺼짐) |
| 05:00 | **백업** — 재부팅 뒤 30분 안에 Docker 가 서 있어야 한다 |

## ⚠ 세 조각이 다 있어야 아침이 선다 (P-303)
1. 이 예약(위 한 줄).
2. Docker Desktop 「로그인 시 시작」 켬.
3. **로그인 없이는 Docker Desktop 이 안 뜬다** → 자동 로그인 + 즉시 화면 잠금(세종 권고) 또는 대표 출근 직후 손 로그인. 이 결정은 대표(P-303) — 안 정하면 재부팅 뒤 05:00 백업은 **돌지 않는다.**

다음 날 아침 판정(P-285 닫는 조건): 작업 스케줄러 「마지막 실행 결과 0x0」 + 아침 스모크 N+1.
