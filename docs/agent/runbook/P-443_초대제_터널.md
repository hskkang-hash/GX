# P-443 초대제 터널 — 대표 PC 8500 을 HTTPS 한 주소로 (준비서 · 턴 AQ · 조율자)

**지금 상태(2026-09-30 13:5x 실측)**: `cloudflared` 미설치 · `~/.cloudflared` 없음 · Cloudflare 계정·도메인 정보 없음 → **터널 0 · 「바깥」 칸 0 그대로**(지어내지 않는다).

## 대표 손 1회 (자격이라 대표만)
1. Cloudflare 계정에 도메인 1 이 있어야 한다(Access 가 도메인에 붙는다). **도메인이 없으면 멈춘다** — Access 없는 임시 주소(`trycloudflare`)는 쓰지 않는다(시드 계정 공용 비번이 인터넷에 선다 · WO-20 §12).
2. `winget install Cloudflare.cloudflared` 뒤 `cloudflared tunnel login` — 브라우저 인증. 만들어지는 `cert.pem` 은 금고 `C:\GuardianX-vault\cloudflared\` 로 옮긴다(값은 금고 · 저장소 0).
3. Zero Trust → Access → 애플리케이션 1(`gx.<도메인>`) · 정책 「메일 허용 목록 = 대표 + 초대 1」.

## 영실 집행 (대표 1 뒤)
```
cloudflared tunnel create gx-aq
cloudflared tunnel route dns gx-aq gx.<도메인>
```
`C:\GuardianX-vault\cloudflared\config.yml` (저장소 밖):
```
tunnel: gx-aq
credentials-file: C:\GuardianX-vault\cloudflared\<터널 id>.json
ingress:
  - hostname: gx.<도메인>
    path: ^/api/(docs|openapi\.json)
    service: http_status:404          # P-296 운영 모양 — 개발 문서는 터널 밖
  - hostname: gx.<도메인>
    service: http://localhost:8500    # 내는 것은 8500 하나(9001 · 8025 · 3002 · 8000 밖)
  - service: http_status:404
```
- 백엔드: `DJANGO_CSRF_TRUSTED_ORIGINS` 에 `https://gx.<도메인>` 한 줄(env-file · 이름만 기록) → `restart_live.py`.
- 켜기: `cloudflared service install` · **끄기: `sc stop cloudflared` 한 줄**(삭제·되돌리기 아님 → 세종 판정 · 영실 집행).

## V 가 재는 것 (「바깥」 0.5 의 조건)
바깥 휴대폰(LTE · 사내망 밖)에서 `https://gx.<도메인>` → Access 메일 인증 → 로그인 6/6 · 「누른 뒤」 표본 5 · `/api/docs` 404 · `:9001`·`:8025` 미도달. 하나라도 못 재면 0.
