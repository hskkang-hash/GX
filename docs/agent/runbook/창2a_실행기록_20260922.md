## §3 못 한 것 — **VAPID**

찾은 자리 전부에서 **0**:
```
settings.VAPID_PUBLIC_KEY / VAPID_PRIVATE_KEY / VAPID_CLAIM_EMAIL / VAPID_CLAIMS / WEBPUSH_SETTINGS  → 전부 없음
.env · .env.gates · backend/.env                                                                      → 0줄
```
실행서가 기댄 「U3 이 되살려 둔 값」은 **존재하지 않는다** — U3 차선이 턴 AC·AD 에 둘 다 안 돌았다.
**실행서 ㉢ 대로 이 창에서 뺐다**: 「없으면 VAPID 는 이 창에서 뺀다. 없는 값을 지어내지 않는다.」

**대표 판단이 필요한 자리 하나**: 구독한 기기를 세니 **0**(웹푸시 구독 표 없음 · 웹훅 1행뿐)이다.
즉 **새 쌍을 만들어도 끊길 것이 없다.** 그러나 비밀을 새로 만드는 것은 금고 일이라 안 했다.
  · 값이 어딘가(대표 금고)에 있으면 → 주시면 창 2b 에서 싣는다
  · 없으면 → **새 쌍을 만들어도 되는가** 한 마디. (지금은 만들 이유는 있고 막을 이유는 없다)
