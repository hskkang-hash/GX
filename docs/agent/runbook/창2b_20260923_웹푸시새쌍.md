### 지금 두 통의 모양 [실측 · 재생성의 밑그림]

| | `gx-gunicorn-e` | `gx-celery-e` |
|---|---|---|
| 이미지 | `guardianx-backend:latest` | `guardianx-backend:pg18` |
| Entrypoint | `["python"]` | `["python"]` |
| Cmd | `-m gunicorn config.wsgi:application --bind 0.0.0.0:8000 --workers 4 --threads 4 --worker-class gthread --timeout 120 --access-logfile - --error-logfile -` | `-m celery -A config worker -l INFO --concurrency=2 --time-limit=600 --soft-time-limit=300 -n gx-worker-e@%h` |
| WorkingDir | `/app` | `/app` |
| Restart | `unless-stopped` | `unless-stopped` |
| Network | `gx-main-network` | `gx-main-network` |
| 마운트 | **1** — `backend→/app` | **5** — `backend→/app` · `backend→/repo/backend` · `scripts→/repo/scripts` · `evidence/D-373→/docs/agent/evidence/D-373` · 볼륨 `gx_backup_vault_e→/backup` |
| 환경 | 50개 | 50개 |

⚠ **`--entrypoint python` 을 반드시 준다.** 이미지의 `ENTRYPOINT` 는 `/entrypoint.sh` 라
그냥 띄우면 제 방식대로 celery·beat 를 올린다(창 2a 에서 여기 한 번 걸렸다).
⚠ **`MSYS_NO_PATHCONV=1`** 없이는 Git Bash 가 `/app` 을 `C:/Program Files/…` 로 바꾼다.
⚠ **`-e KEY=VALUE` 를 쓰지 마라 — 비밀이 argv 에 남는다.** `--env-file` 만 쓴다.
⚠ **`-e 이름`(값 없이)도 쓰지 마라** — 호스트에 그 이름이 없으면 **빈 값으로 덮는다**.

### 이미지를 무엇으로 할 것인가 — **둘 다 `:pg18`**
`:pg18` 은 `:latest` 에서 파생된 것(`FROM guardianx-backend:latest` + apt 한 층)이라
**진부분집합이 아니라 상위집합**이다. gunicorn 에게 pg_dump 18.6 은 **쓸 데가 없지만
해도 없다.** 두 통의 이미지가 갈려 있는 것 자체가 다음 사람의 함정이라 여기서 맞춘다.
⚠ 단, 이것은 **「이유 있는 변경」이 아니라 「해 없는 정리」**다 — 보고에 그렇게 적는다.
gunicorn 을 재생성하는 **진짜 이유는 VAPID 환경**이다(그 통이 API 를 낸다).

## §1 걸음 — 순서대로. 각 걸음의 확인이 서기 전에 다음으로 가지 않는다

### ㉠ 쌍을 만든다 — **값을 화면에 내지 않는다**
`py_vapid` 로 P-256 쌍을 만들고 **곧장 `.env.vapid` 에 쓴다.**
표준출력에는 **이름 · 길이 · sha256 앞 12자**만 낸다.
`GX_VAPID_SUBJECT` 는 `mailto:` 한 줄 — 비밀이 아니다.

확인: `.env.vapid` 가 세 줄이고 `git check-ignore` 가 잡는다 · `git status` 에 안 보인다.

### ㉡ 두 통의 환경을 **파일로** 뜬다 — 저장소 밖 임시
`docker inspect` 로 지금 통의 `Config.Env` 를 그대로 뜨고, **이미지가 주는 이름**
(`PATH` · `LANG` · `GPG_KEY` · `PYTHON_VERSION` · `PYTHON_SHA256` · `LD_LIBRARY_PATH`)은 **뺀다**
— 이미지가 다시 준다. 거기에 VAPID 세 줄을 더한다.
임시 파일은 **저장소 밖**(스크래치패드)에 두고 **창이 끝나면 지운다**.

확인: 파일의 줄 수가 `50 − 6 + 3 = 47` 이다 · 값은 화면에 안 낸다.

### ㉢ 옛 통을 **이름만 비킨다** — 지우지 않는다
```
docker stop gx-gunicorn-e && docker rename gx-gunicorn-e gx-gunicorn-e-old-2b
docker stop gx-celery-e   && docker rename gx-celery-e   gx-celery-e-old-2b
```
⚠ `gx-celery-e-old`(창 2a 의 것)가 이미 있다 — **이름이 겹치지 않게** `-2b` 를 붙인다.
⚠ 지금 `-old` 둘은 **되돌릴 길**이다. 지우는 것은 대표 결정이다.

### ㉣ 새 통을 세운다
`--entrypoint python` · `--env-file` · 마운트를 §0 표 그대로 · `--restart unless-stopped`
· `--network gx-main-network` · 이미지 `guardianx-backend:pg18` · Cmd 를 §0 표 그대로.

확인 셋:
1. `gx-nginx-e:8500/api/dsm/health` **200** · `gx-gunicorn-e:8000/api/dsm/health` **200**
2. celery **worker ready** · 마운트 **다섯** 전부(`/backup` 포함) · `pg_dump --version` 18.6
3. VAPID **세 이름이 있다**(값 아님 — `이름=있음/없음`만)

### ㉤ 고객이 누르는 자리 — **도달 1**
브라우저(gx-shell 안 Playwright · `locale="ko-KR"`)로:
`gxseed_u1_operator` 로 3002 로그인 → `/m/settings` (또는 09-17 회차의 그 자리) →
「이 기기로 알림 받기」 구독 → 「내 기기로 한 통」 → **알림이 뜨는가**.

잴 것 넷: ① `push-subscriptions/vapid-key` **200** ② 구독 POST **200** · 구독 **1**
③ `test-send` **200** ④ **브라우저에 알림이 떴다**(제목에 `[훈련]`).

⚠ **웹푸시 발송은 훈련 채널만이다.** 제목에 「훈련」이 없으면 그건 보내면 안 되는 통이다.
⚠ 실패해도 **지어내지 않는다.** 못 닿으면 「503 그대로 · 사유」로 적고 창을 닫는다.
⚠ 구독 POST 가 **쿼리 문자열로 endpoint·키를 받는다**[09-17 실측] — 비밀이 URL 에 실리는
모양이다. **이 창에서 고치지 않는다**(제품 라우트 · U3 자리). 보고에 적어 U3 로 넘긴다.

### ㉥ 되돌리기 표 · 삭제 0 확인
지운 것 0건 · 옛 통 둘 살아 있음 · 임시 env 파일 지웠음 · `.env.vapid` 는 남기되 커밋 안 됨.
