## ★ 걷기가 **두 번**이었고 그 차이가 이 문서의 값이다

**1차 — 회색(완주 2/3).** 조율자가 **같은 시각에 게이트 묶음을 돌리고 있었다.**
이 환경은 동시 접속 1개(`end_previous_session` · UX-24b · 손 밖)라 게이트의 로그인이
걷기의 세션을 끊었고, S3 가 로그인 화면으로 튕겼다. 걷기는 그것을 정직하게 **회색**으로 냈다 —
「걸었더니 막혔다」가 아니라 「**세션을 빼앗겨 못 걸었다**」.

**2차 — 단독으로 걸었다 [실측 23:55]:**
```

[WALK]   분류되지 않은 콘솔 오류 0건   0건 (알려진 잡음 41건은 따로 센다)
[WALK]   세션을 닫았다            POST /api/v1/auth/logout 200
[WALK] 통과 — 세 시나리오를 걸었고 콘솔은 조용했다
```

**교훈 등재**: **걷기는 단독으로 건다.** 이 환경에서 걷기와 게이트를 겹치면 나오는 빨강은
제품의 사실이 아니라 **세션 한 칸의 사실**이다. 1차의 회색을 「S3 결함」으로 읽었으면
없는 결함을 좇았을 것이다. `deploy.sh` 가 회색과 빨강을 갈라 낸 것이 그것을 막았다.
