# 무관문 쓰기 10자리 — **조율자가 차선 밖에서 다시 쟀다**

[실측 2026-09-06 · 턴 I · 조율자 · 차선 S 의 산출을 **믿지 않고** 독립으로 대조]

---

## 왜 다시 쟀나

차선 S 가 「무관문 쓰기 라우트 10자리를 찾아 10자리 다 401 로 닫았다」고 냈다.
이 저장소가 반복해 만난 실패 모양이 정확히 이 자리다 — **고친 사람이 자기 코드를
자기 도구로 재고 초록을 낸다.** 그래서 조율자가 **차선 S 의 판정기를 쓰지 않고**
날 HTTP 로, **같은 순간 두 서버에** 같은 요청을 던졌다.

두 서버는 **코드만 다르다**(같은 컨테이너 · 같은 DB · 같은 MinIO · 같은 설정):

| 포트 | 코드 | 기동 |
|---|---|---|
| **8000** | 턴 H 코드 (`abbdf36` · 차선 S 의 이번 턴 수정 **없음**) | 22:20 |
| **8400** | 이번 턴 작업본 (차선 S 의 `access_gate` 수정 **있음**) | 22:5x |

⚠ **없는 id(999999999)로만 두드렸다** — 아무것도 쓰지 않는다. 실재 id 로
쓰기 경로를 두드리면 그것은 측정이 아니라 사고다(이 저장소의 기존 규칙).

---

## 잰 것 — 익명, 인증 머리글자 없음

```
--- 8000  (턴 H 코드)
  POST /api/v1/auth/reset-password-for-user   →  400
  POST /api/apikey/keys                       →  500
--- 8400  (이번 턴 코드)
  POST /api/v1/auth/reset-password-for-user   →  401
  POST /api/apikey/keys                       →  401
```

## 이 네 수가 말하는 것

**400 은 401 이 아니다.** 익명 요청이 `reset-password-for-user` **핸들러 안까지
들어갔다**는 뜻이다 — 문이 열려 있었고, 본문이 마음에 안 들어서 되돌아 나온 것뿐이다.
본문을 맞춰 주면 그 다음은 없다. 그 핸들러가 하는 일은 **아무 계정의 비밀번호를
바꾸는 것**이고, 거기에는 슈퍼유저도 들어간다.

**500 은 더 나쁘다.** 익명 요청이 API 키 발급 코드까지 닿아서 **거기서 터졌다**.
막힌 것이 아니라 **깨진 것**이다. 그리고 API 키는 그 자체가 자격증명이라,
그 문 하나가 열리면 **그 뒤의 모든 관문이 무의미해진다.**

**8400 의 401 둘**은 같은 요청이 이제 **핸들러 앞에서** 끊긴다는 뜻이다.
길목(`backend/common/access_gate.py`)에서 막았고 dj-core 는 한 줄도 안 고쳤다(§0.4).

★ 이것이 P-83 이 갈라 놓으라고 한 바로 그 칸이다 — **401·403 과 4xx 나머지는
  다른 칸이다.** 턴 H 의 `verify_write_auth` 는 422 를 관문으로 세어 「관문 17」이라는
  거짓 초록을 냈다. 만약 그때 이 두 자리를 401 로 셌다면, 오늘 이 400·500 은
  영영 안 보였다.

## 아직 안 끝난 것 — 정직하게

1. **`POST /api/v1/auth/create-user` 는 두 서버 다 404** 다. 차선 S 가 센 10 중
   하나인데 이 경로로는 안 잡힌다. 조율자가 잰 것은 **10 중 2** 이고,
   나머지 8 은 차선 S 의 판정기 수(`docs/agent/evidence/D-368/writeauth_20260906_TI.json`)다.
   **2 는 내 눈으로 봤고 8 은 남의 눈으로 봤다** — 섞어 적지 않는다.
2. **8000 은 아직 이 수정을 안 물고 있다.** 병합 뒤 8000 을 다시 세우고
   `verify_live_freshness` 가 초록이 된 자리에서 한 번 더 잰다. 그때까지
   **「지금 서비스되는 것이 닫혔다」고 말하지 않는다.**
3. `read_only_in_practice` 로 남은 **5자리**는 여전히 익명이 핸들러까지 닿는다.
   차선 S 가 사유를 이름으로 남겼다(경로 틀 접두 판단 · ETRI 연동 입구).
