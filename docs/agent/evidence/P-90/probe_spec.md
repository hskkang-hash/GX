## 2. 명령 — 값 없음 · 본문 없음

```
BASE="https://<운영 공개 URL>"        # 값은 vault 메모 · 이 파일에 적지 않는다
for p in /api/config-management/list-optimized /api/auth/timezones /api/register-settings /api/dsm/events; do
  curl -sS -m 10 -A "GX-P90-probe/1" -o /dev/null \
       -w "$p %{http_code} %{size_download} %{content_type}\n" \
       -D - "$BASE$p" | grep -Ei "^(/api|x-gx-public-projection)" 
done
```

출력 4줄(경로 · 코드 · 바이트 · 타입)과 1건의 헤더 유무를 JSON 한 벌로 저장한다. 재시도 없음(율제한 5/m 안) · 같은 날 두 번 보내지 않는다.
