# P-90 운영 읽기 탐침 4건 — 명령 정본

- **대표 승인: 있음** (2026-09-11 「운영 읽기 4건 보내라」)
- **실행: 못 함 · 사유 = 운영 주소가 선언된 적이 없다** (아래 §3 실측)
- 이 문서가 정본이다. 주소 한 줄이 오면 §2 를 그대로 실행한다.

## §1 무엇을 왜 재는가

우리 개발 DB 에서 이 넷은 **인증 관문이 0줄**이었다(`authn=(없음)` — 라우터 실측본
`D-343/route_inventory.json`). 우리는 그 넷을 이번 주에 닫았다. 남은 질문은 하나다:

> **운영에 서 있는 판에도 같은 문이 열려 있는가.**

넷 중 하나(`receive-from-etri`)는 턴 J 에 실측된 P0 다 — 익명이 접수번호 하나로
남의 배송을 취소할 수 있었다. 그 문이 운영에 열려 있다면 **지금 이 순간 열려 있다.**

## §2 명령 — 이대로, 이것만

```bash
GX_PROD="<대표가 주는 주소>"      # 예: https://<운영 호스트>
OUT="docs/agent/evidence/P-90/probe_$(date +%Y%m%d_%H%M%S).json"

for spec in \
  "HEAD    /api/v1/auth/reset-password-for-user" \
  "OPTIONS /api/apikey/keys" \
  "HEAD    /api/delivery/etri-integration/receive-from-etri" \
  "HEAD    /api/v1/auth/otp/reset" ; do
  m=${spec%% *}; p=${spec##* }
  code=$(curl -s -o /dev/null -w '%{http_code}' -X "$m" --max-time 10 "$GX_PROD$p")
  size=$(curl -s -o /dev/null -w '%{size_download}' -X "$m" --max-time 10 "$GX_PROD$p")
  printf '%-8s %-58s -> %s (%s bytes)\n' "$m" "$p" "$code" "$size"
done | tee "$OUT.txt"
```

### 이 명령이 **하지 않는** 것 — 승인 범위가 이것이다
| | |
|---|---|
| 인증 | **없다.** 자격증명 한 글자도 싣지 않는다 |
| 본문 | **없다.** `HEAD`·`OPTIONS` 는 본문을 갖지 않는다 |
| 쓰기 | **없다.** `POST`·`PUT`·`PATCH`·`DELETE` 를 부르지 않는다 |
| 로그인 | **없다.** 세션을 만들지 않는다 |
| 계정 | **없다.** 실재 사용자명·접수번호를 쓰지 않는다 |
| 횟수 | 경로당 **2회**(코드 1 · 크기 1) · 총 **8 요청** · 타임아웃 10초 |

⚠ **`POST` 로 두드리지 않는 이유**: `receive-from-etri` 는 접수번호 하나로 **취소가
일어나는** 문이다. 도달을 재려고 진짜 메서드를 부르면 **그 자체가 사고**다.
`HEAD` 가 404 를 내고 `PROPFIND` 가 405 를 내면 「문은 있고 그 행이 없다」가 갈린다
(라우트 삼킴 함정 · D-350 계열). 도달만 재고 **실행하지 않는다.**

### 읽는 법
| 응답 | 뜻 |
|---|---|
| **401 · 403** | 관문이 섰다 — **운영은 안전하다** |
| **200 · 405 · 422** | **관문이 없다** — 그 문은 지금 열려 있다 → 즉시 대표 보고 · 긴급 패치 창 |
| 404 | 그 경로가 운영 판에 없다(다른 버전) — 버전 확인 필요 |
| 000 / 타임아웃 | 못 쟀다 — **회색.** 안전하다는 뜻이 아니다 |

응답 **크기**도 함께 적는다: 턴 L 에 익명이 165KB 장고 디버그 전문을 받던 결함이
있었다. 운영 응답이 수백 바이트를 넘으면 그 결함도 함께 서 있다는 신호다.

## §3 왜 아직 못 보냈나 — 「없다」의 실측

```
$ grep '^GX_API=' .env.gates
GX_API=http://localhost:8000                      ← 우리 컨테이너다

$ grep -rE "https?://[a-z0-9.-]+\.[a-z]{2,}" --include=*.py --include=*.sh \
    --include=*.yml --include=*.md --include=*.example . | 제3자 제외
→ NOTAM(aim.koca.go.kr) · 기상(open-meteo) · 주소(juso.go.kr) 뿐

$ grep -rn "P-90" docs/          → 언급 4곳 · **주소 0곳**
$ ls docs/agent/evidence/P-90/   → (이 문서를 쓰기 전까지 비어 있었다)
```

**운영 주소는 이 저장소에 한 번도 적힌 적이 없다.** 네 턴 동안 「보내라」를 기다렸지만,
정작 「어디로」는 아무도 적지 않았다 — 승인과 함께 왔어야 할 한 줄이다.

> **원칙 등재 — 승인에는 주소가 붙어야 한다.** 「보내라」는 대상을 포함해야 명령이다.
> 대상 없는 승인을 받은 쪽이 대상을 **추정하면**, 그 순간 그것은 승인받지 않은 행위다.

## §4 대표께 — 필요한 것은 한 줄입니다
운영 GuardianX 의 **주소**(`https://…`). 그 한 줄이 오면 위 8개 요청이 나가고,
결과는 네 줄(메서드 · 경로 · 상태코드 · 크기)로 즉시 보고합니다.
같이 주시면 좋은 것: 접속 제한(허용 IP)이 있는지 · 보내도 되는 시간대.
