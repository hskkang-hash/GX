- 짝 문서: 같은 폴더의 `규약_QA.md`(차선 Q). **정본은 그 문서의 규약 ①이다.**
  이 문서는 「그 규약대로 박았고, 그 게이트로 재 봤다」를 적는다.

## 0. 두 절이 어긋날 뻔했다 — 그리고 어디서 갈렸나

착수 시각에 이 폴더가 비어 있어 두 차선이 **각자 규약을 정했다.** 나중에 맞춰 보니
갈린 자리가 하나였다:

| | 처음 C 안 | Q 규약 ① | **채택** |
|---|---|---|---|
| 게이트가 읽는 자리 | `index.html` 의 머리표 | 엔트리 JS 안의 리터럴 토큰 | **Q** |
| 해시 길이 | 7자리 | 40자리 | **Q** |
| 접두어 | 없음 | `GX_COMMIT:` | **Q** |

**Q 가 옳았고 그 사유가 실측이다**: 접두어 없이 `[0-9a-f]{40}` 을 찾으면 지금
번들의 **긴 숫자 상수 두 개**가 걸린다. 남의 숫자를 커밋으로 읽는 게이트의 초록은
아무것도 맞추지 않는다 — 그것이 바로 이 절이 없애려는 종류의 초록이다.
그리고 7자리는 다른 커밋과 부딪힐 수 있다. **부딪히는 신원은 신원이 아니다.**

그래서 C 안을 접고 Q 규약으로 구현했다. `verify_bundle_hash.py` 의 `TOKEN_PREFIX`
는 **고칠 필요가 없다** — 조율자 배선 하나가 여기서 지워진다.

## 1. 번들이 실제로 내는 것 셋

| # | 무엇 | 어디 | 형태 | 읽는 이 |
|---|---|---|---|---|
| ① | **정본 토큰** | 엔트리 JS (`assets/index-*.js`) | `GX_COMMIT:<40자리 16진>` · 정확히 1회 | 게이트 |
| ② | 화면 글자 | 모든 화면 오른쪽 아래 | 「버전 3d40cf6」 · **7자리** | 사람 · 지원 창구 |
| ③ | 덤 · 머리표 | `index.html` 의 `<head>` | `<meta name="gx-commit" content="<40자리>">` | 아무나 · 눈으로 |

★ ③은 **정본이 아니다.** Q 규약 §1-③ 의 정신 그대로다 — 곁의 것만 새로 쓰이고
  JS 가 낡은 채로 남는 것이 정확히 P-59 사고의 모양이다. 판정은 ①로 한다.
  ③을 남겨 둔 이유는 하나다: 브라우저 개발 도구를 못 여는 사람도 문서 소스 한 번으로
  버전을 볼 수 있다. **판정에 쓰지 말 것.**

★ ②는 번들에 **통짜 문자열로 없다.** 「버전 」과 해시를 템플릿으로 붙이기 때문이다.
  ⚠ 「버전 3d40cf6」을 통째로 grep 하는 확인은 **언제나 못 찾는다.** 그것은 빨강이
  아니라 확인하는 쪽의 오답이다. ②는 **화면 캡처로** 확인한다(Q 규약 §1-② 와 같다).

★ ①은 소스에서 **조립하지 않는다.** 접두어까지 포함한 완성된 글자를 빌드가 넣고
  화면 코드는 그것을 그대로 든다. `'GX_COMMIT:' + 해시` 로 이어 붙이면 그 문장이
  번들에 리터럴로 남는다는 보장이 없다(상수 접기 · 트리셰이킹).
  살아남게 하는 것은 `constants/build.ts` 의 전역 대입 한 줄이다 — 어디서도 안 쓰이는
  값은 트리셰이킹이 지우고, 지워지면 게이트는 「말하지 않는 번들」을 보게 된다.

## 2. 빌드가 커밋을 어디서 아는가 — **순서가 곧 판단이다**

1. 환경 변수 `GX_COMMIT` (또는 `VITE_GX_COMMIT`) — **명시가 추론을 이긴다.**
2. `git rev-parse HEAD` — 저장소 위에서 도는 호스트 빌드면 이것으로 족하다.
3. 둘 다 없으면 **빈 값** → 화면 「버전 알 수 없음」 · 머리표 `unknown` ·
   **토큰은 아예 안 나간다** → 게이트 빨강.

**[실측 2026-09-05 · `gx-fe-build` 안에서 두드림]**
`git` 실행 파일은 **있고**(`/usr/bin/git`) `.git` 이 **없다** — 넣는 것이 `src` 와
`vite.config.ts` 뿐이기 때문이다. `cd /app && git rev-parse` → `fatal: not a git
repository`. 즉 컨테이너 빌드에서 2번은 **예외 없이 실패한다.**
「git 이 깔려 있으니 되겠지」는 이 자리에서 틀린 추측이다.

⚠ **`--short` 를 붙이지 말 것.** 넘기는 값은 온전한 40자리여야 한다. 7자리를 넘기면
빌드는 서고 화면도 뜨지만 **토큰이 안 나가고 게이트가 빨개진다**(40자리가 아니면
토큰을 내지 않는다 — 신원으로 못 쓰는 값을 신원인 척 내보내지 않는다).

### RUNBOOK 에 들어갈 세 줄

```
docker cp frontend/src/. gx-fe-build:/app/src/
docker cp frontend/vite.config.ts gx-fe-build:/app/vite.config.ts
docker exec -e NODE_OPTIONS=--max-old-space-size=6144 \
            -e GX_COMMIT=$(git rev-parse HEAD) \
            gx-fe-build sh -c 'cd /app && npx vite build --outDir dist_te'
```

## 3. 잰 것 — **Q 의 게이트를 그대로 돌렸다** [실측]

내 판정기를 따로 짜지 않았다. 짜면 두 벌이 되고 두 벌은 반드시 갈린다.

| # | 무엇 | 결과 |
|---|---|---|
| 1 | 커밋 넣고 빌드 | `✓ built in 1m 19s` |
| 2 | 토큰이 박혔나 | `grep -o 'GX_COMMIT:[0-9a-f]\{40\}'` → `GX_COMMIT:3d40cf66411a22ec7d93501f4665781435ace788` · **엔트리 청크에 1회** |
| 3 | 그 청크를 `index.html` 이 부르나 | `assets/index-HJjiVC5m.js` — **부른다** |
| 4 | 머리표 | `<meta name="gx-commit" content="3d40cf66411a…">` |
| 5 | **Q 의 게이트 · 내 번들** | `python scripts/verify_bundle_hash.py --dist <dist_te>` → **`통과 — 서버가 내는 번들이 현재 커밋이다`** |
| 6 | **Q 의 게이트 · 지금 서버가 문 낡은 것** | 같은 명령 `--dist backend/_fe_dist` → **`실패`** · 「번들이 자기가 어느 커밋인지 말하지 않는다」 |
| 7 | **커밋 없이 빌드**(음성 시험) | 머리표 `content="unknown"` · 화면 「버전 알 수 없음」 |
| 8 | 그때 지어낸 해시 | `grep -c 3d40cf6 assets/index-*.js` → **`0` · 세 청크 전부** |

5와 6이 짝이다 — **같은 게이트가 내 것에 초록, 지금 서 있는 것에 빨강**을 낸다.
게이트가 아무것에나 초록을 내는 물건이 아니라는 것이 6이고, 내가 박은 것이
그 게이트를 실제로 만족한다는 것이 5다.

8이 요점이다 — **커밋을 모르는 빌드는 해시를 만들어 내지 않는다.**
턴 D 의 거짓 초록은 「아무도 모른다」였다. 지어낸 해시는 그보다 나쁘다.

## 4. ⚠ 지금 서 있는 서버는 **빨강이다** — 그리고 그것이 옳다

위 6번이 그 줄이다. `backend/_fe_dist` 는 도장 없는 낡은 번들이다.
**병합 뒤 조율자가 다시 빌드해 넣기 전까지 이 게이트는 빨강으로 남는다.**
초록으로 바꾸는 것은 이 차선의 일이 아니다 — 재빌드와 배치가 그 일이다.

## 5. 못 잰 것

- **`--web`(서 있는 서버가 내주는 것)으로는 안 쟀다.** 이번 턴 라이브 접속 한 자리는
  QA/E2E 차선의 것이고(동시 접속 1개) 브라우저를 열지 말라는 제약이 있다.
  잰 것은 **빌드 산출물(`--dist`)까지**다.
- **화면 캡처 없음.** 오른쪽 아래 「버전 3d40cf6」이 실제로 어떻게 보이는지,
  그리고 어떤 단추도 가리지 않는지는 재촬영 차선의 자리다.
  (`pointerEvents: 'none'` 이라 가로채지 않는다 — 그러나 그것은 코드가 하는 말이지
  잰 것이 아니다.)
