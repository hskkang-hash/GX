# §1 답 — **(c)** 이고, 원인은 보고 문구가 아니라 **집계기**였다 (P-10 · D-400)

**실행 2026-09-16**

---

## 1. 세종이 물은 것 [인용]

> 직전 턴 route-alive 는 **빨갰다**(exit 1). 이번 보고는 「게이트 9종 전부 exit 0」.
> **왜 초록이 됐는지가 보고에 없다.** (a) 죽은 라우트를 처분했다 / (b) 시험을 고쳤다 /
> (c) 게이트 9종에서 route-alive 가 빠졌다 — 셋 중 어느 것인가.

## 2. 답 — **(c) 의 변형** [실측]

```
(a) 아니다 — 죽은 라우트 2건은 **처분되지 않았다.** 지금 자격증명을 주고 때리면
    `verify_route_alive.py` 는 여전히 **exit 1 · 죽은 라우트 2건** 이다
(b) 아니다 — 시험을 한 줄도 고치지 않았다 (D-327)
(c) 그렇다. 다만 **목록에서 빠진 것이 아니다** — route-alive 는 9종에 있었다.
    빠진 것은 **판정**이다: 자격증명이 없으면 그 게이트는 SKIP(판정 불가)을 내고,
    **집계기가 SKIP 을 exit 0 으로 셌다.**
```

★ 그러므로 **「게이트 9종 전부 exit 0」은 빨간 것을 재지 않고 낸 초록이다.**
  내 보고가 그 사실을 숨겼다 — 09-14 회신 본문에는 적었으나 커밋 메시지에는 안 적었고,
  **세종이 읽는 것은 커밋이다.**

## 3. ★★ 그리고 route-alive 하나가 아니었다 [실측]

집계기를 고쳐 다시 재니 **다섯 자리가 SKIP** 이었다:

```
secrets           exit 2   시크릿 스캐너 미설치 (이 호스트에 gitleaks CLI 없음)
                           ⚠ 다만 pre-commit 훅의 gitleaks 는 **커밋마다 실제로 돈다**
                              [실측: 커밋 로그 「gitleaks (시크릿 스캔) Passed」] — 둘은 다른 자리다
bypass            exit 2   프레임워크 모델 잔존(coreuser·usergroup·role…) — 뷰 레벨 대응 중
model-inheritance exit 2   볼 대상 0건 (이 실행에 변경분이 없다)
ui-library        exit 2   볼 대상 0건
route-alive       exit 2   서버·자격증명 없음
```

**아홉 중 넷만 실제로 쟀다.** 「전부 초록」이라는 말이 넉 달 동안 다섯 자리를 덮고 있었다.

## 4. 고친 것 — 종료 코드가 스스로 말하게 (D-400)

```
0 = 쟀고 통과      1 = 쟀고 실패      2 = **못 쟀다**(판정 불가)
```

이 저장소는 이미 `verify_migrations.py` 등에서 **exit 2 = 판정 불가**를 쓴다.
**집계기만 그것을 몰랐다.** 이제 `verify_gates.sh` 가 같은 규약을 쓴다.

★ 실패(1)로 하지 않은 이유: 서버 없는 환경에서 CI 를 빨갛게 만들면 **그 게이트는 결국
  꺼진다**(D-353). 꺼진 게이트는 아무것도 안 지킨다. 「모른다」는 **자기 칸이 있어야 한다**
  — D-290 의 집계기 판이다.

★ 판정식은 **한 벌이다.** `summary_rc()` 하나를 단일 게이트·티켓 전체·자기시험 셋이
  함께 쓴다. 각자 계산하면 반드시 어긋나고, 어긋난 판정식 복사본 하나가 D-212 였다.

★ 출생 표본(D-310): `--self-test` 가 세 갈래를 본다 —
  ①판정 불가→2 ②통과→0 ③**실패+판정 불가→1**(실패가 「모른다」 뒤에 숨으면 안 된다).
  음성 갈래를 실제로 확인했다 [실측]: `summary_rc` 를 망가뜨리자 자기시험이 **exit 1** 로
  빨개졌고, 되돌리자 초록이 됐다.

## 5. 세종 오류 1건 [실측]

지시서가 「죽은 라우트 2: `/monitoring-dashboard` · `/intergrated-dashboard`」라 적었다.
**그 둘은 죽은 라우트가 아니다** — 화면 경로이고, 열었더니 홈으로 튕긴 **도달 불가** 건이다
(D-396 ③④). 죽은 라우트 2건은 `/api/media-data/` 와 `/api/media-data` —
**같은 자리의 두 형태**(경로 끝 빗금 있고 없고)이고, 원인은 이 환경의 MinIO 부재다.
잠금에 이미 올려 두었다: `MEDIA_LIST_SHOWS_EMPTY_WHEN_STORAGE_DOWN`.
