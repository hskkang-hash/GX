# 정정 — 「제품 언어 게이트 빨강 83건 · 커밋 셋 동안 조용히 지나갔다」는 **gx-shell 의 착시**였다

[조율자(영실) · 2026-09-24 · 턴 AH · **세종 P-312 · P-313 의 전제를 바꾸는 정정**]

## ① 조율자가 보고한 것

턴 AH 중간 보고(09-24 16:0x)에서 이렇게 적었다:

> 「제품 언어」 게이트가 지금 빨강입니다 — **새 위반 83건.** 훅이 `frontend/src/features`
> 가 바뀔 때만 돌아서 제 커밋 셋 동안 「검사 대상 없음」으로 지나갔습니다 —
> **조용히 지나간 것이지 통과한 게 아닙니다.**

세종은 이것을 받아 WO-12 §10 에 **P-312**(「83 은 UX-31 의 분모 · 빨강은 빨강」)와
**P-313**(「게이트는 경로 조건으로 건너뛰지 않는다 · 조용히 지나간 세 커밋은
`evidence/UI-COPY/` 에 『지나간 커밋 셋 · 사후 실측 83』으로 적는다」)을 세웠다.

## ② 실측 — 훅이 도는 자리(호스트)에서 **고치기 전 그대로**를 돌렸다

`git archive HEAD`(= `7e575a4` · 조율자의 문구 고침 **전**)를 떼어 내 **호스트**에서
그 판의 `scripts/verify_ui_copy.py` 를 돌렸다:

```
[COPY] 잔여 82건 (기준선 84건 · 갚은 것 2건)
[COPY] 통과 — 새로 생긴 대장 언어 0건
EXIT 0
```

**빨강이 아니었다.** 82건은 `0b7222f`(2026-09-21 · 턴 AA)가 기준선
`docs/agent/evidence/UX-20/copy_baseline.txt`(git 추적) 으로 **잠가 둔 빚**이었고,
새 위반은 **0** 이었다. 세 커밋(`c590008` · `9d8237c` · `7e575a4`) 동안 훅이 그 게이트를
건너뛰었어도, 돌았다면 **통과**였다 — **숨긴 빨강이 없다.**

## ③ 왜 83건 빨강으로 보였나

조율자가 이 게이트를 **gx-shell 안에서** 돌렸다. 머리글은 「호스트에서 돈다」다.
gx-shell 에는 `/repo/backend·frontend·scripts` 만 물려 있고 **`docs` 는 없다**
(정확히는 다른 게이트가 만든 `docs/agent/evidence` 부분 나무만 있다). 그래서
기준선 파일이 안 보였고, **잠긴 빚 전부가 「새로 생긴 것」으로 보였다.**

세종은 §12 ④에서 「『83 새 위반』은 실은 84 전체 위반」까지 짚었다. 이 문서가
더하는 것은 **그 다음 한 걸음**이다 — 전체 위반이었다면, 훅이 보는 **새 위반은 0**
이었고 **게이트는 초록**이었다.

## ④ 무엇이 무너지고 무엇이 남나

| 판정 | 무너지는 것 | 남는 것 |
|---|---|---|
| **P-313** | 「조용히 지나간 세 커밋이 빨강을 숨겼다」 — **거짓** | 「안 돈 게이트는 회색으로 말한다」는 일반 원칙은 그 자체로 설 수 있다. 다만 **이 사례가 근거가 아니다** → 세종 재판정 |
| **P-312** | 「빨강 83」·「GA 가 빨강으로 셈해 상용이 내려가면 그게 정본」 — 빨강이 아니었다 | 84건이 **막다른 빈 화면**(「없습니다」만 있고 다음 손 없음)이었던 것은 **사실**이다. 갚은 것(84 → 0)은 진짜 제품 가치다 |

⇒ 조율자는 **P-313 을 짓지 않았다**(훅을 `always_run` 으로 바꾸는 것은 1.4초라 싸지만,
방금 무너진 전제 위에 선 판정이라 세종이 다시 판정할 자리다).

## ⑤ 이 정정이 코드로 남긴 것

같은 착시가 다시 안 나게 **P-320** 을 이 턴에 지었다 — `verify_ui_copy.py` 가 판정
전에 `docs/design/GX-COPY_v1.md`(이 게이트의 사전) 등 표지 셋을 확인하고, 하나라도
없으면 **수를 내지 않고 회색 exit 2**. 이제 gx-shell 안에서 돌리면:

```
[COPY] **판정 불가 · 회색** — 재는 자리가 틀렸다. 없는 표지: docs/design/GX-COPY_v1.md
EXIT 2
```

⚠ 표지를 `docs/agent` 로 잡았으면 **이 함정을 그대로 통과했다** — gx-shell 안에도
`docs/agent/evidence` 부분 나무가 있다. 표지 후보를 양쪽에서 재 보다가 잡혔다.
