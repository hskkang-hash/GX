### 3-1. 키 형태 게이트 — 양성/음성 대조 (D-277)

값이 아니라 **형태**로 쓴다(`.gitleaks.toml` 원칙 2). 이 파일에도, 룰에도 실제 키는 없다.

| 룰 | 무엇을 잡나 |
|---|---|
| `gx-datago-service-key` | URL 인코딩 base64 — `%2B`·`%2F`·`%3D%3D` 를 포함한 포털키 형태 |
| `gx-datago-service-key-decoded` | 그 디코딩본 (60자 이상 base64) — 인코딩을 벗겨 붙이는 실수까지 |
| `gx-kma-auth-key` | 기상청 22자 토큰 — **따옴표 안일 때만** |
| `gx-kma-auth-key-env` | 같은 토큰의 env 줄 형태 |

**양성 대조** — 가짜 키 형태 4종을 심자 4룰 전건 발화.
**음성 대조** — 저장소 전수 스캔에서 새 룰의 오탐 **0건**.

> ★ 1차판은 오탐 5건을 냈다. `weather_suitable = check_weather_conditions()` 같은
> **평범한 코드**가 "weather + = + 22자 식별자"로 읽혔다.
> **룰이 오탐을 내면 사람은 그 룰을 끄고, 꺼진 룰은 없는 룰이다.**
> 그래서 촉발어에서 일반어 `weather` 를 빼고, 값이 따옴표 안이거나 env 줄일 때만 잡게 고쳤다.
