## 3. 왜 이 둘인가 — SEC-11a 의 정의로 되돌아갔다

P-35 는 SEC-11a 를 「화면 · 계약 · **외부 진입면**」이라 적었다. 화면 쪽은 이미 0 이므로
남은 것은 외부 진입면이고, 잔여 안의 외부 진입면은 정확히 이 둘이다:

```
/api/partner/    11건  파트너 API 키 발급 · 회전 · 폐기 · 상태전환 · 콜백 등록
/api/third-api/   1건  제3자 연동 주문 생성
```

**바깥의 기계가 읽는 면**이다. 거부가 200 으로 나가면 연동자·게이트웨이·모니터링·
재시도 로직이 전부 실패를 성공으로 읽는다 — **F-05 계약 사고와 정확히 같은 모양**이다.

되돌리기는 `API_CONTRACT_PROMOTE_PATHS` 에서 두 줄을 빼는 것이다.

빨개진다. 자기시험에 여섯 갈래를 더했다(양성·음성·「대조 0건은 잔여 0이 아니라 못 쟀다」).
