# 게이트 입력 신선도 — **입력 파일은 게이트가 스스로 다시 만든다** (세종 §1-2)

- 차선 **S** · 턴 B · 2026-09-05 · 원칙 등재: `docs/agent/RESUME_NEXT.md` §1-2
- 대상: `scripts/verify_route_inventory.py` · `scripts/probe_route_inventory.py`

---

## 1. 뿌리 — 낡은 파일이 두 턴 동안 거짓 초록을 냈다

승격 접두를 늘려도 **커밋된 인벤토리 json 은 그대로였고**, 게이트는 그 파일을 읽어
초록이었다. 접두 둘이 296건 중 **0건**을 갚고 있었다는 사실이 두 턴 동안 보이지 않았다.

기술적 자리는 한 줄이었다 [실측 2026-09-05]:

```
[ROUTE-LEDGER] [입력] 라우트 685건 · 대장 685건 (인벤토리 측정일 미기재)
[ROUTE-LEDGER] 대장과 코드가 갈리지 않았다          ← exit 0
```

커밋된 파일의 `measured_at` 은 **빈 문자열**이었고, 판정 줄은 그것을
`(인벤토리 측정일 미기재)` 라고 **적기만 하고 통과시켰다.**
`--max-age-days` 라는 검사는 있었지만 **기본값이 `None`(꺼짐)** 이었다.

> 게이트가 읽는 파일이 늙으면 게이트도 늙는다.
> **모른다는 것은 통과가 아니다.**

## 2. 세운 것 — 규칙 셋

### ① 인벤토리는 자기가 언제 잰 것인지 **스스로** 적는다

`scripts/probe_route_inventory.py` 의 `measured_at` 기본값이 「빈 문자열」에서
**「지금(초 단위·시간대 포함)」** 이 됐다.

```python
"measured_at": (os.environ.get("GX_MEASURED_AT")
                or datetime.now().astimezone().isoformat(timespec="seconds")),
```

★ **시간대를 붙여 적는 이유** [실측]: 프로브는 컨테이너에서 돌고 게이트는 호스트에서 돈다.
호스트 `2026-09-05T11:25:05+0900` · 컨테이너 `2026-09-05T02:25:05+0000` — 시간대 없는
시각을 적으면 **방금 뜬 인벤토리가 게이트 눈에 9시간 낡은 것으로** 보인다.
24시간 예산의 3분의 1을 시계 차이가 먹는다.

### ② 24시간이 넘으면 **회색(exit 2)** — 초록도 빨강도 아니다

`staleness()` 가 낡음을 따로 판정한다. 저장소 규약(D-400) 그대로:

```
0 = 쟀고 통과   1 = 쟀고 실패   2 = 못 쟀다 (회색)
```

★ **낡음을 `judge()` 의 실패 목록에 섞지 않았다.** 섞으면 「환경이 낡았다」가
「코드가 틀렸다」(exit 1)로 보고되고, 반대로 빨강이 회색으로 눅는다.
순서도 규약대로다 — **빨강이 회색보다 앞선다.** 실패가 「모른다」 뒤에 숨으면 안 된다.

### ③ 회색이면 게이트가 **스스로 다시 뜬다** — `--refresh`

`refresh()` 가 `gx-shell` 에서 프로브를 돌려 입력을 다시 만든다.
다시 뜨지 못하면 그것도 **회색**이다 — 어느 갈래에서도 「못 쟀다」가 초록이 되지 않는다.

★ 기본 판정이 컨테이너를 부르지 않는 것은 그대로 뒀다(D-301 — 판정이 환경에 매이면
환경이 죽을 때 게이트가 **초록으로** 죽는다). 다시 뜨는 것은 **명시적인 한 걸음**이고,
낡은 채로는 초록을 주지 않는다.

## 3. 실측 — 세 갈래를 다 돌렸다

```
$ python scripts/verify_route_inventory.py --refresh
[ROUTE-LEDGER] 인벤토리를 다시 떴다:
    [ROUTE-INVENTORY] 봉투(D-349): clean 291 · authz_envelope 224 · promoted 170
[ROUTE-LEDGER] [입력] 라우트 685건 · 대장 685건 (인벤토리 측정일 2026-09-05T09:26:14+07:00 · 0.0시간 전)
[ROUTE-LEDGER] PASS 대장과 코드가 갈리지 않았다 (입력 신선 — 0.0시간 전 측정)
EXIT=0
```

```
$ (measured_at 을 빈 문자열로 바꾼 뒤)
[ROUTE-LEDGER] [입력] 라우트 685건 · 대장 685건 (인벤토리 측정일 **미기재**)
[ROUTE-LEDGER] GRAY 인벤토리에 측정일(measured_at)이 없다 — 언제 잰 수인지 **모른다**. 모르는 것은 통과가 아니다
[ROUTE-LEDGER] **회색은 초록이 아니다.** 대장과 코드가 갈리지 않은 것은
[ROUTE-LEDGER] 낡은 파일 위에서 본 것이라 아무것도 증명하지 않는다.
EXIT=2
```

```
$ (measured_at 을 2026-09-01 로 바꾼 뒤)
[ROUTE-LEDGER] [입력] … (인벤토리 측정일 2026-09-01T10:00:00+09:00 · 97.4시간 전)
[ROUTE-LEDGER] GRAY 인벤토리가 97.4시간 지났다 (허용 24시간) — 게이트가 읽는 입력이 낡았다.
                낡은 입력 위의 초록은 초록이 아니다
EXIT=2
```

★ **바로 그 출생 표본이 이제 회색을 낸다.** 두 턴을 거짓 초록으로 살게 한 상태
(빈 `measured_at`)를 넣으면 exit 2 다.

## 4. 자기시험 — 9건 추가 · 18건 중 0건 실패 [실측]

```
python scripts/verify_route_inventory.py --self-test
  OK  ★ 출생표본 — 측정일이 없으면 회색이다 (「미기재」는 통과가 아니다)
  OK  측정일 키가 아예 없어도 회색이다
  OK  ★ 24시간 하고도 1분이 지나면 회색이다
  OK  음성 대조 — 23시간 전이면 신선하다 (초록을 막지 않는다)
  OK  날짜만 적힌 옛 파일도 읽는다 — 그날 0시로 본다
  OK  날짜만 적힌 어제 파일은 회색이다 (0시 기준 36시간)
  OK  읽을 수 없는 측정일도 회색이다 — 모르는 것은 통과가 아니다
  OK  나이를 시간으로 센다 (24.0)
  OK  낡음은 judge 의 실패 목록에 들어가지 않는다 (회색 != 빨강)
[ROUTE-LEDGER] 자기시험 18건 중 0건 실패
```

**음성 대조를 함께 둔 이유**: 「전부 회색」은 신선도 검사가 아니라 고장난 게이트다.
23시간 전 · 시간대가 붙은 방금 파일은 **초록으로 지나가야 한다.**
