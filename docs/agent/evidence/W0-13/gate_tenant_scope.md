# C-3.1 게이트 — 커널이 서기 **전에** 세운다

**작성** 2026-08-27 · **규약** C-3.1 · §2 (게이트 3종) · **결정** D-105 · K5
**게이트** `python scripts/verify_tenant_scope.py` · 원자료 `verify_tenant_scope_run.txt`

---

## 0. 오늘 이 게이트는 아무것도 막지 않는다

`backend/kernels/` 가 아직 없다. 커널은 WP-2 EXIT 후 K1 부터 선다.
그러니 지금 이 게이트가 훑을 커널 함수는 **0개**다.

그런데도 지금 세운다. 이유가 하나 있다.

---

## 1. ★ 왜 지금인가 — 나중에 오는 게이트는 빚을 만난다

오늘 세 번, 판정을 지킨 것은 게이트가 아니라 사람의 눈이었다:

1. 적용본이 등록부를 참조하지 않아 `GridSetting` 479행을 채우려 함 — 시뮬레이션이 잡았다
2. 저널이 한 줄로 쓰이는 결함 — 적용 전 코드 검토가 잡았다
3. 타임아웃 게이트가 저장소를 안 보고 있었음 — 실행 로그가 알려줬다

셋의 공통점은 **판정이 먼저 있고 게이트가 나중에 왔다**는 것이다.
나중에 오는 게이트는 이미 쌓인 빚을 만나고, 그러면 래칫으로 잠그는 수밖에 없다 —
`verify_classification.py` 가 **빚 113건을 안고 출발한 것**이 정확히 그 모양이다.

> **커널은 아직 한 줄도 없다. 여기서만은 빚 0 으로 시작할 수 있다.**
> K1 의 첫 커밋부터 이 게이트가 서 있으면 래칫이 필요 없다.

---

## 2. 무엇을 보나

| 검사 | 판정 |
|---|---|
| 커널 모듈 최상위 **공개 함수**(`_` 로 시작하지 않는 것) | `@tenant_scoped` 가 있거나 `KERNEL_PUBLIC` 에 **사유와 함께** 등재되어야 한다 |
| 모르는 커널 디렉터리 | **실패.** C-1 의 K1~K7 에 없는 이름은 커널이 아니다 — `KERNEL_NAMES` 와 DA-04 §4 표를 같은 커밋에서 고쳐야 한다 (D-264 계열) |
| `PUBLIC_ROUTES` 전건 | 사유가 있어야 한다 — 사유 없는 면제는 미분류와 구별되지 않는다 |
| `PUBLIC_ROUTES` 건수 | **증가금지 래칫** (현재 4건). 늘면 실패 |
| `PUBLIC_ROUTES` 를 못 읽음 | **실패.** 이름·형태가 바뀌었다면 게이트도 함께 고쳐야 한다. 못 읽은 채 통과시키지 않는다 |

### 2-1. PUBLIC 래칫이 막는 것

미분류(UNREVIEWED)를 줄이는 **가장 쉬운 방법은 PUBLIC 으로 옮기는 것**이다.
그 길을 막지 않으면 커버리지는 오르고 노출은 그대로 남는다.
면제 추가는 대표 승인 사항이고, **이 수를 조용히 올리는 것이 그 승인을 건너뛰는 방법**이다.

## 3. 무엇을 보지 **않나** — 경계를 분명히 한다

라우트 단위 스코프(현재 실재하는 것)는 이 게이트가 아니라
`backend/tests/test_route_tenant_scope.py` 가 본다. 그쪽은 Django 를 띄워 라우트를
열거해야 하므로 pre-commit 에서 돌릴 수 없다.

**같은 것을 두 곳에서 세지 않는다** (원칙 1: 중복 0).
두 곳이 세면 언젠가 두 수가 갈리고, 그때 어느 쪽이 진실인지 알 수 없게 된다.
그래서 이 게이트는 Django 없이 정적으로 판정할 수 있는 것만 본다.

## 4. 주입 시험 — 게이트가 실제로 멈추는가

커널이 없으므로 **미래를 주입해서** 시험했다.

| 주입 | 기대 | 결과 |
|---|---|---|
| `kernels/k1_event/probe.py` 에 스코프 없는 공개 함수 `list_events` | exit 1 | **exit 1** · "C-3.1" 위반 검출 |
| 같은 함수에 `@tenant_scoped()` 를 걺 | exit 0 | **exit 0** |
| `kernels/k9_unknown/` 디렉터리 생성 | exit 1 | **exit 1** · "모르는 커널" 검출 |
| `PUBLIC_ROUTES` 에 면제 1건 추가 | exit 1 | **exit 1** · "면제가 4 → 5 로 늘었다" |
| 전부 되돌림 | exit 0 | **exit 0** · 작업 트리 깨끗 |

> 되돌리기는 `git checkout` 을 쓰지 않고 **원본 복사본**으로 했다 —
> 오늘 그 명령으로 커밋 안 된 MinIO 수정본을 날린 적이 있다 (gate_timeout.md §5).
