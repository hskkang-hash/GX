# UX-16 — 월(Wall) 모드 (차선 C1 · 2026-09-05 턴 D)

대장 정의: 「월(Wall) 모드 `/wall` — 지도 + 미처리 큐 + 카메라 맥박」
사유: 「관제실 대형 화면에는 마우스가 없는데 지금 화면은 데스크톱 전용이다.
최소 글자 24px · 자동 갱신 · 로그인 세션 12시간.」

대상 화면: `frontend/src/features/dsm/pages/Wall.tsx` (조율자 자리표를 채웠다)

---

## 1. 무엇을 만들었나

| 파일 | 무엇 |
|---|---|
| `frontend/src/features/dsm/pages/Wall.tsx` | 자리표를 지우고 세 칸을 채웠다 (고침) |
| `frontend/src/features/dsm/hooks/useCameraPulse.ts` | 「카메라 상태」 문을 **방어적으로** 읽는다 (새 파일) |

경로 `/wall` 은 조율자가 이미 `App.tsx` · `routes.ts` 에 등록해 두었다 —
**두 파일을 건드리지 않았다.**

### 세 칸

    ┌──────────────┬────────────────────┬──────────────┐
    │ 지도          │ 지금 처리할 것       │ 카메라 상태    │
    │ 좌표 산포     │ 등급·유형·경과시간    │ 응답 없음 /   │
    │              │ ×N · 처리 단계       │ 마지막 응답 N  │
    └──────────────┴────────────────────┴──────────────┘

**한 칸이 죽어도 나머지가 산다.** 세 칸은 서로 다른 자원(`useDsmResource`)을 갖는다.

### 글자 — 라이브러리에 맡기지 않았다

이 화면은 antd 를 **한 개도 쓰지 않는다.** 평범한 상자와 글자로만 짰다.
라이브러리 기본값은 14 이고, 그 14 는 어느 구석에서 조용히 되살아난다 —
3m 밖에서는 없는 글자다. 선언한 크기 전수:

    [24, 24, 24, 24, 24, 28, 28, 28, 32, 32, 40, 40]   · 12건 · 최소 24

판정기가 이 파일의 크기 선언을 전부 세고 **24 미만이 하나라도 있으면 빨개진다.**
선언이 0건이어도 빨개진다 — 0건은 통과가 아니라 **못 잰 것**이다.

### 멈춘 화면과 평온한 화면을 가른다

머리 한 줄이 **자동 갱신 중** · **마지막 갱신 N분 전**을 스스로 말한다.
그 상대시각이 스스로 자라야 하므로 5초짜리 화면 시계를 따로 둔다 — 안 그러면
**그 줄 자체가 얼어붙어 거짓말을 한다**(판정기가 `setInterval` 의 실재를 센다).
갱신 주기는 20초다.

갱신이 실패하면 낡은 자료를 **지우지 않고** 위에 크게 적는다:
「불러오지 못했습니다. 아래는 마지막으로 받은 내용입니다.」
권한이 끊기면(401/403 → `forbidden`) 「이 항목에 대한 권한이 없습니다. 다시
로그인해 주십시오.」를 32 크기로 적는다 — **대형 화면에서 세션이 죽은 것이
평온으로 보이면 안 된다.**

### 카메라 상태 — 아직 없는 문을 부른다

`GET /api/dsm/cameras/pulse` 는 차선 C2 가 이번 턴에 내는 문이고 **병합 전에는 없다.**
그래서:

- 부르는 자리를 **따로** 둔다 — 이 칸의 404 가 지도와 큐에 닿지 않는다.
- 응답 모양을 **아는 이름부터 차례로** 물어본다
  (배열: `cameras`/`items`/`results`/`rows`/`data`/`pulses`,
  이름: `name`/`stream_monitor_name`/`camera_name`/`title`/`label`,
  생사: 불리언 `alive`/`online`/`ok`/… 또는 문자열 `status`/`state`,
  시각: `last_seen_at`/`last_frame_at`/`last_pulse_at`/…).
- **못 알아들으면 그 칸만** 「카메라 상태를 불러오지 못했습니다」로 말한다.
- 생사를 모르면 `null` 이다 — **「응답 없음」으로 적지 않는다.** 「죽었다」와
  「모른다」를 합치면 멀쩡한 카메라가 죽은 것으로 보인다.

### 지도 — 바깥 지도를 부르지 않았다 (판단과 사유)

저장소의 지도 컴포넌트(`components/maps/*`)는 카카오·구글 **열쇠**를 요구한다
(`VITE_KAKAO_API_KEY` · `VITE_GOOGLE_MAPS_API_KEY` — `.env.example` 에 자리표만 있다).
열쇠가 없거나 사설망이 막히면 그 컴포넌트는 **아무 말 없이 빈 사각형**이 된다 —
이 화면이 가장 피해야 할 모양(「사건이 없다」와 구별되지 않는 그림)이다. 그리고
그 판단을 브라우저 없이 검증할 방법이 없다.

그래서 좌표를 **우리 손으로** 찍었다: 큐 카드의 `lat`/`lng` 를 경계 상자에 맞춰
SVG 에 산포하고, 바깥으로 나가는 요청은 0건이며, 좌표가 없으면 「지도에 표시할
위치가 없습니다」로 적고, 아래에 「위치를 아는 카드 N장 · 전체 M장」을 함께 적는다.

⚠ **이것은 배경 지도가 아니라 좌표의 상대 위치다.** 배경 지도가 필요하면 열쇠와
함께 조율자가 배선한다 — 아래 「조율자 배선 필요」 참조.

### 마우스 없는 조작

`R` 하나다(다시 시도 — 두 칸을 함께 다시 부른다). 화면 아래에 「단축키 R — 다시 시도」로
적어 둔다. 입력창 갈래는 큐 화면과 **같은 함수**(`isTypingTarget`)를 쓴다 — 두 벌을 두지 않는다.

## 3. 못 쟀고 왜 못 쟀나

| 못 잰 것 | 왜 |
|---|---|
| **3m 밖에서 읽히는가** | 실제 대형 화면과 사람이 필요하다. 판정기가 잰 것은 **선언된 크기**이지 읽히는 크기가 아니다 |
| 세 칸이 실제로 **따로 죽는가** | 브라우저를 안 열었다. 자원이 셋이라는 것은 소스에서 보이고, **동작은 안 봤다** |
| `cameras/pulse` 응답을 실제로 읽는가 | 그 문이 **아직 없다**. 모양은 C2 가 정한다 — 읽기 갈래는 방어적으로만 짰고 실측이 아니다 |
| **로그인 세션 12시간** | 아래 참조. **판정 불가**이고, 지금 값으로는 **못 버틴다** |

### 로그인 세션 12시간 — 재 본 것

`backend/config/settings.py` (§0.4 밖이지만 여러 차선이 함께 쓰는 공용 설정이라
**고치지 않았다**):

```python
NINJA_JWT = {
    "ACCESS_TOKEN_LIFETIME": timedelta(minutes=200),   # 3시간 20분
    "REFRESH_TOKEN_LIFETIME": timedelta(days=7),
    "ROTATE_REFRESH_TOKENS": True,
    ...
}
```

**접근 토큰이 200분이다 — 12시간이 아니라 3시간 20분이다.** 12시간을 버티려면
클라이언트가 재발급을 돌려야 하는데, 그 재발급은 `rj-core` 의 `createApiClient`
안에 있고 `rj-core` 는 **§0.4 금지구역**이며 이 환경에는 **설치조차 되어 있지 않다**
(`frontend/node_modules` 가 비어 있고 `rj-core` 는 사설망 git+ssh 의존이다).
그래서 「12시간 버틴다」를 **초록으로 적지 않는다 — 판정 불가**다.
월 모드가 할 수 있는 일은 세션이 끊긴 것을 **크게 말하는 것**뿐이고, 그것은 했다.

## 4. 다음 사람이 브라우저에서 확인할 것 세 줄

1. `/wall` 을 열고 **가장 작은 글자를 재라** — 24 미만이 하나도 없어야 한다.
   자리표 글자(「이 화면은 아직 준비 중입니다」)가 보이면 이 절은 **안 닫힌 것**이다.
2. 서버를 끄고 **20초 이상 기다려라** — 화면이 그대로 있으면 안 되고,
   「불러오지 못했습니다」가 뜨고 「마지막 갱신 N분 전」의 **N 이 계속 자라야** 한다.
3. C2 의 `cameras/pulse` 가 붙기 **전과 후**를 둘 다 보라 — 붙기 전에는 오른쪽 칸만
   「카메라 상태를 불러오지 못했습니다」이고 **지도와 큐는 계속 돌아야** 한다.
   붙은 뒤에는 이름과 「응답 없음」/「마지막 응답 N분 전」이 떠야 한다.
