# OPS-16 — **계량 표의 0행은 백엔드에서 나오지 않는다** (턴 H · 차선 E · 2026-09-06)

> 차선 C 가 턴 G 에 화면(`Metering.tsx`)에서 「0행이 부품 기본 빈 그림으로 떨어진다」를
> 발견했다. **화면은 차선 C 의 것이라 손대지 않았다.** 여기서는 백엔드가 0행을
> 어떻게 내는지만 쟀다.

## 0. 결론 — **백엔드는 0행을 낼 수 없다**

`apps/dsm/metering.py::usage_series()` 는 언제나
`recent_months(months)` **길이만큼** 행을 만든다. 그리고 그 함수는

```python
count = max(1, min(int(count), MAX_MONTHS))     # MAX_MONTHS = 24
```

로 **바닥을 1 로 물린다.** 그러므로 행 수의 하한은 **1** 이고 0 이 아니다.
`usage_csv()` 도 머리줄 + 그 행들이라 언제나 2줄 이상이다.

[실측 2026-09-06 · 개발 DB · `months` 인자를 비틀어 봤다]

    recent_months(0)  → ['2026-09']      (1행)
    recent_months(-3) → ['2026-09']      (1행)

## 1. 실제로 무엇이 나오는가 — 테넌트 둘을 그대로 세어 봤다

`gx-shell` 에서 `TenantScope.of(user)` 로 `usage_csv(months=6)` 을 불렀다.
**행은 언제나 6개**이고, 빈 것은 행이 아니라 **칸의 값 0** 이다.

```
달,카메라 대수,쓰는 사람 수,이벤트 수,보낸 알림 수,저장 용량
2026-09,4,29,22,120,1493917814          ← ETRI-Group
2026-08,3,20,0,0,1493917814
2026-07,3,19,0,0,1493917814
...
2026-09,9,25,0,0,379668206              ← Anyang: **여섯 달 내내 이벤트 0 · 알림 0**
```

★ 즉 화면이 받는 것은 **「행이 없다」가 아니라 「값이 0 인 행이 여섯 개」**다.
`Anyang` 은 여섯 달 전부 이벤트 0 · 알림 0 이라 **참말로 0 인 표**이고,
그 표를 「빈 그림」으로 그리면 **잰 0 이 안 잰 것처럼 보인다.**

## 2. 백엔드는 「0」과 「못 쟀다」를 **이미 갈라서** 보낸다

`usage()` 의 칸 하나는 이렇게 나간다:

| 상황 | 응답 |
|---|---|
| 참말로 0 | `{"value": 0, "state": "ok"}` |
| 못 쟀다 | `{"value": null, "state": "unknown", "why": "…"}` |

CSV 에서도 못 잰 칸은 **빈 칸**으로, 0 은 **`0`** 으로 나간다
(`usage_csv` 머리말: 「0으로 적으면 표계산기가 그것을 0으로 더한다」).

→ **그러므로 화면이 `value` 의 참·거짓만 보면 안 된다.** `0` 은 falsy 이고,
falsy 를 「비었다」로 읽는 순간 **잰 0 과 안 잰 null 이 같은 그림**이 된다.
갈라 주는 칸은 이미 응답에 있다: **`state`**.

## 3. 백엔드가 표를 **안 주는 갈래는 하나뿐이다 — 그리고 그것은 0행이 아니라 422 다**

`usage()` 는 요청자에게 소속이 없으면 `LookupError` 를 던지고,
`law_api.py` 가 그것을 **HTTP 422** 로 바꾼다:

```
요청자에게 소속이 없어 사용량을 셀 수 없습니다.
소속 없이 센 수는 누구의 사용량인지 답할 수 없습니다.
```

[실측 2026-09-06 · 개발 DB] 살아 있는 계정 **112명 중 소속 없는 계정 3명**
(`AnonymousUser` · `huy` · `chi`). 이 셋으로 로그인해 계량 화면을 열면
**빈 표가 아니라 422** 가 온다.

→ 화면이 422 를 조용히 삼켜 「행 0개」로 만들면 그것도 빈 그림이 된다.
그때 사람이 볼 문장은 **위 한국어 사유**이지 빈 그림이 아니다.

## 4. 이 문서가 **말하지 않는 것**

- `frontend/src/.../Metering.tsx` 를 **열지도 고치지도 않았다.** 화면은 차선 C 의 것이다.
- 화면이 위 둘(값 0 · 422) 중 **어느 쪽을 빈 그림으로 만들고 있는지**는 여기서 안 쟀다.
  잰 것은 「백엔드가 무엇을 보내는가」 하나다.
