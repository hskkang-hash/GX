# P-77 — **게이트가 화면 글자의 42%를 안 보고 「통과」를 냈다**

[실측 2026-09-06 · 턴 H · 차선 Q] `scripts/verify_ui_copy.py` · `docs/agent/verify_gates.sh::gate_ui_copy`

## 무엇이 안 보였나

턴 G 까지의 술어는 이 한 줄이었다:

```python
JSX_TEXT = re.compile(r">([^<>{}]*[가-힣][^<>{}]*)<")
```

`{}` 를 배제한다. 그래서 **JSX 본문에 보간이 한 번이라도 끼면 그 본문 전체가 안 보였다.**
화면에는 떠 있고, 게이트는 「잔여 0 · 통과」를 냈다. **D-433 이 UX-20 을 닫은 근거가 그 수였다.**

## 앞뒤 — 같은 43개 화면 파일

| 재는 것 | 낡은 정규식 파서 | JSX 전수 파서 |
|---|---:|---:|
| 한글이 든 JSX 본문 조각 | **80** | **137** |
| 못 보던 조각 | — | **57 (42%)** |
| JSX 본문 조각 전수(한글 없는 것 포함) | 80 | 211 |
| **본 비율**(한글 글자 기준) | **91.8%** (6,129/6,673) | **100.0%** (6,673/6,673) |
| 걸린 위반 | **0건** | **2건** |

★ 「본 비율 91.8%」와 「JSX 조각 42% 못 봄」이 다른 이유: 화면 한글의 대부분은 **문자열
리터럴**에 있고 그쪽은 낡은 파서도 봤다. 못 본 42%는 **조각 수**이고, 그 조각들이 짧아서
글자 수로는 8.2%다. **그 8.2% 안에 두 위반이 다 있었다.**

## 다시 잰 잔여 — **2건** (이름으로)

```
frontend/src/features/dsm/pages/DrillMode.tsx    [출처 칩]  data_source =
    <Tag>data_source = {current.data_source}</Tag>          (훈련 모드 화면 · 현재 상태 카드)

frontend/src/features/dsm/pages/FocusQueue.tsx   [절 ID]    F-14
    「… 위 두 수가 다른 것이 그 약속의 증거이고, F-14 통계는 왼쪽 수를 봅니다.」
```

⚠ **UX-20 절을 다시 열지 않는다 — 잔여로 센다**(세종 판정). 래칫(D-311) 기준선에
이 둘을 이름으로 잠갔고, 게이트는 이제 매 실행마다 **「잔여 2건」**을 적는다.
기준선 18건은 그 전 턴에 다 갚혀 있었다(갚은 것 18 · 잔여 0) — 이번 2건은
**갚은 자리에서 새로 드러난 것**이지 갚은 것이 되살아난 것이 아니다.

## 게이트가 바뀐 것 셋

1. **파서를 JSX 전수로 바꿨다** — 텍스트 노드 · 문자열 리터럴 · 템플릿 리터럴(보간으로
   잘라서) · 속성값(`placeholder`·`title`·`aria-label`·`alt` …). 되돌아가지 않는 한 벌 훑기.
   `<` 를 만나면 **식이 올 자리인가**를 먼저 묻는다 — 그 술어가 없으면 `a < b` 와
   `Array<T>` 에서 파서가 새고, 샌 파서는 조용히 파일 하나를 통째로 안 본다.
2. **첫 줄이 「본 비율 N%」다.** 90% 미만이면 **회색(exit 2)** — 커버리지를 모르는
   게이트는 판정한 것이 아니다.
3. **자기시험에 출생 표본 ②를 박았다** (`BIRTH_JSX`) — 위 두 자리를 조각 뽑기까지
   끝까지 돌린다. `scan_line` 만 시험하면 **파서가 눈이 멀어도 초록**이다. 그것이
   2026-09-06 까지 이 게이트가 있던 상태였다.

## 본 비율은 무엇으로 재나 — **파서 밖의 잣대**

바뀐 파서에게 「다 봤느냐」를 물으면 언제나 100%다. 그 대답은 아무것도 재지 않는다.
그래서 분모를 파서가 만들지 않게 했다: **주석을 걷어 낸 화면 소스에 남은 한글 글자 수**.
그 글자가 어느 조각에도 안 담기면 그만큼을 못 본 것이다. 파서가 어디선가 새면 이 수가 떨어진다.

⚠ 이 잣대가 못 세는 것: **순영문 본문**(`data_source = live`)에는 한글이 없다. 본 비율은
「파서가 샜는가」를 재는 수이지 「빠짐없이 걸렀는가」를 재는 수가 아니다.

## 재현

```
$ python scripts/verify_ui_copy.py --self-test
[COPY] 자기시험 통과 — 양성 3(문구) + 2(JSX 파서) · 음성 8

$ python scripts/verify_ui_copy.py

[COPY] [입력] 43개 화면 파일 (주석 걷어낸 뒤) · 패턴 7종
[COPY] 잔여 2건 (기준선 2건 · 갚은 것 0건)
[COPY] 통과 — 새로 생긴 대장 언어 0건

$ bash docs/agent/verify_gates.sh --gate ui-copy
  PASS  판정기 자기시험 통과 (양성 3 문구 + 2 JSX 파서 — 그날 화면 그대로)
  [입력] 43건 — 화면 파일의 사용자 본문 (문자열 몸통·JSX 본문)
        [COPY] **본 비율 100%** …
        [COPY] 잔여 2건 (기준선 2건 · 갚은 것 0건)
  PASS  [COPY] 통과 — 새로 생긴 대장 언어 0건
```

⚠ 같은 턴 안에서 한글 글자 수가 6,673 → 6,651 로 움직였다 — **다른 차선이 화면 파일을
고치고 있다.** 본 비율은 100% 로 같다(파서가 새지 않았다는 뜻이고, 그것이 이 수의 일이다).
