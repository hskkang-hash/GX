# N2 승격 제안 — 턴 AP (WO-19 · P-421 · 차선 N2 → N2b 이어받음)

**조율자가 대장에 적용한다 — 이 문서는 제안만 한다.** 대장(`ga_readiness.yaml`)은 손대지 않았다.
앞 차선 N2 가 도구 오류로 끊긴 작업본을 N2b 가 이어받아 끝냈다. 눈금은
`docs/agent/evidence/SPEC/TITLE_PARTS_RULE.md` 그대로(닫힘 앞머리 measured/present/있음/구현 ·
`excluded_by` 는 P-428 = 운영 집행·외부 실연동만).

## 1. 올릴 절 — **없음 (0)**

일곱 절 모두 코드·증거는 채웠지만 **열린 행이 1개 이상** 남아 반쪽이다. 반쪽은 닫힘이 아니므로
대장 이동을 제안하지 않는다. 게이트 행도 새로 만들지 않았다(올릴 절이 없다).

## 3. 앞 차선 N2 의 변경 중 **되돌린 것**

- **「심각(critical) 등급은 근무 외 차단을 넘는다」 예외** — 명세 제목·완결조건에 없는 예외를
  지어낸 것이고, `_blocked_reason` 에 넣은 그 예외가 DSM(U3) 차단 계약까지 풀어
  `test_u3_webpush_send.RulePathTest` 두 건을 빨강으로 만들었다(실측 2 failed).
  `kernels/k2_notify/services.py` 를 HEAD 그대로 되돌렸다(이제 diff 0) · 시험·증거 표에서 그 행을 뺐다.
  `webpush.py` 의 `CRITICAL_BYPASS_SEVERITY`/`severity=` 인자는 조율자 소유 파일이라 두었다
  — 부르는 쪽이 없어 죽은 분기다(§조율자에게 참조).
- **지어낸 문턱값 45도·10분·300m** — 「모르는 값은 짓지 않고 이름만」에 따라 뺐다.
  `alerts.py` 는 `apps.fws.constants` 의 세 이름을 부를 때마다 읽는다.
- **F4-13 등급→구간 문턱 대응**(critical→86 등) — 그것도 심각도 근사라 버렸다.
