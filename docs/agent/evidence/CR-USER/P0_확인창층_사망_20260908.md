# P0 — 확인창 층 전체가 렌더되지 않는다 (import 한 줄)

## 무엇이 죽었나
`antd` v5 의 **정적 메서드**(`Modal.confirm` · `message.*`)는 React 19 에서 제거된
`ReactDOM.render` 를 쓴다. 공식 해법은 `@ant-design/v5-patch-for-react-19` 다.

| 잰 것 | 값 |
|---|---|
| `frontend/package.json:79` | `"react": "^19.0.0"` |
| `frontend/package.json:117` | `"antd": "^5.25.0"` |
| `frontend/package.json:25` | `"@ant-design/v5-patch-for-react-19": "^1.0.3"` ← **선언돼 있다** |
| `grep -rn 'v5-patch-for-react-19\|unstableSetRender' frontend/src` | **0건** ← **아무도 import 하지 않는다** |
| `main.tsx` 첫 줄들 | 그 import 없음 |
| 배포 번들 `/app/_fe_dist/assets` 에서 `unstableSetRender` | **0건** |

**의존성은 설치됐고 배선은 안 됐다.** 그래서 확인창도 토스트도 **한 번도 뜨지 않는다.**

## 두 차선이 독립으로 같은 것을 쟀다
- U1 차선: 클릭 뒤 2초·5초에 **문서 전체**(포털 포함) 세기 →
  `.ant-modal` **0** · `.ant-modal-confirm` **0** · `[role=dialog]` **0** · `textarea` **0** ·
  `document.body.children` **1**(포털 컨테이너가 생기지도 않았다) · React 오류 **0** · pageerror **0**
- U2 차선: 별개 계정·별개 하네스 · 4.5초 DOM 확인 → **모달 0 · 요청 0 · JS 오류 0**

**대조(같은 화면·같은 세션·수 초 차)**
| 누른 것 | dsm API 호출 | 결과 |
|---|---|---|
| 「실제로 판정」 (확인창 경유) | **0** | 판정 그대로 「미판정」 |
| 「접수하기」 (확인창 없이 직행) | `POST /events/4808/response?to_state=acknowledged` **200** | 미처리 → **접수** |

클릭은 닿고 React 핸들러도 돈다. **확인창을 지나는 길만 죽어 있다.**

## 반경 [실측]
| 종류 | 전체 | 우리 제품 화면 |
|---|---|---|
| `Modal.confirm` | **3** | 3 (`EventDetail.tsx:164` 진위 판정 · `:237` 되돌리기 · `MobileEventDetail.tsx:185` 되돌리기) |
| `message.*` | **11** | 10 |
| `Modal.info/warn/error/success` · `notification.*` | 0 | 0 |

죽는 일:
1. **진위 판정**(실제/오탐 둘 다) — U1 ⑪ · U2 ③ · FC 페인포인트 #2
2. **되돌리기**(사유 필수) — 데스크·모바일 둘 다
3. **성공 안내 전부** — 성공한 동작조차 아무 말이 없다(「처리 단계를 「접수」로 옮겼습니다」가 뜬 적 없다)

세 번째가 특히 나쁘다: **성공했는데 화면이 침묵**하므로 사용자는 실패로 읽고 다시 누른다.

## 고침 (적용하지 않음 — 이 점검은 읽기 전용)
`frontend/src/main.tsx` 맨 위 한 줄:
```ts
import '@ant-design/v5-patch-for-react-19';
```
※ 고친 뒤 반드시 **재빌드 + `_fe_dist` 교체**해야 한다. 번들에는 「이 탐지를 실제로 판정합니다」
문자열이 이미 들어 있다 — **코드는 배포됐고 실행만 안 된다.**

## 왜 게이트가 못 잡았나 — 다음 턴의 진짜 숙제
`verify_screens` · `capture_screens` 는 **화면을 열어 찍는다**. 확인창은 **누른 뒤에** 뜨므로
촬영 경로에 없다. FC 표 #2 는 「상세에 판정 칸이 그려졌다」를 근거로 0.5 를 줬다 — **그려진 것은
맞고 눌리는 것은 아니었다.** 「그려졌다」와 「동작한다」를 가르는 술어가 게이트에 없다.
