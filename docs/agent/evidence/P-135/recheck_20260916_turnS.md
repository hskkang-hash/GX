# 게이트 계정 10/10 재확인 — 턴 S 조율자 ① [실측 2026-09-16]

지시서 §3 조율자 ① 「역할 계정 10/10」. P-135 회전(`rotation_20260915_194428.json`)이
적은 **그 열 계정**을 다시 쟀다.

## 무엇을 쟀나 — 그리고 **무엇을 안 쟀나**

| 잰 것 | 안 잰 것 |
| --- | --- |
| `.env.gates` 의 값이 **DB 해시와 맞는가** (`check_password`) | 실제 로그인이 **되는가** (HTTP · 세션 발급) |

**HTTP 로 두드리지 않았다.** 이유 둘 — 둘 다 재려던 행위가 사고가 되는 자리다:

1. **잠금.** dj-core 는 실패를 `Attempts N/5` 로 세고 다섯이면 잠근다. 값이 갈려 있으면
   「확인하려던 일」이 곧 **게이트 계정 열 개를 잠그는 일**이 된다. 값이 맞는지 모르는
   상태에서 두드리는 것은 확인이 아니라 도박이다.
2. **동시 접속 1개.** 로그인은 앞선 세션을 끊는다(`end_previous_session`). 이 턴은 차선
   다섯이 도는 중이고 V 단독 세션이 뒤에 온다 — 조율자가 열 번 로그인하면 그 측정을
   미리 죽인다(턴 R 에 같은 이유로 FC 가 경합 수 50.0 을 냈다).

`check_password` 는 **HTTP 를 타지 않으므로** 잠금 카운터를 안 올리고 세션도 안 끊는다.
이 A/B 는 새로 지어낸 것이 아니라 D-457 에서 이미 쓴 가름법이다.

## 읽는 법 — 이 표가 **말하지 않는 것**

* 이것은 「로그인 10/10 초록」이 **아니다.** 자격이 맞는다는 것과 문이 열린다는 것은 다르다
  (`token/pair` 로 들어가면 세션 없이 401 이 나고, 그 401 을 「살아 있다」로 읽은 거짓 초록이
  2026-09-17 에 실제로 났다). **실제 로그인은 V 단독 세션이 잰다** — 그때가 첫 로그인 수다.
* 명령줄에 값이 오르지 않았다. 호스트 셸이 `.env.gates` 를 펼쳐 `docker exec -e 이름` 으로
  **이름만** 건넸다(`gx-shell` 에는 저장소 뿌리가 마운트돼 있지 않아 컨테이너 안에서
  `.env.gates` 를 읽는 길이 아예 없다 — `/repo/backend`·`/repo/scripts`·`/docs` 뿐이다).
* ⚠ 만약 한 줄이라도 **불일치**로 나왔다면 그것을 바로 「자격이 끊겼다」로 읽으면 안 된다 —
  셸 소싱은 `#` 이후를 주석으로 자르므로 **읽는 눈이 틀린 경우**가 먼저다(D-457). 이번엔
  열 줄 다 일치라 그 갈래로 갈 일이 없었다.
