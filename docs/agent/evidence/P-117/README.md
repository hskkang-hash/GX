## ④ 이번 턴에 걸린 함정 하나 — **`gx-shell` 의 `/repo/docs` 는 호스트에 안 닿는다**

`gx-shell` 의 바인드 마운트는 `scripts → /repo/scripts` · `backend → /app`·`/repo/backend` ·
`frontend → /repo/frontend` · `docs → **/docs**` 다. **`/repo/docs` 는 마운트가 아니다.**
그래서 컨테이너 안에서 게이트를 부르며 `--out /repo/docs/...` 를 주면 산출물이
**컨테이너 안에만** 떨어지고, 호스트에는 **옛 파일이 그대로 남아 새 산출물처럼 보인다.**
이번에 실제로 그랬다 — 호스트 사본은 `measured_at: 2026-09-05` 인 채였고 컨테이너 안은
`2026-09-10` 이었다. **컨테이너에 위임하는 게이트는 산출 경로를 `/docs/...` 로 준다.**
