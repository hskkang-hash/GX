# P-71 후속 — **깃발은 둘인데 하나만 봤다** [실측 2026-09-06 · 턴 G · 조율자]

## 세 차선이 같은 빨강을 따로 가져왔다

| 차선 | 보고한 것 | 붙인 이름 |
|---|---|---|
| E | 시험 두 파일 **36 errors** | 「내 변경 때문이 아니지만 확인은 못 했다」 |
| C | **모든** 모듈이 죽는다 | 「환경이다(회색)」 |
| V | `--nomigrations` 로 **65 errors** | 「환경 결함이지 코드 결함이 아니다」 |

셋 다 같은 문장을 봤다:

```
CommandError: App 'user' does not have migrations.
```

★ **셋 다 「환경」이라고 불렀고, 셋 다 틀렸다.** 자기 차선 밖에서 온 빨강은
환경처럼 보인다 — 옆 차선이 만든 회귀도 그렇게 보인다. 그 둘을 가르는 것은
차선 하나가 아니라 **전체를 보는 자리**의 일이다.

## 뿌리 — 판별자 한 줄

P-71 훅은 「마이그레이션이 꺼진 실행이면 끼우지 않는다」를 이렇게 물었다:

```python
disabled = self.connection.settings_dict.get("TEST", {}).get("MIGRATE") is False
```

그런데 **pytest-django 의 `--nomigrations` 는 그 칸을 안 건드린다.**
대신 `settings.MIGRATION_MODULES` 를 「무엇을 물어도 `None`」인 물건으로 갈아 끼운다.
그래서 판별자가 「켜져 있다」고 답했고, 훅이 `migrate user` 를 불렀고,
`user` 앱은 그 실행에서 마이그레이션이 없으므로 `CommandError` 가 났다.

**끄는 방식이 둘인데 한 자리만 봤다.** 훅은 자기 자신의 조건에 걸려 넘어졌다.

## 고침 — 깃발을 세지 말고 **사실을 잰다**

```python
def migrations_are_disabled(app_labels) -> bool:
    from django.db.migrations.loader import MigrationLoader
    return all(MigrationLoader.migrations_module(a)[0] is None for a in labels)
```

「이 앱에 태울 마이그레이션이 있는가」를 **장고 자신의 로더**에게 묻는다.
세 번째 도구가 또 다른 방식으로 마이그레이션을 꺼도 이 술어는 그대로 맞는다.

## 실측 — 앞뒤

```
[앞] docker exec gx-shell python -m pytest /app/tests/test_be_metering.py -q --nomigrations
     21 errors in 3.66s
[뒤] 같은 명령
     21 passed, 34 warnings in 31.04s
```

★ **3.66초 대 31.04초.** 빨강이 8배 빨랐다 — 아무것도 안 했으니까.
「시험이 왜 이렇게 빨리 끝나지」는 그 자체로 신호다.

## 되돌아오지 않게 — 시험 셋 (`backend/tests/test_s_conftest_bootstrap.py`)

1. **pytest-django 가 끄는 그 방식**을 세워 놓고 묻는다 — `TEST['MIGRATE']` 는
   건드리지 않는다(그것이 이 회귀의 조건이었다).
2. **음성 대조군** — 마이그레이션이 실재하는 앱(`contenttypes`)을 「꺼졌다」로 읽지 않는다.
   언제나 True 를 내는 술어는 우회층을 조용히 끈다.
3. 빈 목록에 `all()` 은 True 다 — **그 파이썬 규칙이 우회층을 끄면 안 된다.**

`pytest /app/tests/test_s_conftest_bootstrap.py` → **7 passed**.

⚠ 새 시험 클래스 이름을 `TheDisabledRun…` 으로 지었다가 **한 건도 안 걷힐 뻔했다.**
이 저장소에는 `pytest.ini` 에 `python_classes` 선언이 없어 기본값 `Test*` 가 적용된다 —
`…Test` 로 끝나는 기존 클래스들이 걷히는 것은 그것들이 `django.test.TestCase` 라서다.
**초록이 아니라 「0건 수집」이 나올 자리였고, 0건은 초록처럼 보인다.**
