# SEC — **틀린 토큰은 401 이 아니라 500 이다** · 읽기 면 **364/364**
[실측 2026-09-23 · 턴 AF · 조율자(영실)]

## ① 무엇을 잰 것인가 — 그리고 **왜 이 수가 어제는 없었나**

턴 AE 에 조율자가 「가짜 헤더로 364자리 **0건**」을 냈고 그것을 커밋(`709a5aa`)·보고·
대표께 **잰 수라고 올렸다.** 그 수는 **틀렸다** — 차선 S 가 잡았다:

```
probe_read_surface.measure(caller, method, url, principal, query)
                                                ^^^^^^^^^  ^^^^^
                                                주체        질의값
```
다섯째 자리는 **질의값**이다. 조율자가 거기에 `{"Authorization": …}` 을 넣어
그 글자는 URL 뒤에 `?Authorization=Bearer+…` 로 붙었을 뿐, 진짜 헤더는
`Caller.call()` 의 `token` 인자로만 만들어진다 — **한 번도 안 실렸다.**
「익명」과 「가짜」는 **같은 요청**이었다. 그 0 은 **분모 0 인 초록**이다.

S 가 고친 판으로 **조율자가 다시 쟀다.** 유출은 **여전히 0 이다** —
**그러나 그 0 의 이유가 다르다.**

## ② ★★ 잰 것 — 유출은 0, 그런데 **답이 401 이 아니다**

```
읽기 면 전수 364자리 · 익명 한 번 · 틀린 토큰 한 번 [조율자 실측]

익명      401×341 · 200×13(공개 선언) · 500×4 · 400×3 · 404×3
틀린 토큰  500×364        ← 전부
```

한 자리를 골라 **모양별로** 갈라 보면:

| `Authorization` 에 실은 것 | 답 |
|---|---|
| 없음(익명) | **401** ✅ |
| `Bearer ` (빈 값) | **401** ✅ |
| `Basic YWJjOmRlZg==` | **401** ✅ |
| `Bearer gx.bad.token`(쓰레기 글자) | **500** ❌ |
| 모양만 JWT · **서명 틀림** | **500** ❌ |
| 모양만 JWT · **만료 + 서명 틀림** | **500** ❌ |

### 뿌리
```
jwt.exceptions.DecodeError: Invalid header string: 'utf-8' codec can't decode …
  … core/middleware/refresh_token.py:173
  … core/middleware/refresh_token.py:204
```
**dj-core 의 미들웨어**다. 미들웨어라 **모든 요청**에 걸린다 — 그래서 364자리 전부다.
`ninja_jwt` 가 던지는 `DecodeError` 를 그 자리가 **안 잡는다.**

## ③ 무엇이 사실이고 무엇이 **아직 안 잰 것인가** — 과장하지 않는다

**사실이다**:
- **자료는 안 샜다.** 유출 0/364 — 틀린 토큰으로 자료를 받은 자리는 없다.
- **틀린 토큰 하나로 읽기 면 전부가 500 이 된다.** 익명에게 **200 을 주던 공개 자리
  13개**까지 500 이 된다 — 그 열셋은 자격증명이 아예 필요 없는 자리인데도 그렇다.
- 500 마다 **트레이스백이 로그에 쌓인다**(차선 S 가 시험 285초의 사유로 관측).
- **거절과 고장을 못 가른다** — 지켜보는 사람이 「막혔다」와 「죽었다」를 구별할 수 없다.

**아직 안 쟀다**:
- ⚠ **진짜 만료 토큰**(서명이 **유효**하고 `exp` 만 지난 것)이 401 인지 500 인지는
  **안 쟀다.** 위 표의 「만료」 표본은 서명도 틀렸으므로 서명 검사에서 먼저 죽는다.
  진짜 만료 토큰을 만들려면 **서명 비밀키**가 필요하고, 이 창에서 그것을 쓰지 않았다.
  ⇒ **「사용자가 매번 500 을 본다」고 적지 않는다.** 그건 아직 모른다.
  ⇒ 그러나 **「아무나 틀린 토큰 한 줄로 모든 자리에 500 을 만들 수 있다」는 잰 사실이다.**

## ④ 고칠 자리 — **우리 손 밖이다**(§0.4)

`core/middleware/refresh_token.py` 는 **dj-core** 다. §0.4 금지구역이라 **읽기·호출만**
할 수 있다. 걷기 W1 의 dj-core 422 와 같은 자리다.
⇒ **손 밖 선언**으로 적되, **회색으로 바꾸지 않는다.** 이것은 **잰 빨강**이다.
⇒ 우리가 할 수 있는 것 둘:
  1. **게이트가 이 사실을 세게 한다** — 「틀린 토큰에 500 을 내는 자리 수」를 분모와 함께.
     지금 `gate_fake_bearer_regression`(차선 S 신설)은 **자료 유출**만 센다.
     유출 0 은 초록인데 **세상은 364/364 가 500** 이다 — **게이트가 세상을 다 말하지 않는다.**
  2. 인수 코드 결함으로 **등재**하고 공급자에게 올린다(계약 자리).

## ⑤ 이 문서가 남기는 한 줄

> **0 이라는 수가 같다고 같은 사실이 아니다.**
> 어제의 0 은 「가짜 헤더를 안 보냈다」였고, 오늘의 0 은 「보냈는데 자료가 안 나왔다」다.
> 그리고 오늘의 0 옆에는 **어제 없던 364 라는 빨강**이 있다.
