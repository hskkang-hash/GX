# P-189 2차 — **내가 만든 거짓 회색** (2026-09-19 · 턴 W · 차선 Q · V 가 잡았다)

## 무엇이 났나

이 턴에 내가 `verify_click_completes.py` 의 증거 쓰기 자리에 넣은 되읽기 검사가
**언제나 회색**을 냈다. `--measure` 가 **exit 2** 로 끝났고, 측정이 안 된 것이 아니라
**판정기 결함**이었다.

```python
OBSERVED.write_text(_redact_credentials(_text), ...)   # 가려서 쓴다
_back = OBSERVED.read_text(...)
if json.loads(_back) != json.loads(_text):             # ← _text 는 **가리기 전** 원문
    return EXIT_UNDECIDABLE                            #    그래서 언제나 어긋난다
```

증거에는 카카오 지도 `appkey=` 가 **18곳** 있어 `_redact_credentials` 가 **언제나**
작동한다. 그러므로 저 비교는 **언제나 참이 아니다.** V 가 컨테이너 원본과 저장소 사본을
`appkey` 만 맞춰 대 보니 **차이는 가린 문자열뿐**이었다 —
**증거는 유효했고, 게이트가 아니라고 말한 것**이다.

> **거짓 초록만 위험한 것이 아니다. 거짓 회색도 위험하다.**
> 회색은 조용하다. 몇 턴 지나 누가 「FC 는 원래 회색이야」로 읽기 시작하면,
> 내가 막으려던 바로 그 일(증거가 증거 노릇을 못 하는 것)이 **게이트 뒤에 숨어서** 난다.
> 이 턴에 F 가 「회색이 빨강을 덮고 있었다」로 증명한 그대로다.

## 고친 방향 — 칸을 **둘로** 나눴다 (약하게 만들지 않았다)

가리기는 **쓰기 전에 일어나는 정당한 변형**이지 인코딩 손상이 아니다. 그래서
`evidence_roundtrip(raw, written, read_back)` 을 두고 칸을 갈랐다:

| 칸 | 무엇을 견주나 | 무엇을 잡나 |
|---|---|---|
| ① **되읽기** | **쓴 것** == **다시 읽은 것** | 인코딩·줄바꿈 손상 |
| ② **가리기** | 가리기 **전후의 판정 수**가 같은가 + 가린 자리 수 | 가리기가 값이 아닌 것을 지우는 것 |

②를 그냥 빼지 않은 이유: 빼면 「가리기가 수를 바꿔도 아무도 안 본다」가 된다.
가린 자리 **수만 세는 것보다 강하게**, **가리기 전후의 판정 수가 같은지**를 본다.

## 진짜 증거(162KB)로 되짚었다 — 장난감 표본이 아니다

저장된 증거의 `REDACTED-…` 를 가짜 키로 되돌려 「가리기 전 원문」의 모양을 되살리고 돌렸다:

```
저장된 증거: 162,827바이트 · 가려진 자리 18곳
되살린 원문: 162,593바이트 · 가릴 자리 18곳
가린 뒤:     162,827바이트 (차이는 가린 문자열뿐)

지금 판정 → 초록
    ① 되읽기: 쓴 것과 다시 읽은 것이 **같다**
    ② 가리기: 자격 **18곳**을 가렸고 **수는 그대로다** (29, 4, 15)
    셈: {'가린 자리': 18, '수(가리기 전)': (29,4,15), '수(가린 뒤)': (29,4,15)}

종전 판(가리기 전 원문 vs 쓴 파일) → **회색 (언제나)**
```

★ ② 가 「가리기가 수를 바꾸지 않았다」를 **수로** 말한다 — 18곳을 가려도 29/48 그대로다.

## 변이 시험 — 이 시험이 그 결함을 **실제로** 잡는가

고친 코드에 종전 판(`written = raw`, 즉 가리기 전 원문과 견준다)을 도로 심고 자기시험:

```
[P-118] X [P-189] 되읽기 검사가 틀렸다 2건:
[P-118] 자기시험 **실패**   (exit 1)
```

자기시험에 박은 갈래 다섯: ① **가리기가 일어난 판이 초록인가**(← 이 결함의 출생 표본) ·
② 가릴 것이 없는 판도 초록이고 가린 자리를 0으로 적는가 · ③ 다시 읽은 것이 다르면 빨강 ·
④ **가리기가 수를 바꾸면 빨강** · ⑤ cp949 로 깨진 판은 빨강.

## 안 한 것 — **`--measure` 를 다시 돌리지 않았다**

돌리면 `docs/agent/evidence/P-118/click_completes.json` 을 **내 측정으로 덮는다.**
이 턴의 FC 수는 **V 가 낸 것**(29/48 · `measured_at=2026-09-19T10:13:05Z`)이고,
정본을 고친 내가 그 자리에 앉으면 「고치는 사람과 재는 사람이 다르다」가 깨진다.
그래서 위 되짚기는 **V 가 쓴 그 증거**를 읽어서만 했다.
`--measure` 의 exit 0 은 **V 가 다음에 돌릴 때** 나온다.
