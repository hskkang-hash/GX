**절차 정본은 여기가 아니다.** 한 덩이로 붙여 넣는 절차는
`docs/agent/RUNBOOK_로컬기동.md` 의 **STEP 2D** 에 있다. 두 벌로 적으면 어긋나고,
어긋난 뒤에는 어느 쪽이 정본인지 아무도 모른다(D-369).

## 이 턴에 **하지 않았다** — 그리고 왜

세종 판정 P-55 는 「재기동한다」이고 시점은 **병합 직후 · 다른 에이전트 정지 뒤 ·
15분**이다. 2026-09-05 20:xx 현재 다섯 차선이 `gx-shell` 안에서 시험 DB(`test_gx_*`)를
만들고 지우는 중이고, QA/E2E 차선은 8500 으로 부하를 내고 있다. `postgres` 를 내리면
앞엣것이 한꺼번에 죽고, 앞단을 내리면 뒤엣것의 측정이 끊긴다(지시서 §4 함정 ④).

**재기동이 필요한 조치를 「했다」로 적지 않는다.** 절차를 남기고 왜 안 했는지를
적는 것이 정직한 산출이다.

## 창을 열기 직전의 상태 — `pre_window_state.txt`

로그 상한이 **없는** 컨테이너 다섯: `gx-shell` · `postgres` · `redis` ·
