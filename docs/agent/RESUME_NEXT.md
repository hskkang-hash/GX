## 0. 먼저 — 게이트가 우리 커널을 막은 것이 이번 턴의 성과다

C-3.1 게이트가 **첫 커널 커밋을 멈춰 세웠다.** 그리고 그 이유가 정확했다: `tenant_scoped` 는 `request` 를 못 찾으면 그냥 통과시키므로, 커널에 붙이면 **표식만 남고 아무것도 안 막는다** — 착시 ①(부착률)의 재현이다. 게이트가 자기 자신이 만들 뻔한 착시를 잡았다. 임의로 확정하지 않고 P-K1-1 로 올린 것도 옳다.

```
D-281  P-K1-1 확정 — C-3.1 을 계층별로 나눈다 (커널에는 데코레이터를 쓰지 않는다)

  판정: 커널 계층(L3)에서 request 기반 데코레이터 사용 금지.
        대신 **테넌트 없이는 호출 자체가 불가능한 시그니처**로 만든다.

   · HTTP 계층(뷰): @tenant_scoped() 유지 — request 가 실제로 있으므로 유효하다.
   · 커널 계층(L3): 스코프를 **키워드 전용 필수 인자**로 받는다.
       def list_events(*, scope: TenantScope, ...)   # scope 없으면 호출 자체가 불가
     데코레이터는 "붙였는가"만 보지만, 필수 인자는 **부르는 쪽이 테넌트를 알아야만** 호출된다.
     표식이 아니라 구조다 — 우회할 자리가 없다.
   · 네 제안(통과 형태로 문지기 호출을 더해 요구 수준을 올림)도 함께 채택한다. 시그니처가 1차, 문지기가 2차.
   · 게이트: verify_tenant_scope 에 **"커널 공개 함수 중 scope 인자 없는 것 = fail"** 을 추가하라.
     C-3.1 문언은 이 판정으로 개정된 것으로 본다(임의 이행 아님 — 승인부다).
```

## 1. ★ 초록의 다섯 번째 착시 — 환경 (D-282)

```
D-282  착시 ⑤ 환경 — "시험 환경이 실물과 다르면 초록은 실물을 말하지 않는다"
  · 대응 게이트(신설): 마이그레이션 정합 검사를 CI 에 넣는다.
      python manage.py makemigrations --check --dry-run   → 미반영 모델 변경이 있으면 exit 1
    "모델 14건 / 표 0건" 같은 격차가 조용히 유지되는 것을 막는다.
  · 원칙: --nomigrations 는 **속도용 보조 수단**이지 정본 판정 환경이 아니다.
    최소 1개 시험 경로는 실제 마이그레이션을 적용한 DB 에서 돌아야 한다.

  ▣ 착시 5형 (매 보고 자가점검)
    ① 부착률(D-249) ② 시나리오 수(D-262) ③ 모수와 술어(D-271) ④ 탐지기 자체(D-277) ⑤ **환경(D-282)**
    ①~③ = 무엇을 얼마나 쟀나 · ④ = 재는 기계가 작동하나 · ⑤ = **재는 자리가 실물인가**
```
