## 1. Gate 0 — 로컬 100% 기동 (선행, 변함없음)

**§2(WP-2)는 로컬에서 격리 시험이 실제로 돌아야 착수 가능하다.** R1 증거는 지금까지 probe 복제본에서만 나왔다 — 저장소 자체가 로컬에서 기동·시험되지 않으면 봉인을 검증할 수 없다.

→ `docs/agent/RUNBOOK_로컬기동.md` 실행 (직전 지시 그대로): build 폴더 인벤토리 → dj-core 설치본/사본 수색 → venv 이식 → `import core.base` 관문 → `manage.py check` → 프론트 기동 → 미검증 재고 1,217줄 검증.
- 경로 A(로컬 설치본 발견) 성공 → **Gate 0 통과, §2 착수.**
- 경로 A 실패(셋 다 없음) → 목록만 보고 STOP. 운영서버 회귀는 대표 접근확보 후.
