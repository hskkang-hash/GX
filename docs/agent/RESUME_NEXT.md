## 0. 판정 — 임계경로(W0-13) 3갈래 전부 확정

```
D-261  W0-13 백필 판정 — 갈래별 3분할 확정 (P-W0-13-1/2 답)

 (a) 부모 상속 가능 23,616행 → 【적용】
     - 소유가 부모 레코드에서 결정론적으로 도출되므로 추측이 아니다.
     - 조건: dry-run 리포트 첨부(D-209) + 역방향 롤백 스크립트 동시 작성 + 사전 백업(D-002).
       롤백 스크립트 없이 적용 금지 — 23,616행은 되돌릴 수 없으면 사고다.

 (b) terminals.Terminal 3,399행 → 【분할】 단일소유 1,809 적용 / 미사용 1,590 백필하지 않음
     - 역추론 모호 0건이므로 1,809행은 적용. 나머지 1,590행은 소유자를 "추측"하게 되므로 채우지 않는다.
     - 다만 【보류】로 두지 말고 상태를 명시하라: tenant_unassigned 로 표기하고,
       격리 시험에 "전역 관리자 외 어떤 테넌트에도 비노출"을 기대값 단언으로 고정.
       → 미분류가 조용히 남는 것이 아니라, 선언된 상태가 되고 시험이 지킨다.

 (c) 공용 마스터(Timezone·Country·GridSetting 등) ~2,000행 → 【백필 금지】 확정
     - 네 판단이 옳다. 채우면 다른 테넌트 화면에서 국가·시간대가 사라진다.
     - 조치: shared: true (PUBLIC 분류)로 면제대장에 명시 등록 + 근거 1줄씩.
       격리 시험 기대값은 "전 테넌트 조회 가능" — 이것도 단언으로 고정한다.
       PUBLIC 은 검사 면제가 아니라 "공용임을 시험으로 증명한 것"이어야 한다.

 → 이 판정으로 W0-13 해제. W0-13 → W0-14c(652 확대) 로 바로 진행하라.
```

## 1. ★ EXIT 재정의 — "누출 0건"이 거짓 완결이 될 뻔했다

네 §4(5)가 잡아낸 것: **격리 시험이 보는 모델 9종 / 실제 테넌트성 모델 131종.** 나머지 122종에 대해 우리가 말할 수 있는 것은 "누출 없음"이 아니라 **"모른다"** 이다. 이 상태로 EXIT 하면 D-249에서 고친 것과 **똑같은 실수의 재발**(부착률 → 이번엔 시나리오 수)이다.

```
D-262  WP-2 EXIT 조건 1 재정의 — 시나리오 수가 아니라 "모델 커버리지"로
  기존: 재현 누출 0건 · 시나리오 5/5              ← 대상 9종에서만 성립. 불충분.
  개정: ① 시나리오 5/5 green (유지)
        ② P0 6종 전수 격리 시험 통과 (누출 0건) — 신설, EXIT 필수
        ③ P1 17종: 시험 계획 등재 + WP-2 EXIT 후 착수 일정 명시 (EXIT 필수 아님)
        ④ P2 99종: 각각의 분류 사유를 문서로 첨부 (자동 면제 금지 — D-263)
  → "우리가 무엇을 검증했고 무엇을 아직 모르는지"를 EXIT 문서가 스스로 말하게 한다.
     에스비 검수의 "보안 점검 통과"도 이 문서로 답한다.

D-263  P2 99종 자동 면제 금지 (네 경고 수용)
  - "라우트 없음"으로 자동 면제하면 미분류가 면제로 위장하고, 시험은 초록이 되고 노출은 남는다.
  - 93종은 같은 앱에 단건 경로가 있다 → 면제 불가. UNREVIEWED 로 명시 등록하고 사유를 기재하라.
  - 측정 결함 시정: delivery 12모델이 똑같이 "단건 23건"으로 나온 것은 앱 단위 매칭의 산물이다.
    앱 단위 매칭 금지 → 모델별 실경로 매칭으로 재측정. 수가 커서 진척처럼 보이는 수는 버린다.

D-266  재난안전 App 선결 격리 2종 — WP-DA2 착수 전 필수
  - P0 6종 중 flight_log.FlightLog(308행, F-13 정찰) · surveillance.VideoAnalysis(117행, F-01~03)는
    DSM App 이 직접 쓸 데이터다. 에스비 채널은 고객사별 분리가 전제이므로,
    이 2종의 격리가 닫히지 않은 상태에서 WP-DA2(10월 코드) 착수 금지.
  - 이 2종을 P0 6종 중 최우선으로 처리하라.
```
