## 2. ★ 판정 요청이 아니라 판정 지시 — juso 가 역방향을 주는가 (D-318)

승인키가 왔으니 이제 **실측이 가능하다.** 그런데 실측 전에 내가 붙여야 할 우려가 하나 있다.

```
D-318  FX-5 최우선 실측 — juso.go.kr 이 「좌표 → 주소」를 주는지 실호출 1회로 판정하라

  ▣ 우려(추정이다. 그래서 확인 요청으로 붙인다 — D-304):
    juso.go.kr 주소정보 연계서비스의 주력은 **「검색어 → 도로명주소」**와 **「주소 → 좌표」**다.
    우리가 FX-5 에서 필요한 것은 **그 반대 방향(좌표 → 도로명주소, 역지오코딩)**이다.
    ★ 만약 juso 가 역방향을 주지 않으면, 키가 와도 FX-5 는 열리지 않는다.
      그때는 다른 소스가 필요하고, 그건 **어댑터 설계가 아니라 자원 선택의 문제**다.

  ▣ 그래서 이것이 이번 턴에서 **가장 값싸고 가장 파급이 큰 한 걸음**이다.
    호출 1회 · 30분 · 결과에 따라 FX-5 전체 설계가 바뀐다. **빨리 알수록 좋은 것**의 전형이다.

  ▣ 지시 — 순서를 지켜라
    ① 승인키 2건이 **각각 어느 API 의 키인지** 확인한다(신청서가 둘이다. 시스템명은 같다).
       → 키를 값으로 구분하지 말고 **신청서의 API 명으로** 구분해 vault 에 이름표를 붙인다.
    ② 각 키로 **실호출 1회.** 요청·응답 원문을 evidence/ 에 남긴다(키 값은 마스킹).
    ③ 판정 셋 중 하나를 답으로 내라
         ㉠ 역방향 지원 → 스키마 스냅샷을 시험에 박고 어댑터 착수 (D-315 판 고정 재사용)
         ㉡ 정방향만 → **FX-5 를 KERNEL_READY=False 로 유지**하고 DA 에 「자원 부재」로 사유 교체.
            대체 후보를 조사만 하고 **고르지는 마라** — 자원 선택은 내가 판정한다
         ㉢ 판정 불가(권한·승인 대기 등) → 그 사실 자체를 사유로 적는다. 추정으로 채우지 마라
  ▣ ★ 어느 경우에도 **응답을 보기 전에 어댑터를 만들지 않는다**(D-298·D-280). 이건 아직 유효하다.
  ▣ 강제 도구: `JUSO_REVERSE_SUPPORTED` 를 `unknown | yes | no` 3값으로 두고,
    `unknown` 인 채로 juso 어댑터 파일이 존재하면 **exit 1**. D-290(3값 구분) 그대로.
```

## 4. SDN — 잠금의 성격이 바뀌었다 (D-320)

```
D-320  CONTRACT 잠금 상태 전환: 「미발송」 → 「발송·회신 대기」. 기산점을 도구가 센다

  ▣ 발송 완료를 인정한다. 이로써 **계약 6조3항(협조 지연 시 이행기한 자동 연장)의 기산점이 섰다.**
    이건 개발 진척이 아니라 **계약상 지위의 변화**다 — 이제 지연의 책임 소재가 문서로 남는다.
  ▣ blockers.yaml 의 CONTRACT 항목에 필수 칸 셋을 더한다:
        sent_at   : 발송일          due_by : 회신 기한(발송 + 15일. 계약 3조2항 준용)
        elapsed   : 게이트가 매 실행마다 계산해 출력한다
  ▣ 강제 도구: `verify_blockers.py`
     · CONTRACT 항목에 sent_at 이 비면 exit 1
     · due_by 경과 시 **exit 0 이되 표지에 「SDN 회신 지연 N일」을 반드시 출력**한다
     → 잠김이 조용히 늙지 않게 한다. **시간이 지나는 것이 화면에 보여야 협상 카드가 된다.**
  ▣ E2E-3·F-13/14 는 그대로 잠김. 표준(포트·수령요건 34건)은 서 있으므로 **수령 즉시 어댑터만 채운다.**
```

## 7. 대표께 — 하실 일이 없습니다

**ADMIN 잠금이 0건이 되었습니다.** 오늘 처리하신 것으로 우리 손 밖의 잠김은 **SDN 하나만** 남았고, 그것도 발송문이 나갔으니 이제 **기다림이 아니라 기록**입니다 — Code 가 회신 지연 일수를 매 실행마다 화면에 출력하게 했습니다.

| 항목 | 상태 |
|---|---|
| SDN API 명세 | **발송 완료** → 회신 기한 자동 계산. 지연 일수가 표지에 뜹니다 (계약 6조3항 기산) |
| juso 승인키 2건 | **발급 완료** → Code 가 실호출 1회로 방향(좌표→주소)을 확인합니다 |
| data.go.kr 18건 | **전건 승인** → 제품 직결 3종 확보. FX-1·FX-2·FX-6 착수 조건 충족 |
| CCTV·국립공원·아동센터 | **신청 불필요로 판정** → 대장에서 내렸습니다 (사유 §5) |

한 가지만 참고로 — **승인키가 화면 캡처로 대화에 남았습니다.** 등록 URL 이 www.guardianx.com 으로 한정되어 위험은 낮고 저장소에는 절대 들어가지 않게 막아 두었습니다. 다만 **재발급이 마음 편하시면 지금이 가장 싼 시점**입니다. 아직 아무 코드도 그 키에 묶여 있지 않습니다.
