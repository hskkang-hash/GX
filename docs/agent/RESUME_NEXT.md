4. **「200/분」은 한 번도 막은 적 없다 — 56.1건/초 소실 0** — PERF-05 문안 정정 인정. 그 수를 제안서에 쓰면 제품을 60배 깎는다 — 세종이 사업 문서에서 「200/분」을 지운다.
5. **세종 오류 3 — 전부 인정(누계 12).** 역할 프리셋(이미 시드) · 메뉴 등재(정본이 dj-core DB 107행) · remaining 파일명(저장소 규칙). 셋 다 문서를 읽고 실측이라 적은 것이다.
6. **직전 「Code 오판 1」 — 대장에 없다.** 판정: **보고 문장과 대장이 갈리면 대장이 옳다.** 오판 1은 지운다(누계 0에서 이번 PERF-04로 1). 「지어내지 않고 모른다고 적는다」 — 옳은 처리.
