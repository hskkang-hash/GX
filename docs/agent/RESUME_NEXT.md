## §1 인정 · 오판 셈

1. **Q 차선을 빠뜨렸다고 첫 줄에 적었다** — 그리고 그 결과(온보딩 넷 턴째 회색 · probe 표식 없음)를 자기 오판으로 세었다. 옳다. **이번 턴 Q는 조율자가 20분 안에 먼저 띄운다**(P-159) — 다섯 뒤가 아니라 앞에.
2. **없는 게이트를 근거로 차선 셋을 오지목했고, 차선 F가 바로잡았다**(D-480). 지목이 틀렸음을 결정 문서 첫 줄에 적은 것 — 인정. 「판정기는 있었다 · 없던 것은 커밋 자리였다」 — 훅을 커밋 자리에 단 것이 처방이다.
3. **거짓 초록 셋을 분모를 물어서 걸렀다**(tsc 미끼 · 마운트 0 · 훅 0) · 차선 F도 같은 함정에서 자기 보고 한 줄을 철회했다. 「판정기가 아무것도 안 봤다」 계열을 이름으로 부른 것 — 원칙 등재: **분모 0인 초록은 초록이 아니다.**
4. **재부팅 실측 9/10 · 앞단이 뒷단보다 2초 먼저 떠 죽었다** — 「자동 시작 켬 = 복귀」가 아님을 실측으로 적었다. 인정. 처방은 `restart: always`가 아니라 **기동 순서**(P-161). 09-15 10/10과 오늘 9/10 — 같은 절차가 다른 결과를 내면 절차가 아니라 순서가 문제다.
5. **막힌 시간 60분을 따로 셌고 그중 34분이 자기 도구 실수라고 적었다**(CRLF · 백슬래시). 인정. `--all-files`로 422파일을 건드리고 되돌린 것도 스스로 적었다 — 커밋엔 안 들어갔다.
6. **좋았던 것 셋**(U24가 자기 청을 뒤집음 D-479 · U3가 짐작을 안 받고 확인 · U56이 못 본 것을 못 봤다고 적음) — 이것이 파 2 「짓기」에서 가장 값진 줄이다. 차선이 조율자의 짐작을 거절한 것은 위임 이의가 아니라 **실측 우선**이다.
