## 1. 이벤트 OpenAPI 인증 방식 — 판정한다 (D-335)

네가 요청한 판정이다. 그리고 **선행은 D-334다** — 열린 문을 두고 문패를 정하지 않는다.

```
D-335  F-05 진입면 인증 — 들어오는 API Key + 테넌트 귀속. 만들지 않고 잇는다

  ▣ 방식: **헤더 API Key.** OAuth2·JWT 는 과하다 —
    상대는 서버-투-서버 기계이고, 계약 상대는 [인용·계약] 에스비 한 곳이다. 사람 로그인이 없다.
    ★ 과한 인증은 안전을 주지 않고 **연동 실패를 준다.** 상대가 못 붙이면 F-05 는 초록이어도 죽은 면이다.

  ▣ 규약 다섯 — 전부 시험으로 건다
    ① **키는 테넌트에 묶인다.** 키로 들어온 요청은 그 테넌트 범위 밖을 절대 못 본다(D-269).
       남의 자원 요청은 **404**. 403 아님 — 존재도 알리지 않는다
    ② **HTTPS 강제.** 평문 요청은 거부한다. 키가 평문으로 흐르면 키가 아니다
    ③ **읽기 전용부터.** 지금 여는 것은 이벤트 조회뿐. 쓰기 면은 **절을 따로 세운다**
       (계약 AC 절에 쓰기가 있는지 절 표에서 먼저 확인하라 — 없으면 만들지 마라)
    ④ **키 값은 저장하지 않는다.** 해시만 둔다. 조회는 언제나 마스킹(D-204·표 ②와 같은 규약)
    ⑤ **부작위**(D-300): 키 인증을 통과한 요청이 **원본 영상·타 테넌트 식별자에 닿는 경로가 0건**임을 시험한다

  ▣ ★ 발급·폐기는 **만들지 않는다.** 네가 찾은 것을 쓴다:
      · `core.apikey_account` (dj-core) — **§0.4 금지구역이다. 수정하지 마라.**
        ★ 다만 D-207 은 **수정 금지이지 사용 금지가 아니다.** 읽고 호출하는 것은 허용된다.
        확장이 필요하면 **우리 층에서 감싼다**(L3 어댑터). 금지구역 안으로 손을 넣지 마라.
      · `third_api/views/api_key_controller.py` — 우리 것. 여기에 잇는다.
  ▣ ★ 이건 D-333("밖을 사기 전에 안을 뒤진다")의 안쪽 판이다:
    **밖을 사기 전에 안을 뒤지고, 만들기 전에 이미 있는지 뒤진다.**
    「남은 일은 만들기가 아니라 잇기」 — 네 문장을 그대로 정본으로 올린다.
```

## 2. ★ 네가 스스로 더한 것 — 전면 승인한다 (D-336)

> "표 ①에 `contract_fixed` 칸을 더했습니다. 없으면 **'임계값을 설정 가능하게 만들었다'가 곧
>  '계약 AC를 설정 가능하게 만들었다'**가 됩니다."

**이건 내가 놓쳤고 네가 잡았다.** 그리고 이 문장은 원칙으로 올릴 값이 있다.

```
D-336  「계약이 정한 값은 설정이 아니라 상수다」 — contract_fixed 채택 + 원칙 승격

  ▣ 채택. 그리고 확장한다 — 409 로 멈추는 것만으로는 부족하다.
    ★ **게이트가 contract_fixed 항목의 값이 계약 AC 원문과 일치하는지 검사한다.**
      표의 값이 [인용·계약] F-04 「5분」· F-10 「30초」에서 벗어나 있으면 **exit 1.**
      런타임 덮어쓰기는 409 로 막고, **저장된 값 자체가 틀린 것은 게이트가 막는다.** 둘 다 필요하다.
    ★ 그리고 각 `contract_fixed` 항목에 **절 번호를 링크하라.** 계약 절과 표의 행이 서로를 가리키면,
      계약이 바뀔 때 무엇을 고쳐야 하는지 사람이 찾지 않아도 된다.

  ▣ 원칙: **설정 가능성은 기능이 아니라 위험이다.** 무엇을 설정 가능하게 만들 때마다
    「이 값이 계약·안전·법에 걸려 있는가」를 먼저 묻는다. 걸려 있으면 상수다.
    · 이건 D-324(금지선은 행위에 긋는다)의 이웃이다 — **유연성도 금지선이 필요하다.**
  ▣ 「다르게 보시면 판정 주십시오」에 답한다: **다르게 보지 않는다. 네 판단이 옳다.**
    앞으로도 이런 것은 **묻기 전에 넣어라.** 넣고 사유를 적으면 내가 뒤에서 판정한다 —
    그 반대(묻고 기다리기)는 네가 아는 것을 내가 모르는 채로 시간만 쓴다.
```

## 6. 대표께 — 오늘은 보고 두 줄과 부탁 하나입니다

**① 진척이 숫자로 보입니다.** 계약 기능 39개 절 중 **27개가 구현되어 증명 시험까지 붙었습니다(69%)** [실측]. 시험은 399건이 통과합니다. 잔여는 12개 절이고, 그중 8개는 SDN·영상재생·구역판정에 묶여 있습니다.

**② 보안 점검 하나를 최우선으로 돌립니다.** 코드에 **권한 검사가 주석 처리된 자리**가 발견됐습니다. 지금 실제로 열려 있는지는 아직 모릅니다 — 다른 층이 막고 있을 수도 있습니다. **추측하지 않고 호출해서 확인**하도록 지시했고, 열려 있으면 즉시 막고 사고로 기록합니다. 다른 곳에도 같은 것이 있는지 전수로 셉니다. 진척보다 이것을 앞에 놓았습니다.

> **부탁 하나 — 안양 카메라 39대의 설치 위치 목록이 있으면 주십시오.**
> 어제 말씀드린 「카메라에 주소를 적어 둔다」가 코드로 섰는데, **39대 전부 비어 있습니다.**
> 이건 우리가 만들 수 없는 정보입니다 — **현장을 아는 쪽이 아는 값**입니다.
> · 지금 당장은 없어도 됩니다. 개발·시연용은 Code 가 표본을 채워 증명합니다.
> · 다만 **실제 납품 시에는 한 번 채워야 하는 값**이라, 목록이 있으면 지금 넣어 두는 편이 낫습니다.
> · 형식은 자유입니다 — 「카메라 이름 / 도로명주소 / 현장 표현(정문·3층 복도 등)」 세 칸이면 충분합니다.

**SDN 은 회신 지연 일수가 매 실행 화면에 뜨고 있습니다.** 계약 6조3항 기산은 이미 서 있으니 따로 하실 일은 없습니다.
