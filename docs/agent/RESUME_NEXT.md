## §0 인정 — 게이트가 차선이 못 본 것을 잡았다

1. **아홉 절 · 동시 4 · 충돌 0 — 인정.** 데이터 격리 4/4가 첫 100% 영역이다.
2. **잠자는 기능 여섯 — 이번 병합의 진짜 값, 인정.** 「시험이 스스로 상태를 심으므로 전부 초록」 — 시험이 호출을 대신하면 운영에서는 죽어 있다. 원칙 등재: **시험은 부르지만 잇지 않는다 — 잇는 것은 제품이 한다.** 맥박 호출 0곳을 그대로 두었으면 OPS-15는 영원히 `None`을 보며 0건을 냈을 것이다. dormant 게이트가 그것을 막았다.
3. **거짓 초록(`InvalidNotifyInput` → 거절 목록) 막은 것 — 인정.** 거절≠도달(⑪)의 새 얼굴이다.
4. **차선이 지시서를 고친 자리 셋 — 전부 세종 오류.** ① 「네 시각은 모델에 이미 있다」 — `occurred_at` 하나뿐이었다. 칸 셋을 새로 만들지 않고 감사에서 세운 것이 옳다(빈 과거는 「대응이 빨랐다」로 읽힌다). ② ONVIF — 저장소에 0건. 없는 프로토콜 위에 탭을 만들지 않은 것이 옳다. ③ 역지오코딩 — 이미 「불가」(D-329)인데 재사용을 적었다. **세종 오류 누계 4 + 3 = 7.** 셋 다 문서를 읽고 [실측]이라 적었다 — 09-24 §0-3의 규칙을 세종이 또 어겼다. 이번 문서의 [실측]은 전부 대장·캡처·Code 보고 인용이다.
5. **회색 둘이 빨강 — 옳은 색.** OPS-07(수집기 5개 무한 적재)·OPS-10(사람에게 도달하는 경보 0)은 재 보니 없었다. 없는 것을 없다고 적은 것이 이번 턴의 값이다.

## §4 차선 규약 · 함정 여섯

1. **잇는 것은 제품이 한다.** 시험이 상태를 심어 초록이 나면 dormant 게이트가 잡는다 — 잡히면 그것은 빨강이다(D-421 원칙).
2. `SEC-04` 「데이터가 안 나왔다」≠「안전하다」. 관문 건 증거만.
3. `SEC-11` A2 전역 승격이 663건 중 296건을 갚았는지 **재호출 전수**로 잰다. 갚았으면 닫고, 남으면 남은 수를 적는다 — 「대부분」 금지.
4. `OPS-10` 이메일 1통은 **사람이 받았다**가 증거다 — 발송 기록이 아니라 수신함 캡처.
5. `UX-21` §0.4는 수정 금지이지 노출 의무가 아니다 — 메뉴 등재 제거 · 렌더 조건 · 한국어 헤더 래핑. 라우트는 그대로.
6. `UX-22` 등급 명칭 변경은 **표시만** — `severity` 값(info/warning/critical)은 계약 스키마다. 라벨 사전에서 매핑.

VLM(PERF-07)은 대표 결정 ④ 전 착수 금지. 웹훅(UX-19)은 F-05 구독 등록 위에 — 새 인증 경로 금지.
