## §0 답 먼저 — 커밋하라. 그리고 순차를 택했으면 사유 한 줄

1. **커밋하라.** 차선 A는 병합 단위다. 게이트 8·0·0·대기 2, 계약 진입면 20/20, 회귀 초록 — 커밋 조건이 다 있다. 규칙으로: **차선 하나가 병합 조건을 채우면 세종을 기다리지 않고 커밋한다.** 세종이 읽는 것은 커밋이다(09-16 Code 자신의 말). 작업 트리에 두는 것은 「아무도 안 본 것」의 사촌이다.
2. **차선 B~E 미착수 — 「순차 실행 선택에 따름」.** 지시서는 A∥E 동시 착수를 적었다. 순차를 택한 사유가 보고에 없다. 사유가 있을 수 있다(도구 제약·DB 공유·자원) — 그러면 **한 줄로 적어라.** 사유 없는 순차는 지시 미이행이다. 이번 턴은 §2의 자원 분리 규약(P-18) 위에서 **B∥E 동시**로 시작한다. 그래도 순차를 택해야 하면 그 제약을 이름으로 적고, 세종이 규약을 고친다.

## §2 P-18 병렬 실행 규약 — 차선이 서로 밟지 않게

순차를 택한 가장 그럴듯한 이유는 **자원 공유**다: 한 개발 DB·한 MinIO·한 포트·한 시드. 두 차선이 같은 DB에 시험을 돌리면 서로의 빨강을 만든다. 그래서 자원을 가른다.

```
▣ P-18 병렬 자원 분리 [판정]
   차선마다: git worktree 1개(../gx-lane-<X>, 브랜치 lane/<X>) · compose 프로젝트 이름 gx_<x> · DB 이름 gx_<x> · MinIO 버킷 접두 <x>_ · 포트 대역(A 8100 · B 8200 · C 8300 · D 8400 · E 8500 · V 8900) · 시드 테넌트 tenant_<x>.
   .env 는 차선마다 자기 것(gitignored) — 이름은 저장소 .env.example 하나에서 나온다(D-204). 값은 차선 로컬.
   조율자 본 트리(main)만 공용 등록부·병합·커밋. 차선은 자기 워크트리에서만 커밋(lane/<X>), 병합은 조율자가 rebase → 게이트 세 수 → 커밋.
   차선 에이전트 기동: 09-19 지시서 §2.1 골격(목표·소유 파일·선등록 쓰기 면·금지 전문·보고 형식·멈추는 조건) + 이 자원 표 한 줄.
   동시 상한 5. 이번 턴: B∥E 즉시 → B 병합·V → C∥D → C·D 병합·V → A2(P-3) → V(화면 21 재촬영) → E 병합·V.
   충돌 규칙: 두 차선이 같은 파일을 고쳤으면 나중 병합을 되돌리고 조율자가 소유를 갈라 다시 띄운다. 같은 게이트를 빨갛게 하면 나중 것을 되돌린다.
   순차를 택하면 사유 한 줄 — 「도구가 동시 에이전트를 못 띄운다」면 그렇게 적어라. 그러면 세종이 규약을 바꾼다. 사유 없는 순차는 없다.
```
