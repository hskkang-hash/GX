## §2 판정 8 — Critical Path 「결정 셋 + 선언 하나」 중 세종이 정할 수 있는 것을 전부 정한다 (집행)

### P-67 보존·백업 — **기본값이 아니라 선언으로. 개발·스테이징 값은 세종이 선언한다** [판정]

- **개발·스테이징 선언(세종 · 이 문서로 집행)**: 감사 로그 보존 **365일**(감사 대응 최소 · LAW-03 초안) · 스냅샷·구간 참조 **30일**(용량산정서 기본) · 백업 **매일 03:00** · 목적지 **별도 볼륨 `/backup`**(OPS-12a) · 백업 보존 **14일** · 복구 시험 **주 1회 자동**(`ops_restore` dry-run → RTO 실측 기록).
- **운영 값은 고객(U5)이 설정 화면에서 선언**한다 — 고지문(LAW-02)·방침(LAW-03)의 보존 기간 칸이 그 값을 읽는다. 대표 결정에서 뺀다.

→ **OPS-07b · OPS-19 닫는 조건.**

### P-68 SMTP — 역할은 정했다(U5) · 주소는 대표 · **주소 없이도 닫을 수 있는 반쪽**
「사람에게 도달」의 증거는 수신함 캡처다(변동 없음). 다만 **로컬 SMTP 수신함(MailHog/mailpit)** 을 게이트 환경에 세워 「발송→수신함 도착」을 **기계로 실측**한다 — 이것은 OPS-10을 닫지 않지만(사람 아님) 채널·규칙·허용 도메인이 **끝까지 도는 증거**다. 대표 주소가 오면 캡처 한 장으로 닫는다.

### P-69 재는 도구 셋 — 점검표 빈 33칸(폼·오류 흐름·빈 상태)
`walk_states.py`(Playwright · 요청 가로채기):
- **오류 흐름**: 화면별 핵심 API에 500·503·403·타임아웃(10s) **주입** → 화면이 「빈」이 아니라 「오류+다시 시도」를 그리는가 · 스피너 고착 0 · 오류 원문 0(GX-COPY).
- **빈 상태**: 테넌트 `tenant_empty`(카메라 0·이벤트 0·규칙 0)로 로그인 → 각 화면의 빈 문구가 사전과 같은가 · 「빈」과 「오류」가 다른 문구인가.
- **폼**: 필수 빈값 · 형식 오류 · 서버 거절(422) → 칸 옆 문구 · 저장 버튼 상태 · 이중 제출 0.
출력은 점검표 56칸에 **자동 기입**. 첫 수가 빨강이어도 그 색이 옳다.

### P-70 제품의 사실 vs 환경의 사실 — 게이트가 스스로 가른다
게이트마다 `env:` 블록(MinIO 도달 · SMTP 수신함 도달 · 마운트 일치 · 세션 점유자) 을 먼저 재고, 환경이 빠지면 **회색(exit 2 · 사유 = 환경 이름)**. **차선 이름 다섯**: 시험 DB · 포트 · 접두 · 테넌트 · **탐침 계정**(`gxprobe_<차선>`) — 동시 접속 1의 세션 빼앗김을 원천에서 없앤다. 게이트 서버 compose에 MinIO·mailpit 포함.
