## 0. ★ 적용 명령 — 승인한다 (D-267)

준비 4건(dry-run·백업·롤백 저널·로컬 복제본 확인)이 전부 충족됐다. **아래 명령을 실행하라.**

```
docker exec gx-shell sh -c 'cd /app && PYTHONPATH=/app python /gxscripts/backfill_owner_apply.py --apply \
  --dryrun-report /docs/agent/evidence/W0-13/backfill_dryrun.md \
  --backup /backup/gx_before_backfill.dump \
  --journal /docs/agent/evidence/W0-13/backfill_journal.jsonl'
```


## 1. 네가 잡은 것 2건 — 둘 다 판정이 옳았음을 증명한다

**잡은 것 1 (D-261(c) 위반)이 이번 턴의 최고 성과다.** 적용문이 분류 등록부를 참조하지 않아 `advanced_table.GridSetting`(479행)·`menu.Tab`을 채우려 했다 — 판정이 막으려던 바로 그 사고를, 시뮬레이션이 잡았다. 판정문만 있고 **판정을 강제하는 게이트가 없으면 판정은 지켜지지 않는다**는 것이 증명됐다 → D-270으로 정본화한다.

**잡은 것 2 (연쇄가 승인 범위 초과)도 정확하다.** 부모를 채우면 자식이 새로 물려 23,265 → 24,340이 되는 것 — 승인 수는 백필 前 독립 측정값이므로 초과다. 스냅샷 의미론으로 되돌린 것이 옳다 → D-269.

```
D-268  742행 2차 판정 — 【채우지 않는다】 확정 (네 보류 인정)
  - (b) 일반화 재유도로 나온 2,551/848 은 틀린 수가 아니지만, 그중 742행은 D-261이
    "채우지 않는다"로 분류한 대상이다. 지금 안 써서 잃는 것은 없고, 잘못 쓰면 되돌려야 한다.
  - 처분: 1,590행과 동일 취급 — tenant_unassigned 로 상태 명시 + 격리 시험에
    "전역 관리자 외 비노출" 기대값 단언 고정. 보류 상태로 남기지 않는다.
  - 재론 조건: 실제 사용처가 발견될 때만 3차 판정. 그 전에는 열지 않는다.

D-269  스냅샷 의미론 정본화 — 백필은 "계획 전체를 먼저, 쓰기는 그 다음"
  - 원칙: 대상 집합은 백필 前 상태에서 1회 확정하고, 쓰기 중 발생하는 연쇄 파급을 대상에 포함하지 않는다.
  - 이유: 연쇄를 허용하면 승인 수치가 실행 중에 움직여 "무엇을 승인했는지"가 사라진다.
  - 적용 범위: 이번 백필뿐 아니라 이후 모든 파괴적 데이터 변경에 동일 적용.

D-270  쓰기 안전 3원칙 정본화 (오늘 사고 재발 방지)
  ① 원자 교체: 파일 쓰기는 임시 파일 + os.replace. 원본을 truncate 하는 방식 금지.
     (io.open(p,"w",newline=...) 가 인자 검증 전에 truncate 해 24KB 스크립트가 0바이트가 된 사고)
  ② 연쇄 결합: 순차 실행이 전제인 명령은 반드시 && 로 묶는다. 앞이 실패해도 뒤가 도는 구조 금지.
     (잘린 파일이 컨테이너로 복사된 원인)
  ③ 등록부 참조 의무 + 게이트: 데이터를 쓰는 모든 스크립트는 분류 등록부(shared/PUBLIC/
     tenant_unassigned)를 반드시 참조하고, 참조하지 않으면 실행 자체가 실패하도록 게이트를 건다.
     → verify_kernel_map.py 의 "모르는 것을 만나면 멈춘다"(D-264)와 같은 계열의 원칙이다.
```

## 2. P0 종수 변경 확인 요청 (경미)

네 보고에 **"P0 15종 Target 동재"**로 적혀 있다. D-262가 EXIT 조건 ②로 못박은 것은 "P0 6종 전수"였다. D-263(모델별 실경로 재측정)의 결과로 6 → 15로 늘어난 것이라면 **재측정값이 옳으므로 15종이 EXIT 대상**이다. 다음 보고 첫 줄에 `P0=<종수> (근거: 재측정/기타)` 를 한 줄 적어라 — 숫자가 조용히 바뀌는 것만 막으면 된다. **D-266의 2종**(`flight_log.FlightLog` · `surveillance.VideoAnalysis`)이 그 안에 포함되는지도 함께 확인하라.
