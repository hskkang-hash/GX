## 2. ② juso 역방향 — **㉢ 판정 불가. 추정으로 채우지 않았습니다**

```
환경변수 GX_JUSO_API_KEY                        없음

```

대표께서 발급을 회신하셨고 그것을 의심하지 않습니다. 다만 **문서로 안 것을 계정에서 본
것으로 등재하지 않는다**(D-316)는 이번 턴의 원칙이 여기에도 그대로 걸립니다 —
발급된 것과 이 환경에 있는 것은 다른 사실입니다.

**대신 세운 것**(호출 1회면 판정됩니다):

* `scripts/probe_juso_direction.py` — 키를 환경변수에 넣고 한 번 돌리면 요청·응답을
  마스킹해 `evidence/D-318/` 에 남기고 ㉠/㉡/㉢ 을 냅니다. 키 없으면 **exit 2(판정 불가)**

* `JUSO_REVERSE_SUPPORTED = 'unknown' | 'yes' | 'no'` — 3값. 말씀대로 2값으로 두면
  **"안 준다" 와 "안 물어봤다" 가 같은 값**이 됩니다.
* `scripts/verify_juso_direction.py` — `unknown` 인데 **HTTP 구현이 있으면 exit 1**.

> **판단 1건 — 「어댑터 파일이 존재하면 exit 1」 을 「HTTP 구현이 있으면」 으로 읽었습니다.**
> 포트·저하 운전은 명세 없이도 확정할 수 있는 것이고(DA-02 §3), SDN 에서 이미 그 경계를
> 그었습니다. 문자 그대로 읽으면 이미 서 있는 포트가 즉시 빨간불이 됩니다. 다르게
> 보시면 말씀해 주십시오.

## 3. ⑤ 도구 자기표본 — **분모와 함께. 그리고 이 원칙이 세 번 값을 했습니다**

```
[TOOLSELF] 검사 27종 (게이트 7 + verify_*·check_* 20 · 측정기·생성기 29종 제외)
[TOOLSELF] 자기시험 16/27 · 출생 표본 3/27  →  채워서 10/27
```

물으신 수는 **3/27** 이었습니다. (지시서의 24는 추정치였고 실측은 27입니다.)
7종을 채우고 나머지 17종은 D-311 과 같은 이유로 **래칫**으로 잠갔습니다 —
소급 사유를 요구하면 사유란이 거짓으로 채워집니다.

### ★ 이 원칙이 이번 턴에 **세 번** 값을 했습니다

`verify_external_sources.py` 하나에서만 술어를 세 번 좁혔고, **세 번 다 반대편으로
넘어갔다가 자기시험이 그 자리에서 잡았습니다.**

| 판 | 술어 | 무엇이 틀렸나 |
|---|---|---|
| ① | 소스에 이름이 나오면 참조 | 독스트링의 **설명**이 참조로 잡혔다 (거짓 양성) |
| ② | 문자열을 통째로 버림 | `os.environ["X"]` 를 놓쳤다 — **환경변수는 늘 문자열** (거짓 음성) |
| ③ | 토큰을 공백으로 이어 붙임 | `os . environ [ "X" ]` 가 되어 정규식이 안 맞았다 |

지금은 **읽는 문법**(`os.environ[...]`·`settings.X` 등)을 봅니다. 반례 3종이 자기시험에
들어 있습니다.
