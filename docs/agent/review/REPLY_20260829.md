## 2. D-281 — 스코프는 표식이 아니라 시그니처다

`TenantScope` 를 L1 에 세우고 K1 공개 면 6개 전부를 `*, scope: TenantScope` 로 옮겼습니다.

사람 없는 호출은 **없애지 않고 이름을 붙여 셉니다**: `TenantScope.system(reason=…)` 은
사유가 필수이고 그것으로는 **읽지 못합니다**. `grep "TenantScope.system"` 한 줄로 전수가
세어집니다 — 수가 아니라 **이름**으로 잠그는 D-285 (2) 와 같은 계열입니다.

**곁가지로 쓰기 쪽 IDOR 을 막았습니다.** `record_detection` 이 사람 스코프로 불릴 때
`assert_scoped(StreamMonitor, …)` 를 먼저 부릅니다. 전에는 **아무나 남의
`stream_monitor_id` 로 남의 테넌트에 이벤트를 심을 수 있었습니다.**
시그니처만으로는 못 막습니다(스코프를 주기만 하면 되므로) — **시그니처 1차 · 문지기 2차**가
여기서 실질을 갖습니다.

게이트에 1차 검사를 넣고 **커널의 `@tenant_scoped` 는 반려**하게 했습니다.
양성 대조 4/4: 인자 제거 · 기본값 · 위치 인자 · 데코레이터 부착 — 넷 다 exit 1, 복구 후 0.

## 3. D-282 — 눈을 하나 더 달았습니다 (확인 요청)

**★ 양성 대조가 제 대조 코드를 먼저 잡았습니다.** ②를 짤 때 `build_graph()` 를 불렀는데

실패했고, 눈이 먼 것은 **대조 자신**이었습니다.

## 4. D-284 — 검출이 살아났습니다

**검출이 없던 게 아니라 받아서 버리고 있었습니다.** AI 는 한 줄도 안 건드렸습니다.

`grpc_client` → metadata 에 `detections` · `detection_count` · bbox 는 계약대로
**정규화 0.0~1.0** (proto 는 픽셀 정수를 줍니다 — 받는 자리에서 옮기지 않으면 입력 해상도가
바뀌는 날 **이미 쌓인 bbox 가 전부 뜻을 잃습니다**). → `detection_event_bridge` →
K1 `record_detection`. **실호출 경로**(`grpc_dual_stream_service`)가 그것을 부릅니다.

세 가지를 갈라 뒀습니다: **검출 0건 ≠ 배선 없음** · **bbox 모름 ≠ bbox 0** ·
**옮길 줄 모름 ≠ 검출 없음**.

### ★ 배선 시험이 커널 결함을 잡았습니다 (F-04 위반)

같은 배치에 같은 검출 3연발 → 이벤트는 1건으로 접혔는데 `should_notify` 가 **세 번 다 참**
이었습니다. 알림 질의가 `.exclude(pk=event.pk)` 로 자기를 빼는데 **접히면 `event` 가 기존
이벤트**라 유일한 "이전 것"이 매번 제외됐습니다. K2 가 같은 이벤트로 여러 번 알립니다.

기존 시험(30초 간격)은 매번 **새 이벤트**라 이 갈래를 지나가지 않았습니다 —
**시나리오가 초록이어도 갈래가 안 덮이면 못 잡습니다.** 착시 ②(D-262)의 작은 판입니다.

교정: `should_notify = (not folded) and (not prior_exists)`. 이벤트는 여전히 남습니다 —
**U1 의 오탐률 분모는 그대로입니다**(두 창 유지). 양성 대조 확인, 회귀 시험은 **커널 쪽**에.

### 호출처 ② — 지시서 전제를 하나 정정합니다

D-284 는 *"본문이 비어 있고 True 를 낸다"* 고 적었습니다. **앞부분은 맞고, "저장이
안 된다"는 틀립니다.** `VideoAnalysis` 행은 `detect_media` 안의 `Timer` 가 만들고,
MinIO JSON 은 AI 가 콜백으로 씁니다. 그래서 `NotImplementedError` 를 던지지 않고
**독스트링을 사실로 고치고 죽은 코드를 걷었습니다.** 없는 구현을 있다고 적는 것만큼,
있는 구현을 없다고 적는 것도 다음 사람을 헤매게 합니다.

대신 그 자리에서 **진짜 조용한 성공**을 찾았습니다: `.get('results', [])` 가 상류 오류를
빈 목록으로 바꿔 **뷰의 400 갈래가 닿을 수 없었습니다.** 센티넬로 갈라 400 이 닿습니다.

### 전수 조사 39건 — 그리고 조사기가 과녁을 놓쳤던 일

첫 술어는 "빈 본문" 하나였고, 합성 대조 7건은 다 통과하는데 **이 조사를 하게 만든 바로
그 함수를 0건으로 셌습니다.** 진짜 모양은 **"실패를 낼 길이 없다"**(`return True, results`)
였습니다. 착시 ④를 제 손으로 재현한 것이라 코드와 문서에 남겼습니다.

술어를 둘로 넓히고 등급에 **이름**도 보게 했습니다
(`save_log_file_to_minio(data): pass` — 독스트링은 없지만 **이름이 약속**입니다).

```
훑은 파일 514 · 후보 39 (high 29 · medium 6 · low 4 · 판정불가 0)
```

눈에 띄는 것: `send_progress()` — 본문이 **독스트링뿐**인데 **실제로 불립니다.**
진행률 알림이 조용히 아무것도 안 합니다.

**39건은 고치지 않았습니다.** D-284 (3) 이 요구한 것은 **목록**이고, 39곳의 동작을 한
커밋에서 바꾸는 것은 판정 사안입니다.

## 6. 아직 모르는 것 / 안 한 것 — 지우지 않습니다

2. **스냅샷은 붙였지만 한 장도 못 올렸습니다.** MinIO 가 닿지 않습니다(`minio.invalid`).
   못 올리면 `snapshot_path` 는 **빈 문자열**이고 사유가 남습니다 — 가짜 경로를 넣지
   않았습니다.
3. **AI 라벨 어휘를 재지 못했습니다.** 표는 계약 열거값과 **글자가 같은 6종**뿐입니다.
   `"car" → vehicle` 은 그럴듯하지만 재지 않았고, 재지 않은 것을 표에 적으면 그 표가
   근거처럼 읽힙니다.
4. **D-282 가 요구한 "실제 마이그레이션을 적용한 DB 에서 도는 시험 경로"가 없습니다.**
   지금 있는 것은 `--nomigrations` 실행 **안에서 게이트를 부르는** 시험입니다.
   격차를 **보기는** 하지만 그 DB 위에서 **돌지는** 않습니다. **초록으로 세지 않습니다.**
5. **CI 의 migration-check gate 잡은 아직 한 번도 돌지 않았습니다**
