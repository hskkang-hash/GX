게이트 자격증명 — **이름만** 저장소에 산다 (D-204 · P-12 ①)
================================================================================

왜 이 파일이 있는가
-------------------
`route-alive` 게이트는 화면이 실제로 부르는 라우트를 **진짜 HTTP 로 때린다.** 때리려면
로그인해야 하고, 로그인하려면 값이 있어야 한다. 그런데 값은 저장소에 있으면 안 된다.

그 사이에서 이 게이트는 오래 **회색**이었다 — 「판정 불가: 자격증명이 없다」.
회색은 색이 아니라 **빚**이다. 아무도 안 갚는 동안 그 자리는 안 지켜진다.
실제로 그 회색 뒤에 **죽은 라우트 두 자리**가 숨어 있었다 [실측 2026-09-17].

그래서 값은 **저장소 밖의 로컬 파일**에 두고, 저장소에는 **이름만** 남긴다.
게이트는 그 파일을 스스로 읽어 스스로 로그인한다.

어디에 만드는가
---------------
저장소 뿌리에 아래 이름 중 하나. 전부 `.gitignore` 가 잡는다(`.env.*`).
먼저 찾은 것부터 읽고, **이미 환경에 있는 값은 덮지 않는다** — CI 가 준 값이 이깁니다.

    .env.gates        ← 권장. 게이트 전용이라는 것이 이름에 보인다
    .env.local
    .env

무엇을 적는가 — 네 이름
-----------------------

    GX_API=http://localhost:8000
        게이트가 때릴 주소. 컨테이너 안에서 도는 경우 컨테이너가 보는 주소다.

    GX_ROUTE_CONTAINER=gx-shell
        ★ 서버가 **호스트에서 안 보이는** 환경일 때만 적는다.
          이 저장소의 기본값이 그렇다: `gx-shell` 은 8000 을 게시하지 않아
          호스트에서 172.18.0.x:8000 은 시간 초과이고, 컨테이너 안에서는 200 이다 [실측].
          이 이름이 있으면 판정기가 **자기 자신을 그 컨테이너 안에서 다시 돌린다** —
          두 벌의 코드를 만들지 않는다(두 벌은 반드시 어긋난다 · D-369).
          호스트에서 서버가 직접 보이면 이 줄을 지운다.

    GX_ROUTE_USER=<개발용 탐침 계정 이름>
        이 저장소의 개발 환경에는 탐침 계정을 하나 만들어 두었다.
        **운영 계정을 쓰지 않는다** — 운영 서버 로그인 금지(D-209).

    GX_ROUTE_PASSWORD=<그 계정의 비밀번호>
        ⚠ 이 줄의 값을 **어떤 문서에도, 커밋 메시지에도, 증거 파일에도 옮겨 적지 않는다.**
          형식 제약: 특수문자 1자 이상(제품의 비밀번호 규칙).

확인하는 법 — 두 번 돌려 갈리는지 본다
---------------------------------------

    python scripts/verify_route_alive.py            # 있이  → exit 0 또는 1
    (파일을 잠시 치우고 다시)                        # 없이  → exit 2 (판정 불가)

**두 결과가 같으면 이 파일은 읽히지 않고 있다.** 그때는 초록도 믿지 마라 —
익명으로 때려 401 만 보고 「전부 살아 있다」로 적는 것이 이 판정기의 가장 나쁜 실패다.

★ 로그인이 됐다는 것과 토큰이 먹힌다는 것은 다른 사실이다
---------------------------------------------------------
2026-09-17 에 정확히 그 착시가 있었다: 로그인은 200 이었고 JWT 도 받았는데
**26건 중 24건이 401** 이었고, 그 401 을 「문지기가 섰다(살아 있다)」로 읽어 exit 0 이 나갔다.
받은 토큰이 dj-core 의 세션 검사를 통과하지 못했기 때문이다.

이제 판정기는 로그인 뒤 **같은 목록을 익명으로 한 번 더 때려** 무엇이 달라졌는지 센다.
0건이면 판정 불가다 — 들어가지 못한 채 본 401 을 초록으로 적지 않는다.
