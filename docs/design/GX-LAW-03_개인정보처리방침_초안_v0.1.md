# GX-LAW-03 · 개인정보 처리방침 — 초안 v0.1 (GuardianX 운영자용 서식)

- 작성: 세종(CPO) · 2026-09-05(기계) · **초안** — 법률 검토 전. 운영자(지자체)가 자기 명의로 게시한다. GuardianX는 **수집 항목 표와 처리 흐름**을 제품에서 자동으로 채운다.
- 근거: 개인정보보호법 제30조(처리방침 수립·공개) · 처리방침 작성지침. 조문은 법률대리인이 대조.

## 1. 수집 항목 표 (제품이 실제로 저장하는 것 — 이 표가 방침의 뿌리다)

| 항목 | 어디에 | 왜 | 보관 |
|---|---|---|---|
| 영상 정지 이미지(스냅샷) | 객체저장소 | 이벤트 판단 증거 | 이벤트와 같은 기간 |
| 영상 구간 참조(시각·카메라) | DB | 증거 추적 · 원본은 저장소 밖으로 안 나감 | 이벤트와 같은 기간 |
| 사용자 계정(이름·이메일·역할·전화 [확인]) | DB | 로그인 · 알림 수신 | 계정 삭제 시까지 |
| 접속·조작 기록(감사로그) | DB · 해시 체인 | 안전성 확보 · 감사 대응 | [확인] 최소 1년 |
| 알림 발송 기록(수신자·시각·채널) | DB | 대응 이력 | 이벤트와 같은 기간 |

**수집하지 않는 것**: 음성 · 얼굴 인식 특징값 · 차량 번호 인식 [확인 — 제품 사양상 없음].

## 2. 처리 흐름 (한 그림)
카메라 → AI 탐지(온프렘) → 이벤트(스냅샷 1장·구간 참조) → 판정(사람) → 알림(내부 3역할) → 보고서(HWPX/PDF · 스냅샷 포함 여부 [확인]) → 보존 기간 만료 → 자동 삭제.
제3자 제공: **없음**(기본). 외부 연계(에스비 App·SDN)는 **이벤트 메타**만, 영상 없음. 상급기관 보고서 제출은 운영자 판단 [확인].

## 3. 정보주체 권리 (LAW-07과 같은 절차)
열람·존재 확인·삭제 요구 → 접수(화면) → 마스킹본 조회 → 회신 기록 → 10일 이내 회신 [확인 — 법정 기한 대조].
