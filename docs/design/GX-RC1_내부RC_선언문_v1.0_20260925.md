## §2 태그가 선 근거 — **문턱은 하나뿐이다**

```
[RC1] 전량 시험: 통과 2172 · 실패 0 (1242.3초)
[RC1] `rc-1-internal` 태그: 선다 — 전량 2172/0(실패 0) · 빨강·회색 목록은 본문에
      항상 실린다(코드 보장) — 태그 조건 성립.
      S1~S7 의 빨강·회색은 이 태그를 막지 않는다(P-269)
```

⚠ **이 태그는 「이 수로 나간다」가 아니라 「이 수가 지금 우리 수다」이다.**
초록을 강제하는 조건은 **0 개**다. S1~S7 이 온통 빨강·회색이어도 전량 실패가 0 이면
태그는 선다 — 그렇게 짜지 않으면 「내부 RC」라는 말 자체가 불가능해진다.
반대로 **수천 건이 통과해도 한 건이 실패하면 안 선다**(출생 표본: 2151/1 → 안 섬).

서명은 python 이 잴 수 있는 사실이 아니다 — 코드로 0 을 지어내면 그 0 은 측정이 아니라
창작이다. 그래서 세종 표(`GX-S1S7_상용조건_v1.0_20260925.md`)를 읽고, **표가 없거나
값이 {0, 0.5, 1} 밖이거나 근거가 비면 그 행은 회색**으로 남는다.

★★ **0.5 를 빨강으로 적은 까닭.** 표의 눈금은 {0, 0.5, 1} 인데 이 판정기의 칸은
{빨강, 회색, 초록}이라 **반 칸이 없다.** 초록으로 올리면 「다 했다」로 읽히고, 회색으로
내리면 「못 쟀다」와 섞인다 — 둘 다 거짓이다. 그래서 빨강으로 적되 판정문이
「0.5 다. 절반은 섰다」를 그대로 싣는다. **색보다 그 문장이 정확하다.**
