## §1 상용서비스 수준 정의 — 「돈을 받는 조건」 일곱

상용 = 고객(지자체 재난안전과 · 관제센터 · 산림과)이 **사용료를 내고** 쓰는 서비스. 세종 정의:

|---|---|---|---|
| S1 | **첫 근무일에 제 일이 끝난다** — 6종 × 8 필수 flow 48행 ≥ 90 % | 24.5/48 (51 %) | ○ |
| S2 | **누르면 끝난다** — 주요 단추 48 「누른 뒤 서버가 변하고 화면이 따라온다」 ≥ 44/48 | 32/48 · 빨강 1 · 회색 15 | ◐ |
| S3 | **아무도 없는 아침에 서 있다** — 재부팅 뒤 10/10 · 백업 회수증 · 감시 알림 | 10/10 이나 재부팅 증거 0 · 회수증 ● · 감시 ● | ◐ |
| S4 | **틀린 것을 틀렸다고 말한다** — 거짓 초록 0 · 감사 체인 새 끊김 0 · 시험 자료가 고객 화면에 0 | 초록 다섯 부류 갈림 ● · 체인 0 ● · **탐침이 화면 첫 줄** ○ | ◐ |
| S5 | **밖에서 닿는다** — 공개 주소 · TLS · 잠금화면 알림 · 실카메라 | 주소 0 · 스테이징 0 · 웹푸시 자격 소실 · 실카메라 0/4 | ○ |

## §7 Kick · Edge 가 명확한가

있다 — 그러나 **화면에 이름이 없다.** 이 제품이 경쟁 관제 SW(일반 VMS · 지자체 통합관제 · 드론 관제)와 갈리는 자리 셋:

1. **골든타임 계기판** — 사건마다 「발생 → 접수 → 조치 → 종결」 시각을 **기록에서** 세고, 30분을 넘기면 빨갛다. 재난안전법 상황보고 30분과 같은 눈금. (경쟁: 이벤트 목록만.)
2. **거짓말 안 하는 관제** — 누른 뒤 서버가 변한 것만 초록 · 감사 해시체인(법정 문장) · 「이 사진은 시드입니다」까지 적는다. (경쟁: 초록 배지가 뜻이 없다.)
3. **훈련 채널** — 실제 알림 경로로 훈련 발송 · 훈련 사건 배지 · 청구 제외(예정). (경쟁: 훈련 모드 없음 · 실사고로 시험.)

**Kick 이 안 보이는 이유**: 세 가지가 세 화면에 흩어져 있고 제품 이름이 없다. 권고: 「**골든타임 30**」(계기판) · 「**정직 관제**」(판정·체인) · 「**훈련 모드**」를 **제품 안 이름**으로 — 온보딩 첫 카드 셋이 그 셋을 보여 준다(WO-03 파 2).

## §11 Disruptive 셋 — 「내가 미처 챙기지 못한 것」을 포함해

### A. Disruptive 사업모델 — 「카메라당」이 아니라 「보증당」
1. **골든타임 보증 요금(Outcome-based)**: 기본료를 낮추고(센터당 연 1,200만 [권고]), **「30분 안 접수율 ≥ 95 %」를 우리가 보증**하고 미달 월은 크레딧. 계량 근거는 이미 있는 **대응 시계 p50/p95**(OPS-16). 경쟁사는 이 수 자체가 없어 따라올 수 없다.
2. **훈련 모드 무료 90일**: 실카메라 없이 **drill 씨앗 + 훈련 채널**만으로 지자체가 「훈련」을 해 본다 — 청구 0(P-201/206). 훈련 보고서(별지 1호 「훈련」 배너)가 그대로 **재난대비훈련 실적**이 된다(지자체는 연 2회 훈련 의무). 영업이 아니라 **컴플라이언스 도구**로 들어간다.
3. **사건 증거 구독**: 감사 해시체인 + 「이 사진은 시드/실제」 표기 + LAW-08 종이 앵커 → **「법정 제출용 사건 묶음」**(사건 1쪽 + 체인 증명 + 원본 구간)을 건당 옵션 판매. 보험사·손해사정에 두 번째 고객이 생긴다.
4. **공공 이벤트 API 무료 티어**: F-05 읽기 전용 OpenAPI 를 **인접 지자체·소방·경찰에 무료** 개방(키 1 · 읽기 2 라우트). 데이터가 흐르는 곳이 표준이 된다 — 유료는 웹훅(쓰기·구독).
5. **채널 파트너(에스비정보기술) 재판매 = 설치·현장, 우리는 SaaS 구독**: 계약서 1장 + 가격표 숫자 4 가 이번 달 안에 필요한 이유.

### B. Disruptive 기술 — 이미 절반이 있다
1. **오탐 학습의 네트워크 효과(K6)**: 테넌트별 판정(실제/오탐 · 사유)을 **카메라 유형·시간대·기상**으로 묶어 전 고객 공유 임계 모델로 — 고객이 늘수록 오탐이 준다. 개인정보 0(판정 라벨만). v1.2 에 「공유 임계 옵트인」 스위치 하나.
2. **상황보고서 자동 초안 + 재난문자 90자 초안**: 별지 1호 13항목은 사건에서 이미 채워진다. 여기에 **재난문자(90/157자) 초안**과 **골든타임 카운트다운 문구**를 같은 화면에 — 담당자는 「보내기」만. 규제(재난문자 자수)를 제품이 안다.
3. **드론 정찰 요청 한 단추(FWS 연계)**: 구역 경보(3대+) 가 울리면 **드론 정찰 요청 카드**가 큐에 뜬다(이벤트 버스 계약 13종 중 하나). 안양천 드론 사업(제안서)과 **같은 이벤트 버스**라 코드 추가가 작다.
4. **잠금화면 우선 설계(모바일)**: 웹푸시 + M3 3단(어디로/무엇을/무엇을 하나) — 앱 설치 0. 자격 셋만 실으면 바로 선다(창 2b).
5. **감사 체인의 「종이 앵커」를 QR 로**: LAW-08 일일 앵커를 사람이 종이와 대보는 대신 **일일 해시를 QR 로 인쇄 → 다음날 스캔**(코드가 일부러 안 재던 자리를 사람 손 1초로).
6. **엣지 없이 VLM 없이(결정 ⑤ 「안 산다」 유지)** — 규칙 + 사람 판정 + 학습으로 간다. GPU 는 팔릴 때 산다.
