    스테이징 승인이 와도 공개 URL 은 `verify_prod_settings` **5/5** 없이 열지 않습니다.
    비밀키 자리표 · DEBUG=True · ALLOWED_HOSTS=`*` 가 **기본값**이었고 판정기가 0건이었습니다.

**그 게이트는 이번 턴에 섰고, 지금 초록입니다** [실측 2026-09-06 · `gx-shell`]:

    docker exec gx-shell python /repo/scripts/verify_prod_settings.py
    [SEC-18] 통과 5/5 — 운영 프로필로 뜨면 닫혀 있고, 선언이 빠지면 **뜨지 않는다**
      SECRET_KEY(선언 없음·자리표 → 거부) · DEBUG(강제 False) · ALLOWED_HOSTS(`*` → 거부)
      COOKIES(여섯 다 닫힘 · 개발 프로필은 3/6 열림) · ORIGINS_TLS(스킴 없음 → 거부 · HSTS 1년)

⚠ **그러나 「게이트가 초록」과 「지금 세울 수 있다」는 다른 사실입니다** [조율자 정정 · 실측 2026-09-06].
판정기는 **자기가 판을 만들어** 「선언이 있으면 닫히고 없으면 안 뜬다」를 증명합니다. 그것은
규칙이 옳다는 증명이지, **이 환경에 선언 값이 있다는 증명이 아닙니다.** 지금 값은 비어 있습니다:

    뿌리 `.env`               넷의 **값 없음** (`.env.example` 에 이름만 섰습니다)
    컨테이너 SECRET_KEY       **33자** — 운영 프로필은 50자 미만을 거부합니다
    `backend/.env.stg`        `DJANGO_ALLOWED_HOSTS` · `DJANGO_CSRF_TRUSTED_ORIGINS` 없음

**대표께 드리는 뜻**: ④를 승인하시면 **막는 것은 이제 없습니다.** 남은 일은 값 넷을 만들어
심는 것이고 **분 단위**입니다 — 다만 **서버가 정해져야 호스트 이름을 적을 수 있으므로**
승인보다 먼저 할 수 있는 일이 아닙니다. 승인이 늦어질 이유는 **아닙니다.**
승인 없이 URL 을 여는 길은 이제 **게이트가 막습니다**(`deploy.sh` 가 개발 프로필이면 배치 거부).
