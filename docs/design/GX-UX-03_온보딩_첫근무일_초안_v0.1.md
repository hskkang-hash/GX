# GX-UX-03 · 온보딩 문서 — 「첫 근무일에 혼자 시작하기」 초안 v0.1

- 작성: 세종(CPO) · 2026-09-05(기계). 사용자 6종 × 한 쪽. 화면 이름은 GX-COPY 사전을 따른다. 영실은 이 문서를 로그인 화면 「처음이세요?」 링크와 각 역할 첫 화면 「?」에 잇는다(UX-03 AC).
- 원칙: 한 쪽에 **오늘 할 일 7개 이하** · 각 줄은 「어디서 → 무엇을 누르면 → 무엇이 된다」.

## 관제요원 (U1) — 교대 첫날
1. 로그인 → **지금 처리할 것** 화면이 뜬다. 가장 급한 이벤트 하나가 위에 있다.
2. 카드의 사진과 한 줄 사유를 본다 → **실제 / 오탐 / 보류** 중 하나를 누른다(키보드 1·2·3).
3. 실제면 **접수** 를 누른다 — 시계가 돈다. 팀장과 현장에 알림이 간다.
4. 종결은 현장 회신이 오면 누른다. 오탐은 사유를 고른다(임계값 개선에 쓰인다).
5. 아무 일 없을 때: **카메라 화면**에서 격자·순회로 본다. 검은 칸(맥박 없음)은 카메라 무응답이다.
6. 교대 끝: **인계 메모** 에 미처리 이벤트와 특이사항을 적고 로그아웃.
7. 화면에 「저장소에 연결할 수 없습니다」가 뜨면 사진만 안 보이는 것이다 — 알림과 목록은 계속 된다. 관리자에게 알린다.

## 관제팀장 (U2) — 아침 인수
1. 로그인 → **지난 12시간** 한 줄 요약(미처리·오탐·미판정).
2. **미처리** 프리셋에서 남은 것을 본다 → 재판정(등급 올림·내림, 사유 필수).
3. **내 담당** / **요원별 처리** 로 누가 무엇을 했는지 본다.
4. 오탐 많은 카메라 → 설정에서 임계값 조정 → 저장 전 **시험** 으로 시간당 알림 수를 본다(6건 넘으면 주황).
5. 상황보고서: 이벤트 상세 → **보고서 생성**(HWPX·PDF).
6. 훈련 날: 설정 → **훈련 모드** 켜기(사유 필수) — 실제 알림이 나가지 않는다. 끝나면 끈다.

## 이동 중 (U3 = 요원·팀장·담당자의 휴대폰)
1. 문자 링크 → 로그인 → **내게 온 이벤트**.
2. 사진·주소·경과 시간을 보고 **접수** 를 누른다(앱 없이 문자 「1」 회신도 된다).
3. 현장에서 **도착 · 사진 1장 · 한 줄** 로 회신.
4. 근무 외 시간 알림은 설정에서 끌 수 있다(관리자 승인).

## 재난안전과 담당자 (U4) — 월요일
1. 로그인 → **지난 7일** 요약.
2. **보고서** → 월간 「이번 달 우리 센터」 1쪽(대응 시간·오탐률·가동률·건수) → HWPX 다운로드.
3. 민원: **이벤트 검색**(기간·카메라·유형) → 상세 → 스냅샷(마스킹본).
4. 「내 모습 지워 달라」 요청: **열람·삭제 청구** 접수 → 회신 기록.
5. 감사: **감사 기록** 조회(누가·언제·무엇을).

## 시스템 관리자 (U5) — 설치 다음 날
1. **사용자** 등록 → 역할 부여(관제요원·팀장·담당자·관리자).
2. **카메라 일괄 등록**: CSV(이름·코드·주소·주소 상세) 붙여넣기 → 표 먼저 보기 → 적용. 「주소 없는 카메라 N대」가 0이 되게.
3. **알림 규칙**: 등급별 수신 역할 확인 · 심각 수신자 0명 금지 · 채널(이메일 기본).
4. **시스템** 프리셋에서 카메라 무응답·저장 용량 임계를 본다. 매일 08:00 「GuardianX 정상」 메일이 안 오면 장애다.
5. **백업** 상태 · 보존 기간 설정. **훈련 모드** 위치를 팀장에게 알려 준다.

## 외부 연계 개발자 (U6)
1. 관리자에게 **API 키** 발급 → OpenAPI 문서 → 이벤트 조회 → **웹훅 구독**(서명 검증 · 재시도 규약) → 헬스체크.
