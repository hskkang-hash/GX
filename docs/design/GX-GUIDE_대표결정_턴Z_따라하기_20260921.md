## ① Docker 자동 시작 (네 턴째 · 5분 + 재부팅)

**결정 한 줄**: 컴퓨터가 켜지면 Docker 가 스스로 뜨게 한다.

**왜 지금**: 영실이 지난 턴에 직접 시도했지만 `Access is denied` — 영실 셸은 관리자가 아닙니다. 이것은 **대표 계정의 관리자 권한**으로만 됩니다. 이게 안 서면 「재부팅한 다음 아침에 컨테이너 10개가 스스로 섰는가」를 영영 못 잽니다(G5).

**대표가 하는 일**
1. 시작 단추 → `PowerShell` 입력 → 오른쪽 클릭 → **「관리자 권한으로 실행」** → 「예」.
2. 아래 두 줄을 붙여 넣고 Enter.
   ```
   Set-Service com.docker.service -StartupType Automatic
   Get-Service com.docker.service | Format-List Name, StartType, Status
   ```
   `StartType : Automatic` 이 보이면 됐습니다. (`Access is denied` 가 또 나오면 1번이 관리자 창이 아닌 것입니다.)
3. Docker Desktop 창 → 오른쪽 위 톱니(Settings) → **General** → **「Start Docker Desktop when you sign in to Windows」** 체크 → **Apply & restart**.
4. 오늘 퇴근 전 **재부팅 한 번** (컨테이너는 볼륨이 남으니 자료는 안 없어집니다 · 재부팅 전 영실 세션이 돌고 있으면 끝나길 기다리십시오).
5. 다음날 아침 채팅에 **「재부팅했다」** 한 줄.

**영실이 하는 일**: 아침 첫 일로 `python scripts/verify_autostart.py`(세 겹: 서비스 · Desktop · 컨테이너) → `exit 0` · 컨테이너 N/10 · 앞단 200 · `live_freshness --all`. 9/10 이하면 어느 컨테이너인지 이름으로.

**끝났다는 증거**: 보고 첫 줄 「재부팅 아침 10/10 · autostart exit 0」.

**안 하면**: G5 가 다섯 턴째 ◐ · 정전·업데이트 재부팅 뒤 아무도 없는 아침에 서비스가 안 뜹니다.

**그대로 쓸 한 줄**: `① 자동 시작 켰고 재부팅했다.`

## ② 씨앗 삭제 (1분)

**결정 한 줄**: 게이트 탐침(probe) 씨앗 사건 4건과 그에 딸린 것을 지운다.

**왜 지금**: 사건 #295402 를 비롯한 probe 씨앗이 **발송을 계속 낳고**(229→233→…) 매 턴 분모를 움직입니다. 제품은 이제 probe 를 안 세지만(P-193) 표에는 남아 있습니다. 지난번(09-20)과 같은 종류의 결정입니다 — 그때는 「16건」이 실제 177행이었고, 이번은 영실이 **먼저 연쇄를 쟀습니다**:

| 지워지는 것 | 수 |
| --- | --- |
| 사건(DetectionEvent · probe) | **4** |
| 발송 기록(DeliveryRecord · CASCADE) | **42** |
| 클립(EventClip · CASCADE) | **4** |
| 보고서 링크(DsmReportRun · 연결만 끊김 · 행은 남음) | **3** |

**대표가 하는 일**: 위 표를 보고 채팅에 한 줄. 되돌릴 수 없으므로 표의 수가 마음에 안 들면 「사건 #295402 만」처럼 범위를 좁혀 주셔도 됩니다.

**영실이 하는 일**: ① 지우기 전 스냅샷(`evidence/P-184/deleted_probe_snapshot_<날짜>.json` · 4+42+4+3행) ② 삭제 ③ 감사 체인 재측(새 어긋남 0 · 등재 23 그대로) ④ probe 인구조사 0 확인 ⑤ 보고에 「지웠다 (N, {...})」 한 줄. 드릴(drill · 훈련) 씨앗은 **안 지웁니다** — 그건 종결(closed)로 남기는 규약입니다.

**끝났다는 증거**: 보고 「probe 사건 0 · 발송 −42 · 체인 새 어긋남 0 · 스냅샷 파일명」.

**안 하면**: 발송 분모가 매 턴 움직여 U3·V 의 수가 흔들립니다(결함은 아님).

**그대로 쓸 한 줄**: `② 씨앗 그대로 지워라 (4·42·4·3).`

## ③ 창 2a 일시 (한 문장 + 창 30분)

**결정 한 줄**: 컨테이너를 만지는 두 번째 창(2a)을 언제 열지 정한다.

**왜 지금**: 절차서가 준비돼 있습니다(`evidence/P-178/RUNBOOK_창2a.md` · 16단계 · 되돌릴 수 없는 자리 ★셋 · ⛔C7 superuser 박탈은 이번 창에서 **안 함**). 창 1 때 대표 한 줄이 오후 늦게 와서 186분을 기다렸습니다. 이번엔 **일시와 「열어라」를 한 문장**으로 주시면 그 시각에 바로 엽니다.

**이 창이 하는 것 셋**
- **A** `gx-shell` 재생성 — 감독 스크립트(`gate_servers.sh`)가 서버를 지키게 함(★되돌릴 수 없는 자리: 컨테이너 삭제 1회 · 그 전에 보존 5분).
- **B** gunicorn 재활용 값 확인 · 재측(OPS-13a).
- **C** DB 역할 전환 — 앱이 superuser(`postgres`)로 붙는 것을 앱 전용 역할로(되돌릴 수 있음 · **회수가 앱 전환보다 먼저**라는 순서 제약 반영). **C0 에서 한 번 멈춰 대표께 「계속」을 묻습니다.**

**대표가 하는 일**
1. 영실 세션이 살아 있는 시각을 고르십시오(평일 10:00~16:00 사이 30분 · 차선이 전부 멈춘 뒤 엽니다 → 턴 시간표와 안 겹치는 **턴 뒤 시각**이 좋습니다. 예: 09-23 14:00).
2. 채팅에 한 문장.
3. 창 중간에 영실이 **「C0 — 계속합니까」** 하고 한 번 묻습니다. 그때 「계속」 또는 「여기까지」.
4. 창이 끝나면 영실이 「바뀐 것만 바뀌었나」 기준선 표(§2)와 견줘 보고합니다.

**영실이 하는 일**: 절차서 §1 네 조건 확인(하나라도 아니면 안 엶) → §2 기준선 뜨기 → A0 보존 → A1~A4 → B → C0 멈춤 → (계속이면) C1~C6 → 되돌림 표 → `prod_settings` 7/7 · 컨테이너 10/10 · 로그인 4/4 · 보고.

**끝났다는 증거**: 「창 2a 시작 hh:mm · 종료 hh:mm · 되돌린 것 0 · gx-shell 감독 pid · OPS-13a 두 줄 · 역할 전환 C0/C6 어디까지」.

**안 하면**: OPS-13a(앞단 5xx)·OPS-24(권한 최소화)가 회색으로 남고, 앱이 계속 superuser 로 DB 에 붙습니다.

**그대로 쓸 한 줄**: `③ 창 2a 09-23 14:00 열어라. C0 에서 물어라.`

## ⑤ 감사 화면 로거 목록 넓히기 (이번 턴은 표만)

**결정 한 줄**: 감사 조회 화면(U4 재난안전과 · `/dsm/audit`)이 보는 로그 종류(`READABLE_LOGGER_NAMES`)를 넓힐지.

**왜 지금이 아닌가**: 지난 턴 「삭제된 사건을 가리키는 체인 행 29건」이라 적었던 것이, 실은 화면이 닿는 것은 **2행**뿐이었습니다 — 화면은 정해진 로거 이름 몇 개만 봅니다. 넓히면 **감사 화면의 수가 바뀌고**, dj-core 접속 로그(요청마다 한 행 · 13만 행)까지 화면에 올라와 **누출 울타리**(개인정보·IP)를 같이 봐야 합니다. 그래서 이번 턴은 영실이 **「넓히면 화면 수 N → M · 무엇이 새로 보이는가」 표**만 만듭니다.

**대표가 하는 일**: 이번 턴 없음. 다음 턴 표를 보고 「넓혀라 / 그대로」.

**그대로 쓸 한 줄(다음 턴)**: `⑤ 로거 목록 그대로.` 또는 `⑤ 넓혀라 — 접속 로그는 빼고.`

## ⑥ 3대 이상 구역 0개 — OPS-15 (1분)

**결정 한 줄**: 「한 구역에서 활성 카메라 3대 이상이 동시에 끊기면 경보」 규칙(OPS-15)이 **울릴 수 있는 구역이 지금 0개**입니다 — 실카메라(0/4)가 오기 전까지 **훈련 구역 1개(drill 카메라 3대)** 로 규칙이 실제로 한 번 울리게 할지.

**왜 지금**: 「규칙은 서고 현장이 비었다」 부류입니다. 규칙이 옳다는 것과 현장이 감시된다는 것은 다릅니다. 훈련 구역으로 울리면 **경보 경로가 산다는 것**은 증명되고, 대장에는 「훈련 구역으로 잼 · 실카메라 뒤 재측」이라 적힙니다(초록이 아니라 래칫/규칙만 부류 그대로 · 거짓 초록 아님).

**대표가 하는 일**: 둘 중 하나를 한 줄로.
- 「훈련 구역으로 울려라」 → 영실이 drill 카메라 3대짜리 훈련 구역 1개(이름 「[훈련] 안양천 시험구역」)를 만들고 3대를 동시에 끊어 경보 1회 → 웹푸시(훈련 채널) 도달 1.
- 「실카메라 올 때까지 회색」 → 그대로.

**영실이 하는 일**: 훈련 구역·카메라는 `data_source=drill` 로만(청구 제외 · 화면 「훈련」 배지) · 경보 1회 · 기록 후 구역은 남김.

**끝났다는 증거**: 「OPS-15 훈련 구역 1 · 경보 1 · 웹푸시 도달 1 · 절 상태 rule_only 유지(사유 갱신)」.

**그대로 쓸 한 줄**: `⑥ 훈련 구역으로 울려라.`
