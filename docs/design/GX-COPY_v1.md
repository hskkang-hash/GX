- 작성: Code(조율자) · 2026-09-26 (P-29 초안 · 적용은 차선 C 의 UX-20)
- 강제: `python scripts/verify_ui_copy.py` — 렌더 문자열에 대장 언어가 있으면 잔여로 센다
- 정본: **이 문서 하나다.** 화면 코드의 라벨 표(`frontend/src/features/dsm/copy.ts` ·

## 0. 왜 사전이 생겼나 — 사고 한 건과 결함 서른한 건

화면 24장을 한 장씩 읽었더니 결함 31건이 나왔고, 그중 11장의 뿌리가 하나였다:
**화면이 우리 개발 대장의 말로 말한다.** D-번호 · 절 ID · 백틱 경로 · 마크다운 원문 ·
영문 열거값 · 개발 주석이 사용자 본문에 있었다. 가장 나쁜 한 장은 계약 상대사명과
조항이 관제요원 화면에 문단으로 뜬 것이었다(P-27 로 닫음).

**이것은 화면을 만든 쪽의 잘못이 아니다.** 「사유를 화면에 적어라」 「출처를 표기하라」가
시킨 결과다. 정정한다:

> 사유 · 출처 · 판정 근거는 **관리자 패널과 「?」 아이콘 뒤**에 산다.
> 사용자 본문에는 **사용자 언어만** 쓴다.

## 1. 규칙 넷

1. **사전에 없는 새 문구는 만들지 않는다.** 없으면 사전에 먼저 넣고 쓴다.
2. **표시만 바꾼다.** 계약 스키마 값(`severity` 의 info/warning/critical,
   `response_state` 의 occurred/… )은 그대로 두고 **라벨에서 매핑**한다 —
   값을 바꾸면 계약이 바뀐다.
3. **없는 것은 없다고 적는다.** 다만 **어디에 없는지**는 적지 않는다 —
   파일 경로 · 커널 이름 · 표식은 사용자에게 뜻이 없고, 읽는 사람에게는 우리 서랍의 지도다.
4. **한 화면에 축은 하나.** 「대응」 「상태」 「판정」을 나란히 세우지 않는다 —
   사람이 어느 축을 보는지 모른다.

## 2. 지금 화면의 말 → 바꿀 말

| 지금 화면 | 바꿀 말 | 왜 |
|---|---|---|
| 위험 · 경고 · 정보 | **심각 · 경계 · 주의** | 계약 3등급(F-04)이 그 세 낱말이다 |
| 대응 「발생(미처리)」 / 상태 「신규」 / 판정 「—」 **세 열** | **처리 단계 한 열**: 미처리 → 접수 → 조치 중 → 종결 · **판정 배지**: 실제 / 오탐 | 축이 셋이면 아무도 안 본다 |
| 기각(상태) · 오탐(판정) | **오탐** 하나 | 같은 뜻 두 낱말 |
| 종결(으)로 | **종결** | 프로그램이 만든 조사는 사람의 말이 아니다 |
| 규칙대로 발송 | **알림 보내기** | 「규칙대로」가 무엇인지 화면 앞에서는 모른다 |
| Network Error | **사진을 불러오지 못했습니다 · 다시 시도** | 원문 오류는 사용자의 말이 아니다 |
| 오탐률 잴 수 없음(판정 0건 — 분모가 없다) | **아직 판정한 이벤트가 없습니다** | 분모 이야기는 관리자 자리 |
| 표시 7건(요청 상한 50건) | **7건** | 상한은 「?」 뒤로 |
| 패널 상태 data 0/0 loading 0/0 … | (사용자 화면에서 **제거** · 관리자 패널로) | 개발 계수기 |
| 「UX-17 …」 「UX-18 …」 「W1 단일 초점 —」 | **훈련 모드** · **카메라 일괄 등록** · **지금 처리할 것** | 절 ID 는 제목이 아니다 |
| `data_source = live` 칩 | **실운영 / 시드(검수용) / 훈련** 배지 (시드·훈련일 때만 표시) | 영문 열거값 노출 |
| 안내 상자의 개발 문단(백틱 · D-번호 · 커널 경로) | **「?」 아이콘 → 팝오버 한 줄**(사용자 언어) · 원문은 관리자 패널 | 뿌리 ① 그 자체 |
| 연계 상태: `waiting` — 〈사유 문단〉 | **연계 대기** 한 단어 + 관리자 전용 **「자세히」** | P-27 에서 닫음 |
| 「역할 매핑을 찾지 못해…(K3_ROLE_PRESET_MAP)」 | **화면 구성이 아직 정해지지 않았습니다. 관리자에게 문의하십시오.** | 설정 이름은 관리자 자리 |

## 4. 금지 — 사용자 본문에 쓰지 않는 것

- 결정 번호 `D-000` · 절 ID(`UX-00` · `SEC-00` · `F-00` · `P-00` …)
- 백틱(`` ` ``) · 마크다운 강조(`**`) — 렌더되지 않고 그대로 보인다
- 내부 경로 · 파일 이름 · 커널 이름 · 설정 상수 이름 · 감사 채널 이름
- 영문 열거값(`occurred` · `acknowledged` · `live` · `data_source=` …)
- 계약 상대사명 · 계약번호 · 조항 (P-27 · 별도 판정기 `verify_ui_secrets.py`)

## 5. 아직 사전에 없는 것

새 문구가 필요하면 **여기에 먼저 한 줄을 적고** 쓴다. 비어 있는 것이 정상이고,
비어 있지 않은 채로 오래 있으면 그것은 사전이 뒤처졌다는 뜻이다.
