## 1. 상용서비스 수준 정의 [판정]

「고객이 쓰고 사용료를 낸다」를 다섯 문장으로 못 박는다. 하나라도 「아니오」면 상용이 아니다.

1. **들어간다** — 고객 담당자가 받은 URL·계정으로 자기 사무실 PC와 휴대폰에서 로그인한다(설치 안내 없이).
2. **첫날 일이 끝난다** — 6종 사용자가 첫 근무일 업무를 GuardianX 안에서 끝낸다(온보딩 48행 ≥ 90% · 셋째 술어「그 사용자의 언어」).
3. **밤에 죽지 않는다** — 새벽 3시 장애를 시스템이 먼저 알리고, 사람이 1쪽 절차로 30분 안에 되살린다(RTO 30분 · RPO 24시간 [판정]).
4. **법 앞에 선다** — 고지·방침·열람 청구·감사 기록·AI 고지가 갖춰져 감사·민원에 답한다.
5. **청구서가 나간다** — 계량된 사용량(카메라·좌석·이벤트)으로 월 청구서와 SLA 보고가 자동으로 나간다.

지금: 1 ◐(로컬만) · 2 ◐(57%) · 3 ◐(경보 도달 0) · 4 ○ · 5 ○.

## 2. 실사용 사용자 6종 · 페르소나별 업무 Flow — 「돈을 내는 사람」 표시

|---|---|---|---|
| U1 관제요원 | 8h 교대 · 99% 평상 | 로그인 → 지금 처리할 것 → 판정(실제/오탐) → 접수 → 종결 → 순회 → 인계 | 쓰는 사람. 안 쓰면 계약이 안 늘어난다 |
| U2 관제팀장 | 2h | 밤사이 요약 → 미처리 → 재판정 → 요원별 현황 → 임계값 → 보고서 | **추천자** — 옆 시 팀장에게 말하는 사람 |
| U3 이동 중 | 사건당 30분 | 문자 → 접수 → 도착 → 회신(사진·한 줄) | 쓰는 사람 |

| U5 시스템관리자 | 주 1h | 사용자·카메라 일괄 등록 → 알림 규칙 → 시스템 상태 → 백업 → 훈련 모드 | 계약 갱신의 거부권자(막히면 나머지가 막힌다) |

**돈을 내는 사람은 U4의 예산이고, 계약을 만드는 사람은 U2의 입이다.** 제품이 U1에 맞춰져 있는 것은 옳지만, **U4가 매달 손에 쥐는 종이(월간 1쪽)**와 **U2가 자랑할 수(대응 시간)**가 없으면 갱신이 없다.

## 5. 이름은 고객의 말인가

- 게이트 `ui_copy` 잔여 **0** · 등급 「심각·경계·주의」 · 처리 단계 1축 [실측 턴 B]. **눈 확인은 턴 D 재촬영 뒤.**
- 남은 의심 셋 [판정]: ① 「프리셋」 — 관제요원 말이 아니다 → **「보기」** (미처리 보기 · 지난 12시간 보기) ② 「테넌트」가 화면 어디에도 안 나가는지 ③ 「대응 시계」 — 좋은 이름이다, 그대로. 화면 이름 대신 **사람 말 세 개**를 상단에: 「지금 처리할 것 · 무슨 일 있었나 · 우리 센터」.

## 7. 킥·엣지는 명확한가
코드에는 있다 — 대응 시계 · 맥박 군집 · 해시 체인 · 훈련 모드 · 알림 예산. **고객 눈에는 아직 없다** — 랜딩 0장 · 데모 시나리오 0 · 「탐지 후 8분」이라는 문장이 제품 어디에도 안 적혀 있다. 킥은 **월간 1쪽 첫 줄**과 **로그인 화면 한 문장**(「GuardianX는 대응 시간을 잽니다」)에 산다. 둘 다 턴 D.

## 8. 불필요한 화면
관제 역할에서 끊음(턴 C): 드론 Device · NOTAM · 비행로그 · 조사 프로파일 · 영문 CRUD 4. **남은 셋 [판정]**: 레거시 감시 대시보드(스켈레톤 고착) · 미디어 버킷 브라우저 · 드론 다중 스트림(검은 타일) — U5에서도 끊고 UX-23 격자로 대체. 화면 수 24 → **관제 역할 9장**이 목표.

## 9. 경쟁 제품보다 5배 쉬운가 — 재지 않고 말하지 않는다
지금 우리 수: 가장 급한 하나까지 **1클릭 · 2.0s**, 판정까지 **2클릭**. 경쟁(기존 VMS 팝업 → 영상 확인 → 별도 전파 시스템 → 전화)은 **잰 적이 없다**. 5배는 **파일럿 첫 주에 기존 워크플로우 클릭 수·화면 수·교육 시간을 세서** 말한다. 세 지표 [판정]: 이벤트→판정 클릭 수 · 신규 요원 교육 시간(목표 30분) · 야간 1인 근무 가능 여부.

## 12. Disruptive — 사업모델 · 기술 · 영업마케팅

### 12.1 사업모델 셋
1. **대응 시간 보증(Outcome-backed)** — 「탐지→접수 p95 90초·현장 8분」을 SLA로 팔고, 미달 월은 사용료를 깎는다. 탐지 정확도를 파는 경쟁사는 이 약속을 못 한다 — 대응 시간은 **우리 제품이 재는 수**다. 기본료를 낮추고 보증으로 신뢰를 산다.
2. **선시공 후분양(PBAS) 파일럿** — 안양 39대를 6개월 무상, 조건은 **대응 시간·오탐 데이터 공개 사용 동의**와 **레퍼런스 공개**. 레퍼런스 0 → 1이 이 회사의 가장 비싼 자산이다.
3. **관제 연합 데이터** — 지자체별 오탐 라벨(사람 판정)을 익명 집계해 모델·임계값을 공동 개선. 가입 센터가 늘수록 오탐이 준다 — **네트워크 효과가 있는 유일한 자리**. 이용 동의 조항이 뿌리(§11-8). 보험사와의 연결(재난 대응 기록 → 시설 보험료)은 진행 중인 제안과 이어 검토.

### 12.2 기술 셋
1. **관제 코파일럿** — 밤사이 요약 한 줄을 **보고서 초안·전파문 초안·재난문자 문안**까지 넓힌다(K4 + VLM 사유 + 대응 이력). 야간 1인 근무자가 아침 팀장에게 넘길 것이 자동으로 써져 있다. 판정은 사람(AI기본법 34조).
2. **오탐 자가 튜닝 제안** — K6 코호트로 카메라·시간대별 임계값을 **제안**(승인은 사람). 알림 예산과 함께 「이 카메라는 새벽 2~4시 감도 10% 내림」을 버튼 하나로.
3. **앱 없는 현장** — 문자 「1」 회신 접수 · PWA 오프라인 셸 · 전화 버튼. 앱스토어 없이 현장 대응자 100%를 첫날 태운다. 경쟁사는 앱을 깔게 한다.

### 12.3 영업·마케팅 셋
1. **무료 「대응 시간 진단」 4주** — 설치 없이 기존 관제 로그·근무 일지로 탐지→대응 시간을 재 준다(세종이 서식으로). 결과지 1장이 곧 제안서다. 산불철(3월) 전 10개 센터.
2. **투명성 포털** — 지자체가 시민에게 「이번 달 대응 시간·오탐률·카메라 가동률」을 공개(Flock Safety 참고). 지자체장의 홍보 자산이 되고, 옆 시가 묻는다. 월간 1쪽의 공개판.
3. **채널 둘 추가** — 에스비(SDN) 외에 **관제 인력 위탁운영사**(그들의 원가가 인력이고 우리는 인력 효율을 판다)와 **조달 경로**(GS·KISA 인증 → 혁신제품·나라장터). 행안부 CCTV 통합관제 콘퍼런스(3월)에서 **훈련 모드 라이브 데모** — 실경보 없이 안전하게 보여 줄 수 있는 유일한 제품.

## 대표께
- 사용자와 지불 고객의 눈으로 다시 쟀습니다. **기능 79% · 기술 준비 82% · 공개 URL 0 · 돈 받을 준비 22%.**
- 눌러 보니 나온 것 중 가장 무거운 것: 핵심 버튼(미처리→접수)이 죽어 있었고, 사진이 한 장도 안 떴고, **관제실에서 월과 데스크를 동시에 못 켭니다.** 앞의 둘은 고쳤고 셋째는 새 절로 올립니다.
- 돈 받을 준비 22%는 개발이 아니라 세종의 일입니다 — 가격의 형태, 계량, SLA(RTO 30분), 청구, 데이터 이용 동의, 레퍼런스. 이번 주에 세종이 씁니다.
- Disruptive 셋: **대응 시간 보증**으로 팔고, **관제 연합 데이터**로 해자를 만들고, **무료 대응 시간 진단**으로 들어갑니다.
- 부탁 둘: 세종이 직접 누를 길(LAN 주소 또는 Chrome 확장 연결) · SMTP 자격증명(보낼 계정) — 이 둘이 오면 다음 보고는 눌러서, 경보는 받아서 씁니다.
