# GX-REPORT · 무료 대응 시간 진단(4주) — 서식 v0.1

- 작성: 세종(CPO) · 2026-09-06(기계) · 턴 G. GX-PRICE §2 「무료 구간(Free Core · 유입)」의 **첫 도구**.
- 목적: **제품을 설치하지 않고** 관제센터의 대응 시간을 4주간 재서 **한 장**으로 돌려준다.
  이 한 장이 파일럿 제안의 근거가 된다 — 팔기 전에 **그 센터의 수**를 손에 쥐여 준다.

## 0. 이 문서가 약속하는 것 / 약속하지 않는 것

**약속하는 것**
1. **설치 0** — 서버·카메라·계정을 건드리지 않는다. 재는 것은 **그 센터가 이미 쓰는 기록**이다.
2. 4주 뒤 **한 장**을 낸다: 구간별 대응 시간 · 병목 한 곳 · 개선 시 절감 추정(가정을 명시한 채로).
3. 원자료는 **진단이 끝나면 돌려주거나 파기**하고 그 사실을 문서로 통지한다.

**약속하지 않는 것**
1. **탐지 정확도·오탐률을 진단하지 않는다** — 우리 제품이 안 붙어 있으므로 잴 수 없다.
2. **절감 추정은 실측이 아니다.** 가정을 표에 적고, 가정이 틀리면 수가 틀린다고 먼저 말한다.
3. 진단 결과는 **계약을 만들지 않는다.** 무료이고, 이어지는 파일럿은 별도 합의다.
4. 우리가 **영상·개인정보를 받지 않는다** — 받는 것은 §2 의 **시각 기록**뿐이다.

## 1. 4주 동안 하는 일 (사람 손 기준)

| 주 | 우리가 | 고객이 | 걸리는 시간(고객 기준) |
|---|---|---|---|
| 0주 | 진단 합의서 1장 · 받을 항목 목록(§2) 전달 | 담당자 1명 지정 | **30분** |
| 1주 | 기록 수령 → 형식 확인 → **못 읽는 칸 회신** | 지난 3개월 기록 1회 전달 | 1시간 |
| 2~3주 | 구간 분해 · 병목 후보 2~3곳 · 중간 1장 | 중간 1장 확인(15분) | 15분 |
| 4주 | **최종 1장 + 30분 설명** | 설명 자리 1회 | 30분 |

★ 고객이 쓰는 시간 합계 **2시간 15분**을 먼저 적는다. 무료라도 **시간은 공짜가 아니다** —
  이 수를 안 적으면 담당자는 「또 일이 늘어난다」로 읽는다.

## 2. 받는 항목 (이것만 · 개인정보·영상 없음)

| 항목 | 형식 | 왜 |
|---|---|---|
| 사건 접수 시각 | 일시(분 단위) | 구간 ① 의 시작 |
| 최초 확인·판단 시각 | 일시 | 구간 ① 의 끝 |
| 출동·현장 도착 시각 | 일시(있으면) | 구간 ② |
| 종결 시각 | 일시 | 구간 ③ |
| 사건 유형 | 코드·낱말 | 유형별 분해 |
| 야간/주간 구분 | 파생 가능 | 교대 영향 |
| 카메라·구역 식별자 | **가명 코드**(우리는 실주소를 받지 않는다) | 편중 확인 |

**받지 않는 것**: 영상·스냅샷 · 신고자·담당자 성명·연락처 · 번지 이하 주소 · 사건 내용 본문.

## 3. 돌려주는 한 장 (서식)

```
{센터명} 대응 시간 진단 — {측정 기간}                         GuardianX (무료 진단)
────────────────────────────────────────────────────────────
① 구간별 시간        접수→판단  중앙값 {p50_1} · 95% {p95_1}
                     판단→출동  중앙값 {p50_2} · 95% {p95_2}
                     출동→종결  중앙값 {p50_3} · 95% {p95_3}
                     (표본 {n}건 · 제외 {n_excl}건 — 제외 사유: {why_excl})
② 가장 긴 한 구간    {bottleneck} — 전체 시간의 {pct_bottleneck}
③ 시간대·유형 편중   야간 {p50_night} vs 주간 {p50_day} · 최다 유형 {top_type}
④ 카메라·구역 편중   상위 3: {top3_zone} (전체 사건의 {pct_top3})
⑤ 개선 여지 [추정]   {bottleneck} 를 {target}분으로 줄이면 사건당 {saved}분
                     가정: {assumption}  ← 이 가정이 틀리면 이 수는 틀린다
⑥ 못 잰 것           {not_measured}  ← 빈칸으로 두지 않는다
────────────────────────────────────────────────────────────
자료 출처: {센터명} 제공 기록 {기간} · 우리는 영상·개인정보를 받지 않았다
이 진단은 계약이 아니다 · 원자료는 {파기일}에 파기하고 서면 통지한다
```

## 4. 규칙 (이 서식을 쓰는 사람에게)
1. **표본 수와 제외 건수를 반드시 적는다.** 제외를 안 적으면 좋은 수만 남길 수 있다.
2. **⑥「못 잰 것」칸을 비워서 내지 않는다.** 비면 「다 쟀다」로 읽힌다.
3. **⑤는 언제나 [추정] 딱지를 붙인다.** 가정 없는 절감액은 영업 문구이지 진단이 아니다.
4. 우리 제품 이름을 ①~④ 어디에도 넣지 않는다 — **그 센터의 수**이지 우리 자랑이 아니다.

## 5. 남은 확인 [확인]
진단 합의서 1장(무상·비밀유지·원자료 파기) 서식 · 원자료 수령 경로(보안 메일? 실물?) ·
지자체 자료 반출 승인 절차 · 진단 도구를 **손으로 하는가 스크립트로 하는가**(첫 건은 손으로 하고, 두 건째에 도구를 만든다).
