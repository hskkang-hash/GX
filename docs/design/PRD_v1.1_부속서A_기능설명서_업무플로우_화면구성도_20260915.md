**읽는 법.** §1의 120행 표는 한 행이 하나의 사용자 업무다. 「v1.0」 열은 09-14 판정과 대장 대조를 합친 현재 상태(●구현 ◐부분 ○없음 ⊘잠김), 「v1.1」 열은 목표 상태와 그것을 만드는 요구사항 ID다. 「완결 조건」은 PRD v2.7 §1의 「끝난다」 술어 — 역할 계정으로 눌렀다 → 호출 ≥ 1 → 서버 상태가 바뀌었다(재조회) → 화면 상태 칸이 바뀌었다 — 로 적는다. §2의 흐름은 행위자·화면·API·상태 변화를 단계마다 적고, §3의 화면은 GAION 화면정의서 11필드로 적는다. 화면 문구는 전부 GX-COPY 사전의 말이다.
