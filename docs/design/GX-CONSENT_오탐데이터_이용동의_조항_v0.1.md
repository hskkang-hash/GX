# GX-CONSENT · 오탐 판정 데이터 이용 동의 조항 — 초안 v0.1 (계약 부속용)

- 작성: 세종(CPO) · 2026-09-06(기계) · **초안 · 법률 검토 전**. 「관제 연합 데이터」(상용 점검 §12.1-3)의 뿌리. 개인정보가 아닌 **판정 메타데이터**만이 대상이다.

## 1. 대상 데이터(한정 열거)
이벤트 유형 · 등급 · 판정(실제/오탐) · 오탐 사유 코드 · 카메라 유형·설치 환경 분류(하천·도로·시설) · 시간대 · 대응 시계 4시각. **제외**: 영상·스냅샷·좌표·주소·카메라명·사용자·테넌트 식별자(익명 집계 전 제거).

## 2. 목적
탐지 규칙·임계값·VLM 사유 품질의 공동 개선 · 월간 「우리 센터」 지표의 동종 비교(익명) · 대응 시간 보증(SLA 부속)의 기준선.

## 3. 방식
테넌트 단위 옵트인 스위치(U5 설정 · 기본 **꺼짐**) · 익명 집계본만 반출(원자료는 고객 서버에 남는다 · 11조와 같은 원칙) · 반출 로그 감사 기록 · 언제든 철회.

## 4. 대가
옵트인 테넌트: 개선된 규칙·임계값 제안 우선 적용 · 동종 비교 리포트 · 파일럿 무상 기간 연장 [확인 · 가격표와 정합].

## 5. 확인 [법률]
개인정보 해당성(비식별 조치 수준) · 공공기관 데이터 반출 규정 · 계약 8조(IP)와의 관계 · 철회 시 파기 절차.
