## 7. Kick · Edge — 있다. 아직 아무도 팔지 않는다

**Kick(한 문장)**: 「**모른다 · 없다 · 아니다를 구별해 말하는 관제 시스템**」 — 응답 없음 3대 중 「응답을 받은 적이 없는」 3대 · 기록이 없는 칸은 「아직」 · 0건은 「요청은 성공했고 0건」. 세 페르소나(U1·U2·U5)가 서로 모르고 같은 문장을 칭찬했다[영실]. 경쟁 제품은 「3대 오프라인」이라 쓰고 설치 문제와 장애를 가린다.
**Edge 둘**: ① **대응 시계 4시각(발생·접수·조치·종결)** — 골든타임을 사건마다 초 단위로 남기고 「아직」을 빨강으로 그리지 않는다 → 감사·SLA·조달 규격 문장이 된다 ② **영상 무반출 판단 전달**(계약 11조 · 구간 티켓 서명 · 프리사인드 URL 금지) — 「영상은 안 나가고 판단만 나간다」 — 개인정보 심사에서 경쟁 제품이 못 하는 말.
**조달 규격서 문장(제안)**: 「관제 시스템은 장치 무응답을 「설치 후 응답 이력 없음」과 「응답 중단」으로 구분 표시하고, 사건마다 발생·접수·조치·종결 시각을 기록해 미기록 칸을 실패로 표시하지 않아야 한다.」 — 이 문장이 들어가면 경쟁사는 자기 대시보드가 거짓말한다는 것을 스스로 증명해야 한다.

## 9. 경쟁제품보다 5배 쉬운가
**척도 셋**: ① 첫 근무일을 문서 0장으로 혼자 끝내는가 ② 사건 하나 처리에 몇 번 누르는가 ③ 「어디까지 됐나」에 몇 초 만에 답하는가.
- **설계**: 3클릭(목록 → 상세 → 판정) · 대응 시계 한눈 · 첫 화면이 「지금 처리할 것 하나」 — 경쟁 제품(탭 6개 · 필터 8개 · 상태 코드) 대비 **5배 쉬운 설계다.**
- **지금**: 판정 버튼이 죽어 **3클릭이 끝나지 않는다** → 0배. 「처음이세요」 7줄 안내는 좋다 — 그러나 2번 줄(「카드의 사진과 한 줄 사유를 봅니다 · 실제·오탐·보류 중 하나를 누릅니다」)이 실제로는 안 된다. **안내가 제품보다 앞서 있다.**
- **판정**: import 한 줄 + 스냅샷 렌더 + 「전체·기간」이 서면 5배는 **측정 가능한 주장**이 된다 — 안양시 관제요원 3인에게 첫 근무일 완주 시간(목표 ≤ 30분 · 문서 0)을 재서 숫자로 적는다(입소문 서식 · PRD v2.6 §5).

## 10. 고객이 돈을 낼 이유 · Disruptive 셋

**낼 이유(지금 팔 수 있는 것 셋)**: ① 골든타임을 사건마다 초 단위로 증명한다(감사·의회 자료) ② 오탐을 줄여 「알림을 끄지 않는 관제」 — 오탐 판정이 임계값으로 돌아간다 ③ 영상이 밖으로 나가지 않는다(개인정보 심사 통과 문장). **낼 이유가 없는 것**: 보고서(택배 운송장) · 알림(로그) — 이 둘이 서기 전엔 U4가 서명하지 않는다.

**Disruptive 사업모델**
1. **성과 연동 구독** — 카메라당 정액 + 「접수 ≤ 3분 · 조치 착수 ≤ 15분」 달성률 90% 미달 달엔 요금 20% 크레딧. 대응 시계가 있어야만 가능한 가격이다 — 경쟁사는 못 따라온다.
2. **오탐 데이터 동의 할인**(GX-CONSENT 연결) — 오탐 판정 데이터를 모델 개선에 쓰는 데 동의한 센터는 15% 할인 → 데이터 플라이휠 · 센터마다 임계값 학습.
3. **「4주 무료 대응시간 진단」**(GX-REPORT 서식 실재) → 진단 보고서 자체를 의회·감사 자료로 쓰게 한다 → 계약은 그 뒤. **20대 이하 소규모(아파트·학교) 무료 티어**로 채널(에스비) 설치 물량을 확보.
4. **감사 대응 보증** — 「감사관 질문에 60초 안에 사건·처리 기록·담당자를 뽑지 못하면 그 달 무료」.

**Disruptive 기술**
1. **3값 관제(모른다·없다·아니다)의 표준화** — 증거 등급(evidence grade)을 모든 칸에: 「측정됨 · 미측정 · 없음」. 대시보드 API 스키마에 넣어 조달 규격으로 밀어 넣는다.
2. **VLM 2차 판정**(대표 ⑥ GPU 1장) — 1차 감지 → VLM이 「사람인가 · 연기인가 · 반사인가」 한 줄 사유 → 관제요원은 사유를 읽고 누른다. 오탐 판정 → 카메라별 임계값 자동 조정 → **알림을 끄지 않는 관제**.
3. **영상 무반출 판단 전달 아키텍처** — 원본은 센터 안, 밖으로는 서명된 구간 참조와 판단만(계약 11조가 곧 제품 특성).
4. **오프라인 셸 모바일(M1~M3)** — 지하·현장에서 마지막 사건 카드가 살아 있는 휴대폰 화면.
5. **자동 순회 + 침묵 감지** — 「아무 일 없는 8시간」을 「카메라 40/40 살아 있음 · 지난 1시간 조용함」으로 바꾼다 — 조용함도 측정값이다.

**Disruptive 영업·마케팅**
1. **조달 규격서 문장 배포**(§7) — 지자체 재난안전과·소방에 「무응답 구분 표시 · 4시각 기록」 문장을 넣게 한다.
2. **「이번 달 우리 센터」 1쪽 자동 발송**(GX-REPORT 서식) — 매달 예산 담당자 책상에 가치 증명이 놓인다. 갱신 결재의 근거.
3. **안양시 파일럿 → 4주 진단 보고서 공개 사례** → 경기 31개 시군 · 소방서 순회.
4. **채널(에스비) + 무료 티어 물량** → 설치 수로 데이터 플라이휠.
5. **입소문 종이 한 장**(PRD v2.6 §5) — 관제요원이 옆 센터에 말하는 다섯 문장.
